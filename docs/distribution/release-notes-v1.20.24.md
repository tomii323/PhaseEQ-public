# PhaseEQ v1.20.24 更新案内

公開日: 2026-10-13

PhaseEQ v1.20.24では、ユーザーガイドと画像付き操作マニュアルを整理し、PDFの容量を削減しました。アプリ本体の機能・DSP処理・保存形式は変更していません。

## 操作説明の整理

- REWなどで測定済みのデータを入力し、目標特性の設定から補正・DSP出力へ進む手順を整理しました。
- マルチウェイはFIR対応DSPの手順を基本とし、IIRのみのDSPで変更する操作を分けました。LR2／LR4の音響ターゲットへの反映と、補正の実行を区別しています。
- PhaseEQの説明をマルチウェイと同じ目的・操作・確認の流れに揃え、FIR専用機能を明示しました。Stereo Linkは基本手順後の任意操作にまとめています。
- Standaloneの目標特性に、出力帯域分割のHP／LPを音響ターゲットへ反映する手順を追加しました。
- ウェイ編集中に操作できない項目はマルチウェイ側の変更先を案内し、Standalone向けの操作と共通機能を区別しました。
- 会話的な呼びかけを控え、簡潔なマニュアル調を維持しました。必須条件・安全上の注意は保持しています。

## PDFの容量削減

- 掲載サイズに合わせて画像を最大150 dpiへ縮小し、JPEG（品質82・4:4:4）と可逆圧縮（Flate）の小さい方を選択します。画像の拡大は行いません。
- 元の撮影画像・来歴は開発側で保持し、本文・図形は文字・ベクターのまま収録しています。拡大表示や高解像度印刷では、元画像より精細さが低下します。

## 確認範囲

- PDFの全ページ描画、本文・しおり・保存記録、配布契約、既定の軽量品質チェックを確認します。
- フルテスト・実機DSPでの受入試験は実施していません。
