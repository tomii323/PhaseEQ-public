# PhaseEQ v1.20.8 更新案内

PhaseEQ v1.20.8では、一般公開用リポジトリを開設し、利用に必要なプログラムと文書を公開しました。

- 起動に必要な補助プログラムを`runtime/`へ整理しました。ランチャーからの起動方法は変わりません。
- 一般公開するソースと配布ZIPには、開発文書、テストプログラム、開発スクリプト、廃止資産を含めません。
- 画像付き操作マニュアルを同梱しています。現行版の公開先リンクを反映しています。

以前の展開先へ上書きせず、新しいフォルダーへZIPを展開して使用してください。設定・データの扱いは[インストール手順](installation.md)を参照してください。
