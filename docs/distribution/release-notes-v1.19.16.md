# PhaseEQ v1.19.16 更新案内

本書はこの版を公開した時点の変更記録です。現在の操作・設定条件は[操作ガイド](user-guide.md)、後続版の変更は[更新履歴](history.md)を参照してください。 Power V4の生成方式はv1.19.17で廃止され、現在はターゲット追従式です。

PhaseEQ v1.19.16では、Power v4の谷補正を調整し、予測応答の表示設定とターゲット選択時の編集保護を設定画面へまとめました。

## Power v4の谷補正

- 谷BoostのQ上限を0.8から2.0へ広げ、検出した谷の近傍で形状を合わせます。
- 新規ディップ、帯域誤差、中心レベル、ピークPowerの許容量を緩和しました。鋭い局所ディップの除外と、手動IIRを含むヘッドルーム制限は維持しています。
- 生成済みのAuto IIRは自動では置き換わりません。新しい基準を使うには「自動IIRを削除」後、Power v4で再生成してください。ターゲット追従方式と同じ周波数・Q・ゲインになるとは限りません。

## 表示設定とターゲット選択

- 予測応答の自動更新・モード・表示点数は「設定」の「予測応答の表示設定」へ移しました。「更新」ボタンは予測応答の見出し行の右端にあります。
- 「設定」の「ターゲットの選択」で、未保存編集があるときの切り替えロックをON/OFFできます。初期値はOFFです。
- OFFでは未保存の編集を破棄して選択先へ切り替えます。編集を保護したい場合はONにしてください。ONでは従来どおり保存・破棄・キャンセルを確認します。登録済みターゲットは変更しません。

## 更新と確認

編集中の内容を保存し、PhaseEQとマルチウェイを終了してから更新してください。更新後にアプリを起動し、ブラウザーを再読み込みしてください。

通常の軽量品質チェックと、隔離したブラウザーでのPower v4生成、表示設定の変更・保持、手動更新、ターゲット選択ロックの初期値・切り替え・保存を確認しています。
