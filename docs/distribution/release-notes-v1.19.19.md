# PhaseEQ v1.19.19 更新案内

本書はこの版を公開した時点の変更記録です。現在の操作・設定条件は[操作ガイド](user-guide.md)、後続版の変更は[更新履歴](history.md)を参照してください。

PhaseEQ v1.19.19では、Multiwayへの測定割り当てを整理し、PhaseEQ送信時のIIR次数不一致と表示上の警告を修正しました。

## 主な変更

- スピーカー測定データの上部メニューに「マルチウェイに割り当て」を追加。測定一覧の選択を引き継ぎ、専用ページでも測定データと送信先を選べます。
- MultiwayからPhaseEQへの送信対象を、現在の有効な帯域チャンネルに限定。過去の返却データ・追加音声入力に現在のRecipeを誤適用して送信が止まる問題を修正しました。既存データは保持します。
- 左右ペインの最小高さ360px制限を撤廃。左右独立のスクロールを維持し、画面の高さに追従します。
- Auto Gain等の数値入力で初期値が二重指定される警告を修正。Waveletグラフの日本語軸名・測定名に日本語フォントを適用しました。

## 更新と確認

編集内容を保存して両アプリを終了し、新版へ更新して通常ランチャーから起動してください。通信形式・DSP処理の順序は変更していません。

軽量品質チェック、関連回帰テスト、実画面での7チャンネル送信と上部メニューの移動・選択引き継ぎを確認しています。フルテストは実施していません。
