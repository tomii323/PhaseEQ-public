# PhaseEQ v1.20.15 更新案内

PhaseEQ v1.20.15では、PhaseEQとMultiwayのEQリンクの変更・復元を修正しました。

- 別の画面でEQやリンク構成を変更したとき、古い画面の値で上書きされる問題を修正しました。編集中なら編集案を保持し、最新値の読込または確認後の反映を選べます。競合が未解決の間はMultiwayへ送信できません。
- 保存設定を明示的に読み込むと、対象チャンネル・共有項目・EQ値を確認してからリンク構成を復元します。無関係なグループは保持します。自動の画面復帰では現在の共有設定を使用します。
- リンク確認画面の手前に設定ポップオーバーが残る問題を修正しました。取消後は設定案を保持します。
- 操作ガイドと画像付きマニュアルを更新しました。

詳しくは[Stereo Linkの操作](stereo-link.md)と[操作ガイド](user-guide.md)を参照してください。
