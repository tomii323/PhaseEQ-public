# PhaseEQ v1.20.10 更新案内

PhaseEQ v1.20.10では、正式な利用条件を整備し、生成物ZIPへの説明同梱を追加しました。

- PhaseEQは個人利用向けの無償フリーウェアです。本体の商用・業務利用は禁止します。GitHub上の閲覧・Fork・Pull Requestと、それに必要な変更共有は許可します。改変・再配布などの正式条件は[LICENSE.md](../../LICENSE.md)を参照してください。
- 個人利用で生成した成果物は、その後の商用・業務用機器への組み込み、利用、改変、販売、配布にも利用できます。ただし、商用・業務目的で本体を使用して新たに生成・調整することは禁止します。
- 作業保存、DSP／FIR、マルチウェイ、測定結果、測定用音源の出力ZIPに「生成物の利用条件.txt」を追加しました。この説明ファイルを生成物の再配布時にも添付する義務はありません。
- 本体配布ZIPにはLICENSE.md全文を同梱します。README・操作ガイド・画像付きマニュアルは要点と正式条件への参照に統一しました。

DSP処理、係数・波形・測定結果・設定データの内容や形式は変更していません。配布ZIPは新しいフォルダーへ展開してください。詳細は[出力ファイル仕様](output-format.md)と[インストールガイド](installation.md)を参照してください。
