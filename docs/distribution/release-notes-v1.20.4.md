# PhaseEQ v1.20.4 更新案内

PhaseEQ v1.20.4では、マルチウェイのタップ長設定を操作しやすくしました。

## 主な変更

- 帯域のタップ数を変更したとき、再計算中にサイドバーのスクロール位置が変動する問題を修正しました。入力欄より上の位相・時間整合とバッフル実現方式の表示領域を保持し、計算後に同じ場所へ結果を表示します。
- 「出力タップ数を最長フィルターに揃える」を「設定」から「3 FIR出力・タップ長」の帯域別入力欄の下へ移動しました。説明文も同じ場所にまとめています。

## 更新について

既存の設定値と保存形式は維持します。出力タップ数統一の処理と、FIR出力OFF時の無効化も従来どおりです。今回の更新に伴う保存データの移行やフィルターの再生成は不要です。
