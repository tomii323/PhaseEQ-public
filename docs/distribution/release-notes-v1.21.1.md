# PhaseEQ v1.21.1 更新案内

PhaseEQ v1.21.1では、理想スピーカー特性の状態表示を整理し、画像付きユーザーマニュアルとマルチウェイ簡易マニュアルを更新しました。

## 入力状態の表示

- 理想特性を使用中のチャンネルと、入力未設定のチャンネルを区別して表示します。入力元、位相・時間整合の案内、返却一覧、PhaseEQの入力要約へ反映しました。
- 全チャンネルが理想特性またはUnityの場合は、スピーカーの音響時間差を含めず、帯域分割とフィルターだけを解析することを案内します。
- 実測応答と理想特性／Unityが混在する場合の自動時間整合の制限を維持します。全チャンネルへ実測応答を設定するか、全チャンネルを理想特性またはUnityに揃えて解析してください。
- 入力整形の対象帯域に入力と目標の共通データがない場合の案内を、理想特性を含む入力に合わせて整理しました。係数計算と保存形式は変更していません。

## マニュアルの更新

- 画像付きユーザーマニュアルを現行仕様へ更新しました。理想入力、IIR適用後のFIR補正、NTM4、入力整形、指定タップ長と自動クロップ、Stereo Link、設定ファイル読込みを説明します。
- 第3章に番号付き画面マップと各領域の役割を追加しました。ページ切替、編集対象、左側の設定と右側の応答表示、適用・再計算・保存・書き出しの違いを説明します。
- マルチウェイ簡易マニュアルは15ページの構成とダーク配色を維持し、IIR → FIR → 返却 → 合成確認 → 保存・出力の操作を同期しました。画面例には実際の撮影版を記載しています。

## 検証範囲

軽量品質チェック、配布契約、PDFの描画・ページ構成・リンクを検査します。前版で実施した隔離環境の画面検証では、理想特性／入力未設定／実測応答の組合せによる案内を確認しています。実利用中のアプリと編集内容は検証のために操作していません。

実機DSPへの取込みと音響測定は今回の検証に含みません。使用時は出力先の設定と実測応答を確認してください。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.21.1になったことを確認します。

操作の詳細は[利用ガイド](user-guide.md)を参照してください。
