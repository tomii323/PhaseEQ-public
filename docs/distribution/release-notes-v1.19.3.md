# PhaseEQ v1.19.3 更新案内

PhaseEQ v1.19.3では、品質確認と配布公開の処理を高速化し、Release成果物の確認を強化しました。音響処理、DSP係数、画面操作、保存形式の仕様変更はありません。

## 主な改善

### 品質確認時間の短縮

全テストを省略せず、独立したテストを複数の処理へ均等に割り当てる方式へ変更しました。開発時とRelease前の確認時間を短縮し、修正結果をより早く確認できます。

### Release成果物の確認強化

配布ZIPだけでなく、SHA-256チェックサムも公開されていることをRelease完了条件として確認します。更新案内や配布文書の不足は、時間のかかる全品質確認より先に検出します。

### 非公開リポジトリでの確認

公開状態を匿名で確認できない場合は、すでに利用可能なGitHub接続だけを参照します。Release処理から新しい認証を開始したり、認証設定を変更したりしません。

## 更新後の確認

通常どおりPhaseEQとComposite Engineを起動し、既存の設定、Multiway System、Target、Assignment、Resume、DSP Exportを利用できます。DSP結果を変更する更新ではないため、既存プロジェクトの再計算は不要です。

## 互換性

v1.19.2以前の設定と出力形式を継続して利用できます。
