# PhaseEQ v1.21.9 更新案内

PhaseEQ v1.21.9では、マルチウェイの出力先DSPの保存・復帰と一括設定を追加しました。C-DSPの操作説明を読みやすく整理し、マニュアルとヘルプの表現を継続して揃える基準も整備しています。

## 出力先DSPを保存・復帰

出力先DSPとデバイスプロファイルを通常の設定へ保存します。再読込み・再起動、設定JSON、作業バックアップ、System Libraryと履歴からの再開で復帰します。旧設定で選択情報がない場合は、従来の既定先miniDSPを使います。

復元直後の設定を同じ実行内の旧設定で上書きしていた共通経路も修正しました。

## DSPに合わせた一括設定

出力先DSP内に「このDSP用の設定へ変更」ボタンを追加しました。変更項目と変更前後を確認してから適用できます。C-DSPでは次のマルチウェイ設定を変更します。

- サンプルレート：48 kHz
- DSP FIR出力：OFF
- 位相構造補償の自動適用：ON
- 音響ターゲットへの反映：全境界・位相時間整合ともOFF

PhaseEQのEQ編集値とWorking Sessionは保持します。DSPを選んだだけでは設計条件を変更しません。自動更新OFFの場合は再計算してください。分割方式・帯域数・段数などの残る条件は、表示されたエラーに従って調整します。

DSPごとの変更条件、差分の計画、適用、画面描画を分離しています。対応サンプルレートは各プロファイルの宣言から判定し、現在の値が対応している場合は維持します。

C-DSP専用ZIPは機器取込み用です。作業の再開には「作業バックアップZIP」を保存してください。

## ヘルプとマニュアル

C-DSPの説明を「概要／準備／読込み・測定／再生・比較／条件・注意／原典」の6節に分け、PEQの使用条件とファイル読込み先を表で示しました。画面・ZIP内README・利用ガイドで内容を共有しています。

C-DSPをケーススタディとして、長いヘルプの分類、段落、比較表、警告、原典の示し方を記載規約へ反映しました。マニュアル生成ガイドラインにも、配色・書体・文字サイズ・図表・画像枠・余白・確認手順を明記しています。

[画像付きマニュアル](manual/PhaseEQ_v1.21.9_画像付き操作マニュアル_日本語.pdf)は改訂46・96ページ、[簡易マニュアル](manual/PhaseEQ_Multiway_QuickGuide_15p_Dark_JA.pdf)は15ページです。本文は画像付き版最大395文字、簡易版最大400文字です。画像内のUI文字は本文文字数に含めません。共通のダーク配色と画像の拡大上限を維持しています。

## 確認範囲

通常の軽量品質チェックと配布契約を確認しています。隔離ブラウザーでは日英の一括変更・再読込・ヘルプ表示、作業バックアップの保存値、機器用ZIP係数の一致を確認しました。設定の復元境界とSystem Library・履歴保存も試験しています。

全Resume画面の個別往復、PhaseEQとのExchange往復、実機DSPへの取込み・音響測定は今回の検証に含めていません。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.21.9になったことを確認します。

操作の詳細は[利用ガイド](user-guide.md)を参照してください。
