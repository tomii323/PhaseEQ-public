# PhaseEQ v1.20.25 更新案内

公開日: 2026-10-16

PhaseEQ v1.20.25では、PhaseEQ／マルチウェイの操作説明とDelay管理を更新し、補正返却待ち・設定切替・自動補償OFF時の状態残留を修正しました。

## 機能追加・変更

- 画面に保存・終了方法を追加し、更新予約後にアプリの終了と起動スクリプトによる再起動を案内します。
- 帯域分割方式の使い分け、合成Gain・Phase、FIRタップ数のトレードオフ、カイザー窓の周期数・急峻性の目安を整理しました。調整フローと各方式のヘルプも同期し、周期数の表示を小数点以下2桁へ統一しました。
- 必要な補正結果が未返却でも、現在の処理で再計算・出力します。表示した待機理由に応じて、補正の設定・更新・返却を行ってください。
- スピーカー間・各Wayの相対DelayとFIRの理論遅延を分けて管理し、Delayの内訳と積算結果を表示します。測定Delayがある場合は使用し、ない場合はFIRの理論遅延で整合します。
- DSP追加Delayは最小の遅延目安を基準とする相対値とし、グラフ・保存・DSP出力で同じ積算結果を使用します。出力機器のDelay上限は、保存・転送時に確認してください。
- ヘルプと利用者向け文書の説明・操作フローを整理しました。同梱PDFはv1.20.24改訂31で、今回までに更新した操作説明を収録しています。現在の詳細は[操作ガイド](user-guide.md)を参照してください。

## 不具合修正

- 位相構造補償をOFFにしても、自動生成したAll-passが残って補償済みのグラフ・出力となる問題を修正しました。構成切替後の非表示チャンネルとGroup名変更も対象に含めています。
- 合成波の位相・群遅延・インパルス・ステップ・ウェーブレットを、共通遅延を除いた中心で表示するよう修正しました。各チャンネルの相対的な時間差は保持します。
- PhaseEQの設定復元で古い入力の付随情報やMic補正が残る経路と、Multiwayの新しい返却結果・キャッシュにない旧Speaker応答や処理が残る経路を修正しました。不正な復元・返却結果は適用せず、前回の検証済み状態を維持します。
- 検証処理のデータ保存先を実利用から分離しました。検証のために起動中アプリの未保存編集や実利用Exchangeを操作しない規約も追加しています。

## 更新後の確認

編集中の内容を保存し、起動元のターミナルで`Ctrl+C`を押してアプリを終了します。同じアプリフォルダーの起動スクリプトを実行し、バージョンがv1.20.25になったことを確認してください。

旧保存データに残っているAll-passは、自動／手動の所有者を識別できない場合は保持します。自動補償を解除する場合は「位相構造補償を自動適用」を一度ONにしてからOFFにし、グラフと出力設定を確認してください。

通常の軽量品質チェックを実施します。フルテスト、全操作順序の実画面検証、実機DSP・音響の受入試験は今回の検証範囲に含めていません。出力後は、機器の設定と実際の応答を確認して使用してください。
