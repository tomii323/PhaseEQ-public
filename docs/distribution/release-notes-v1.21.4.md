# PhaseEQ v1.21.4 更新案内

PhaseEQ v1.21.4では、スピーカー割り当てに関する説明を実装に合わせて訂正し、公開Release本文と配布ZIP内の更新案内を揃えました。アプリの機能とDSP計算はv1.21.3から変更していません。

## 説明の訂正

- 「測定一覧・使用」の周波数応答・インピーダンス一覧では、選択とプレビューを解除できます。使用中のSpeaker周波数応答は、別の確認付き操作で割り当てを解除します。インピーダンスは記録・プレビュー用です。
- PhaseEQの「マルチウェイに割り当て」では、測定一覧で選んだ候補を右側グラフへ表示します。送信先一覧でチャンネルを選ぶと、そのチャンネルの現在入力も比較表示します。選択だけでは割り当てを変更しません。
- マルチウェイの「3. チャンネル設定」へのスピーカー選択追加は保留中です。選択・登録・解除の操作をこの画面へ移設していません。

配布ZIPには、[訂正版のv1.21.3更新案内](release-notes-v1.21.3.md)と本更新案内を同梱します。公開済みv1.21.3のZIPとチェックサムは保持します。

## 検証範囲

訂正内容はソースとの照合と、文書品質チェック56件・関連回帰試験28件で確認しました。今回のリリースでは通常の軽量品質チェックと、配布ZIP内の更新案内の一致を確認します。実画面と実機DSPの再検証は今回の文書訂正に含みません。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.21.4になったことを確認します。

操作の詳細は[利用ガイド](user-guide.md)を参照してください。
