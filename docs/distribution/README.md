PhaseEQは個人利用向けの無償フリーウェアで、本体の商用・業務利用は禁止です。個人利用で生成した成果物は、その後の商用利用・配布も可能ですが、商用・業務目的で本体を使って新たに生成・調整することは禁止です。正式条件は[LICENSE.md](../../LICENSE.md)を参照してください。
