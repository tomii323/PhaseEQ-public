# PhaseEQ v1.20.26 更新案内

公開日: 2026-10-16

PhaseEQ v1.20.26では、マルチウェイの位相構造補償に使い方の説明を追加しました。

## 主な変更

- 「位相構造補償を自動適用」のすぐ下に、「位相構造補償の使い方」を追加しました。普段は閉じておき、必要なときに開いて確認できます。
- クロス付近の位相差と合成GainのON／OFF比較、設定の流れ、改善効果と適用範囲を掲載しました。数値例は条件を示した理論計算です。実際の効果は補償前後の測定と試聴で確認してください。
- 追加バイクアッド数、FIRタップの要否、群遅延と設定済みDelayの違い、音響ターゲット経由の確認点を掲載しました。
- 説明データ・描画・設定処理を分離し、日本語・英語の表示、利用者ガイド、開発仕様を同期しました。

## 更新後の確認

編集中の内容を保存し、起動元のターミナルで`Ctrl+C`を押してアプリを終了します。同じアプリフォルダーの起動スクリプトを実行し、バージョンがv1.20.26になったことを確認してください。

軽量品質チェックと、隔離したブラウザーで日英の配置・開閉・設定保持を確認しています。実機DSP・音響での受入試験は今回の検証範囲に含めていません。出力時には機器のバイクアッド枠とオールパスへの対応を確認してください。
