# PhaseEQ v1.21.2 更新案内

PhaseEQ v1.21.2では、EQの編集設定と内部処理バージョンを分離し、モノラル・リンクなしでも内部情報の差だけでComposite生成が止まる問題を修正しました。

## Composite生成と再生成の判定

- 内部処理バージョンだけの差を、IIR EQ／FIR EQの編集として扱わないようにしました。既存設定と保存復帰を維持します。
- 実際にIIR EQ／FIR EQ、Auto EQ、入力整形の設定を変更した場合は、従来どおりPhaseEQで再生成・送信が必要です。
- 再生成の通知を「チャンネルのEQ設定」の変更として表示します。Stereo Linkを使用していない場合も、変更対象を確認できます。
- 旧EQ所有データは構造を検証してから読み込みます。正規化して更新する前に元の状態を復旧用に保存し、設定ファイルとWorking Sessionに含まれる内部情報は保持します。

## 検証範囲

隔離した実画面で、モノラル・96 kHz・751 tapsのHigh／LowをPhaseEQへ送信・返却し、内部情報だけの差ではCompositeを生成できることを確認しました。実際のAuto IIR設定変更時の生成停止と、元設定への復帰後の解除も確認しました。受信Working Sessionの同一性、画面の振幅・位相とDSP係数の一致を検査しました。

軽量品質チェックを実施します。実利用中のアプリ・編集内容・データは検証のために操作していません。実機DSPへの取込みと音響測定は今回の検証に含みません。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.21.2になったことを確認します。

操作の詳細は[利用ガイド](user-guide.md)を参照してください。
