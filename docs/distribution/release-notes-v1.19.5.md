# PhaseEQ v1.19.5 更新案内

PhaseEQ v1.19.5では、GitHub Releaseの説明を日本語の更新案内から自動作成するようにしました。Releaseページだけで、主な変更内容と前バージョンからの差分を確認できます。

## GitHub Releaseの日本語表示

- 各バージョンの配布用更新案内をGitHub Release本文にも使用します。
- 更新案内の先頭見出しは省略し、読みやすい本文として掲載します。
- 本文の末尾に、前バージョンからの変更一覧へのリンクを追加します。
- 日本語の更新説明がない場合や、更新案内の見出しとバージョンが一致しない場合は公開処理を停止します。

## 再実行時の動作

- タグ送信による自動公開と、GitHub Actionsからの手動再実行で同じ本文生成処理を使用します。
- 既存Releaseを再実行した場合も、本文を配布用更新案内の内容へ同期します。
- 配布ZIPとSHA-256ファイルを登録する従来の処理は継続します。

音響処理、DSP係数、画面操作、保存形式の仕様変更はありません。
