# PhaseEQ v1.20.31 更新案内

PhaseEQ v1.20.31では、編集対象の切替直後の音響ターゲット表示を修正し、FIRイコライザーのゲイン補正へHP／LPを追加しました。

## 追加・修正内容

- IIRイコライザーでスタンダードからHiなどのウェイへ切り替えた直後に、音響ターゲットがグラフへ反映されない問題を修正しました。EQ設定の復元後にチャンネル所有の帯域分割を確定し、その状態から計算・描画します。
- FIRイコライザーの「ゲイン」で、ハイパス／ローパスを追加できるようにしました。応答はリニアフェーズLR2／LR4、またはIIR LR2／LR4から選択できます。IIR方式は振幅と位相回転をFIR係数へ含めます。
- HPとDC正規化を組み合わせたときに通過帯域まで大きく減衰する問題を修正しました。設計ターゲットのDC振幅が数値床の−180 dB以下の場合は、DCを正規化基準に使用せず係数を保持します。
- 利用ガイドと開発仕様を更新し、設定復元の処理順序、旧設定の互換性、振幅・位相と実現FIRの検証手順を整理しました。

## HP／LPの操作

1. `FIRイコライザー`で`ゲイン`を選びます。
2. 追加項目から`ゲイン・ハイパス`または`ゲイン・ローパス`を選び、追加します。
3. `HP / LP`の編集欄で種類・応答・周波数を設定します。
4. 要求応答と実現FIRのグラフを確認します。実際の応答はタップ長・窓・EQ適用帯域の制約を受けます。

FIR出力OFFでは、このHP／LPは出力へ適用されません。既存の帯域分割へ同じHP／LPを重ねる場合は、適用する意図と合成結果を確認してください。旧設定の`LR2 (legacy)`は従来の応答を保持します。新しい応答を使用した設定は、この版以降で編集してください。

## 検証範囲

軽量品質チェックと、隔離した実ブラウザーでの確認を行いました。スタンダードとLeft Highを2回往復し、切替直後の音響ターゲットと復帰後の状態を確認しました。HP／LP各4方式は、96 kHz・2049 taps・遮断周波数1 kHzの条件で、要求グラフと実現FIRの振幅・位相を独立したLR応答と比較しました。生成FIRの数値試験では、DC正規化ON／OFFも確認しています。実機DSPへの取込・音響測定は含みません。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.20.31になったことを確認します。

操作の詳細は[利用ガイド](user-guide.md)を参照してください。
