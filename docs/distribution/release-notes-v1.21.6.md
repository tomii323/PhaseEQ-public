# PhaseEQ v1.21.6 更新案内

PhaseEQ v1.21.6では、表示モードInteractiveが再起動・再読込み後に旧Lightへ戻る経路を修正しました。v1.21.4以降のコミットと、[v1.21.5の変更](release-notes-v1.21.5.md)も含めて公開します。

## 表示モードの復元

チャンネル利用後に最新設定とStandalone退避設定の表示モードが異なる場合、設計設定はStandaloneから、共通表示モードは最新保存値から復元します。チャンネルの復元時にも現在の共通表示モードを維持します。保存形式と表示モードの既定値Lightは変更していません。

## ここまでの変更

- Auto IIRの入力整形へ手動IIRを、Auto FIR Gainの入力整形へ全IIRと手動FIR Gainを反映します。
- 出力帯域分割・書き出しへ`IIR Band Split`と`Target + Band Split`を表示します。FIR OFFでも、スピーカー＋実現応答と目標＋帯域分割の誤差を確認できます。
- C-DSP 8x12 DL向けのDirac測定用Pre APF・通常出力用Post・PEQ・チャンネル別目標振幅の専用ZIPとヘルプを追加しました。
- Multiwayの旧形式グラフデータを確定済み応答から再投影し、編集待ち設定と出力係数を保持します。関連文書も更新しました。

## 検証範囲

通常の軽量品質チェックと配布契約を確認します。表示モードの復元は、専用コピー・保存先・ブラウザー・サーバーで、再読込み、新規セッション、専用サーバー再起動でInteractiveの復元を確認しました。Lightへの切替とStandaloneの設計設定の保持も確認しました。実利用のアプリと保存データは検証操作の対象にしていません。実機DSPへの取込とDirac Live測定は未確認です。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.21.6になったことを確認します。

操作の詳細は[利用ガイド](user-guide.md)を参照してください。
