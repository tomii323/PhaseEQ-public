# PhaseEQ v1.19.20 更新案内

本書はこの版を公開した時点の変更記録です。現在の操作・設定条件は[操作ガイド](user-guide.md)、後続版の変更は[更新履歴](history.md)を参照してください。

PhaseEQ v1.19.20では、日本語・英語の画面に残っていた固定文言の翻訳漏れを修正しました。

## 主な変更

- 応答処理の操作メニューとTarget操作名を日本語表示に対応。
- 編集対象、接続状態、詳細欄の英語表示を修正。
- 測定登録・割り当ての案内、履歴、ZIP生成再試行、Multiway受信案内、テスト用メモリ診断の翻訳を追加。
- 固定UI文言の翻訳経路と表示名を検査する回帰テストを追加。

## 互換性と更新

保存された測定名・プロジェクト名・メモ・実ファイル名は翻訳せず、そのまま表示します。DSP処理、通信形式、保存値は変更していません。

編集内容を保存し、PhaseEQとMultiwayを終了して新版へ更新後、通常ランチャーから起動してください。

軽量品質チェックと関連回帰テストを実施しています。全画面の全状態を実操作で網羅した確認、フルテストは実施していません。
