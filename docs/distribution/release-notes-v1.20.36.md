# PhaseEQ v1.20.36 更新案内

PhaseEQ v1.20.36では、マルチウェイで帯域タップ長を1以上に指定し、自動クロップをOFFにした場合に、指定したタップ数の最終FIR係数枠を生成するよう修正しました。

## 修正内容

- 合成後の係数が指定長より短い場合は、中央へ配置して左右をゼロで補います。指定長より長い場合は中央を切り出し、窓ON／OFFとも指定タップ数を確保します。例えば15,231 tapsを指定すると、入力が501 tapsや1 tapでも最終係数は15,231 tapsです。
- コサインテーパー窓（α=0.10）がONの場合は、指定長の係数枠へ同じ長さの窓を直接1回適用します。1／2 tapsでは係数消失を避けるため全1窓を使用します。実係数が窓の平坦部に収まる場合は、窓ON／OFFの係数と周波数特性が一致します。
- 指定タップ長0の自動割り当てと、自動クロップONの処理は従来の動作を維持します。PhaseEQへ渡す補正用タップ長の契約も維持します。
- タップ数・Delayの明細に固定枠の追加ゼロと切り出しを表示し、Adaptive処理の表示と分けました。グラフ・保存・DSP出力は同じ検証済み最終係数を使用します。

## 検証範囲

軽量品質チェックと配布契約を検査しています。隔離したChromiumでは、96 kHz・指定15,231 tapsのNTM4／FIR LR4混在構成と、指定351 tapsのカイザー構成で、PhaseEQとの往復受渡し、窓OFF／ON／OFF復帰、描画・保存・DSP係数の一致を確認しました。指定値0と自動クロップONは回帰試験で照合しています。実機DSPと音響測定は今回の確認に含みません。機器への取込後は、係数長と実測応答を確認してください。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.20.36になったことを確認します。

操作の詳細は[利用ガイド](user-guide.md)を参照してください。
