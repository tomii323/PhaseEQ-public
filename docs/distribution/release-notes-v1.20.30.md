# PhaseEQ v1.20.30 更新案内

PhaseEQ v1.20.30では、NTM4とFIR・音響ターゲットが混在する構成の帯域分割と構造補償を修正しました。直接HP／LP、構造補償のオールパス、音響ターゲットを共通の経路選択で扱います。

## 修正内容

- 混在構成でHighに不要なHPが加わる問題を修正しました。今回確認した構成では、Highの直接HP／LPはなく、55 Hzと1 kHzのオールパスが各1段となります。2.5 kHzのLR4は音響ターゲット側に保持されます。
- 帯域分割Recipeの非適用設定とIIR定義の照合を整理し、送信・チャンネル切替時の定義不一致を修正しました。不整合なデータは引き続き適用せず、前回の状態を保持します。
- 設定読込・チャンネル切替・測定入力引継ぎの失敗時に、ボタンなどのイベント値の復元で操作を継続できなくなる問題を修正しました。

更新前に送信した内容は、編集を保存して両アプリを更新・再起動した後、マルチウェイから再送信してください。返却する補正内容と合成結果を確認してからDSP用データを出力してください。

## 文書の更新

14ページのマルチウェイ簡易操作マニュアルで、IIR／FIRの準備、補正範囲、返却と再調整の手順を整理しました。図の参照記号、番号付き手順、矢印も統一しています。開発側には、新しい帯域分割方式にも適用する共通手順と再発防止の検証条件を追加しました。

## 検証範囲

隔離環境の実画面でマルチウェイからPhaseEQへの送信と返却を行い、受信状態、HighのHP／LPの不在、55 Hzと1 kHzのオールパス、実描画データとDSP係数ファイルの一致を確認しました。確認構成は3Way+SUB／Stereo、96 kHz、55 Hz NTM4・1 kHz NTM4・2.5 kHz Linear-phase LR4 FIRで、2.5 kHzの音響ターゲットと位相構造補償の自動適用がONです。合成測定データを使用したソフトウェア検証であり、実機DSPへの取込・音響測定は含みません。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.20.30になったことを確認します。

操作の詳細は[利用ガイド](user-guide.md)、[マルチウェイ簡易操作マニュアル](manual/PhaseEQ_Multiway_QuickGuide_14p_Dark_JA.pdf)を参照してください。
