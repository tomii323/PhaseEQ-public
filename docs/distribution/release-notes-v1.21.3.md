# PhaseEQ v1.21.3 更新案内

PhaseEQ v1.21.3では、スピーカー割り当ての解除とプレビューを追加し、クロスオーバー／設計応答のGain・位相とフィルター範囲を区別しやすくしました。

## スピーカー割り当ての解除と確認

- PhaseEQの「測定一覧・使用」で、周波数応答・インピーダンスの一覧の選択とプレビューを解除できます。使用中のSpeaker周波数応答は、別の確認付き操作で割り当てを解除できます。インピーダンスは記録・プレビュー用です。
- 「マルチウェイに割り当て」で、チャンネルのSpeaker割り当てを確認後に解除できます。既存のEQ設定を保持し、解除した空入力も保存・復帰します。
- PhaseEQの「マルチウェイに割り当て」では、測定一覧で選んだ候補を右側グラフへ表示します。送信先一覧でチャンネルを選ぶと、そのチャンネルの現在入力も比較表示します。候補だけの選択でも表示でき、選択だけでは割り当てを変更しません。

マルチウェイの「3. チャンネル設定」へのスピーカー選択・新規登録・解除の操作の移設は保留中です。v1.21.3ではPhaseEQ側の操作を追加しています。

記載訂正（2026-10-21）：上記の解除対象と2つの一覧の役割を実装に合わせて訂正しました。公開済みv1.21.3のZIPは保持するため、そのZIPには訂正前の記載が残っています。v1.21.4以降の配布ZIPには、この訂正版を同梱します。

## クロスオーバー／設計応答の表示

- Gainは実線・左軸のdB、位相は破線・右軸の°で表示します。凡例に応答の取得元と数量・単位を表示し、Interactive／Lightで区別を揃えました。
- 「EQ補正」は、返送済みPhaseEQ IIR EQ、有効なPhaseEQ FIR EQ、チャンネル設定の追加IIR応答を含みます。
- Wayの設計応答は、Speaker入力とEQ補正に、Multiwayの帯域分割IIR／FIR、StudioのEQファイル合成FIR、Baffle補償、チャンネル調整などを加えた応答です。
- グラフ下の「表示するフィルターの範囲」で対象を確認できます。チャンネル設定のAdditional FIRと最終FIRのクロップ後評価は、この設計応答グラフの対象外です。最終出力はComposite Engine結果とDSP Packageで確認してください。
- 今回のグラフ変更は表示のみを対象とし、DSP計算と出力係数を維持します。

## 検証範囲

隔離した実画面で、スピーカー割り当て解除・選択プレビュー・保存復帰と、Interactive／Lightの凡例・線種・単位を確認しました。割り当て解除前後のDSP係数を照合しました。表示変更については、同一入力で6グラフ・29系列の数値を比較し、NTM4を含む返送IIRと検証用固定FIRによるDSP Packageの39ファイルが変更前後で一致することを確認しました。

実利用中の未保存セッションの出力、実機DSPへの取込みと音響測定は今回の検証に含みません。実利用中のアプリ・編集内容・データは検証のために操作していません。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.21.3になったことを確認します。

操作の詳細は[利用ガイド](user-guide.md)を参照してください。
