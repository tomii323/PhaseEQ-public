# PhaseEQ v1.20.32 更新案内

PhaseEQ v1.20.32では、FIRイコライザーのHP／LPが、マルチウェイへの返却後に編集一覧から消える問題を修正しました。

## 修正内容

- 返却済みWorking Sessionの再読込みや設定復元でも、FIR Gain EQのHP／LPを編集一覧へ復元します。種類・応答・周波数・ON/OFFと旧設定の値を保持します。
- 設定を編集一覧へ戻す共通処理を修正し、空の設定では以前のフィルターを解除する動作も確認しました。
- 保存・復元の回帰試験、マルチウェイへの返却検証、開発文書と再発防止手順を追加しました。

## 検証範囲

隔離した実ブラウザーで、HP／LPそれぞれのリニアフェーズLR2／LR4、IIR LR2／LR4をFIR化する応答の計8通りを返却しました。96 kHz・2049 taps・遮断周波数1 kHzの条件で、受信したFIRとDSP出力のfloat32係数が全件一致しました。振幅・位相グラフとの差は、共通FIR遅延を除いて最大0.00020 dB／0.00055°でした。

NTM4混在構成のHighでは直接IIRを追加せず、55 Hz／1 kHzのオールパスと2500 Hzの音響ターゲットを保持しました。返却後にFIR EQへ戻った際の編集復帰も確認しました。軽量品質チェックを実施しています。実機DSPへの取込・音響測定、他のタップ長や遮断周波数での確認は含みません。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.20.32になったことを確認します。

操作の詳細は[利用ガイド](user-guide.md)を参照してください。
