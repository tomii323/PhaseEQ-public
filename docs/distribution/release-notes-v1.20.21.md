# PhaseEQ v1.20.21 更新案内

PhaseEQ v1.20.21では、Multiwayの自動クロップを高精度なAdaptive FIR Croppingへ更新し、境界別の音響ターゲット設定と画面更新を安定化しました。PhaseEQとMultiwayのカイザー窓β値は、最大16.0まで設定できます。

## カイザー窓β値

- PhaseEQとMultiwayのカイザー窓β値の設定範囲を7.0〜16.0へ統一しました。
- 画面入力、設定読込時の補正、検証、保存・再読込で同じ共通上下限を使用します。
- β値を大きくすると一般にサイドローブ抑制が強くなる一方、遷移帯域が広がります。必要な特性とタップ数を確認して調整してください。

## Adaptive FIR Cropping

- 最終FIR全段の係数を左右端から独立に解析し、減衰、ディップ、削除エネルギー、周波数応答誤差を確認して、安全条件を満たす場合だけタップ数を短縮します。
- 左右非対称の短縮では、短い側へ必要最小限のゼロを配置して時間位置をFIR内へ保持します。適合候補がない場合は元のFIRを維持します。
- 最終FIRと同じ係数、タップ数、時間補償情報を、画面表示、Canonical DSP、Resume、出力manifestへ一貫して反映します。
- 従来の約5%刻みの中央クロップは実行経路から取り外しました。

## 境界設定と画面更新

- 各境界の分割方式と「音響ターゲットに反映」を共通状態へ統一し、High / Midを含む全境界で画面、保存設定、現在計算、PhaseEQ Assignmentが同じON/OFFを使用します。
- Auto ONでは、前回の計算時間にかかわらず設定変更を現在結果へ反映します。重い条件ではAuto OFFを案内しますが、自動的に古い結果へ固定しません。
- Fullrangeから4Way+SUBまでの全構成で、境界UIの表示数、設定保持、モード往復、現在結果への反映を確認しました。

## 旧方式の整理と出力修正

- 旧クロップの解析処理、UI内評価フロー、専用結果表、専用テスト、未使用の表示文言を現行経路から切り離しました。旧資産は復元できる隔離領域へ保存しています。
- 旧設定のクロッププロファイルと許容誤差は読み込み時に破棄し、現在の設定、Session State、出力manifestへ再保存しません。
- フィルター仕様書とZIP生成をAdaptive方式の出力項目へ合わせ、旧クロップ結果列が存在しない場合に`KeyError`で停止する問題を修正しました。
- Adaptive判定結果は、採否、元タップ数、直接クロップ後、時間位置保持用のゼロ追加後、左右の削除数、誤差、補償方式を画面と出力情報へ記録します。

操作方法は[日本語操作ガイド](user-guide.md#composite-engine)をご覧ください。画像付き操作マニュアルはv1.20.15版を継続して同梱しています。
