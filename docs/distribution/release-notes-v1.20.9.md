# PhaseEQ v1.20.9 更新案内

PhaseEQ v1.20.9では、一般向け文書と画像付き操作マニュアルを更新しました。

- 冒頭に概要・仕様を追加し、測定・設計・書き出しの役割と、音楽再生機能がないことを明記しました。
- FIR／IIR、タップ数、遅延などの基礎説明を「設計パラメーターの決め方」へ集約しました。
- 書き出し後の共通確認とアプリ内の比較例を追加しました。出力形式への対応と実機動作確認を区別しています。
- 末尾に利用条件・著作権を追加し、著作権者をTomii323と明記しました。利用・改変・再配布の許諾条件は未確定です。
- 画像付きマニュアルは12章と付録の89ページです。アプリの処理や画面操作に変更はありません。

以前の展開先へ上書きせず、新しいフォルダーへZIPを展開して使用してください。設定・データの扱いは[インストール手順](installation.md)を参照してください。
