# PhaseEQ v1.21.10 更新案内

PhaseEQ v1.21.10では、PhaseEQとマルチウェイの応答グラフの配色・線種・凡例を統一しました。予測応答の表示設定の保持と、FIR OFF時の生成判定も修正しています。

## 応答グラフの表示を統一

- 入力は青、現在の目標は橙、実現応答は緑、補正フィルターは紫、参照応答は控えめな灰色で表示します。
- ゲインは実線、位相は同じ色の破線で表示します。
- 各Wayの色は左右や並び順に依存しない固定色、全体合成は黒／白を基調とする太線で表示します。
- Light／Interactiveで日本語・英語の凡例と表示属性を揃え、多系列時も凡例を省略しないようにしました。

出力帯域分割と書き出しでは、帯域分割の振幅・位相を含む「目標＋帯域分割」を橙で表示し、元の「目標応答」は細い灰色の参照線として残します。IIR分割の位相回転は「目標＋帯域分割」で確認してください。目標編集時の編集中目標は橙で表示します。

## 予測応答の表示設定を保持

Interactiveを選んでも再表示でLightへ戻る経路を修正しました。保存済みの共通表示設定を基準に復元し、画面の初期値や古いStandalone設定で上書きしない構造へ整理しています。

## FIR OFF時の生成判定を修正

マルチウェイでFIR出力をOFFにしたとき、保持中のPhaseEQ FIR EQやAdditional FIRがあることだけを理由に計算が停止する経路を修正しました。保持したFIR編集データはOFF時の処理へ適用しません。FIR出力が必要な帯域分割を選んだ場合の構成エラーは引き続き表示します。

## ヘルプと利用ガイド

画面ヘルプ、[利用ガイド](user-guide.md)、共通表示仕様を揃え、今後のグラフ追加・変更にも同じ表示規約を適用するようにしました。同梱の画像付きPDFはv1.21.9版を継続し、今回の表示変更は画面ヘルプと利用ガイドに記載しています。

## 確認範囲

軽量品質チェックと配布契約を確認しています。隔離したブラウザーで、日英・明暗・Light／Interactiveの表示、LR2／LR4／NTM4の位相応答、表示設定の再読込み・新規ブラウザー・サーバー再起動後の保持を確認しました。NTM4混在構成ではPhaseEQとマルチウェイの往復送受信、受信Working Session、実描画データとダウンロードしたDSP係数を照合しています。

実機DSPへの取込み・再生と音響測定は今回の確認対象に含めていません。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.21.10になったことを確認します。
