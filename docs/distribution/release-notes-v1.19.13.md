# PhaseEQ v1.19.13 更新案内

本書はこの版を公開した時点の変更記録です。現在の操作・設定条件は[操作ガイド](user-guide.md)、後続版の変更は[更新履歴](history.md)を参照してください。 同梱する標準目標特性はv1.19.14、位相整合のターゲットへの適用先はv1.20.1で変更されています。

PhaseEQ v1.19.13では、測定データからマルチウェイへの受け渡し、Target編集、帯域分割、マイク測定音源の準備を改善しました。メニュー・説明文の日本語／英語切り替えにも対応しています。

## 測定データとスピーカー仕様

- スピーカー測定データを「測定一覧・使用」「測定データを登録」「測定条件・メモ」に分けました。マイク校正と任意のスピーカー仕様DBも独立したメニューになりました。
- マルチウェイのチャンネル一覧から送り先を選び、登録済み測定データをセットできます。ファイルを読み込んでDB登録とセットをまとめて行うこともできます。
- 利用したプロジェクト名を測定データのメモへ追記し、複数のプロジェクト名から同じ測定データを検索できます。
- マルチウェイChannel編集中の入力変更はチャンネルセットに統一しました。PhaseEQにも自動で読み込み、各Wayには現在の入力名と「測定データのチャンネル選択へ」を表示します。
- スピーカー仕様DBは全幅の1画面で一覧選択と編集ができます。チェックした行を読み込み、「更新」で保存します。未選択時は新規入力となり、入力内容を残しても既存データを更新しません。
- 再配布可の仕様5機種（Pioneer TS-Z172PRS／TS-Z132PRS／TS-S062PRS／TS-W252PRS、Dynaudio MD100）を同梱しました。未登録分だけ追加し、利用者の編集・アーカイブ・削除を保持します。

## Targetとレベル合わせ

- 同梱TargetはAudiofrog Target Curve・Harman H4 Target Curve・Flat Referenceの3件です。Gentle House Curveは同梱対象から外しました。

- 編集中のTargetと保存操作を整理し、現在の編集内容の新規保存、コピー元・入力ファイルに基づく名前の入力補助を追加しました。
- マルチウェイのTargetはPhaseEQ登録済みプリセットから選択します。編集はStandaloneのPhaseEQ Targetで行い、Standaloneへ帯域分割Targetを持ち込みません。
- 受信したChannel TargetはPhaseEQ側では閲覧専用です。Targetの選択保持、管理対象を選んだ際のグラフ更新も修正しました。
- 入力の自動レベル合わせでは、測定の高く平坦な帯域を優先します。手動の基準帯域指定・微調整も利用できます。
- TargetのLF／HF extension切り替えと、各EQ一覧のAll ON・All OFF・All Clearを追加しました。

## 帯域分割とマルチウェイ連携

- リニアフェーズLR4 FIRをPhaseEQ／マルチウェイへ追加しました。LR2・LR4の必要タップ数の目安と自動割当、カイザー窓の周期数・減衰スロープの案内を整えました。
- LR2／LR4の境界ごとに「音響ターゲットとして補正」を選べます。ONでは帯域分割をTargetへ反映して振幅・位相を補正し、その境界の分割フィルター自体は出力しません。位相・時間整合は出力します。
- EQマスクを帯域分割フィルター本体へ適用しないよう分離しました。出力FIRの切り詰め、音響Target補正の低域端・高域端、バッフル補正の反映を修正しました。
- Assignmentの更新検知、接続状態、Channel切り替え、返却FIRの検証を改善しました。全境界がIIR／スルーの場合の自動クロップと手動タップ長の操作も整理しました。

## マイク測定と表示

- 測定音源の配布を全15曲のZIPにまとめ、「マイク測定用音源のダウンロード」に統一しました。初回の音源準備は折り畳み表示で、測定用CDの作成手順も案内します。
- ダウンロードと一時ZIPの扱いを改善し、測定開始前に不要な転送用データを解放します。
- 設定からPhaseEQ／マルチウェイのメニューと説明文を日本語・英語に切り替えられます。作業区分の表示、画面内スクロール、移動ボタンの案内を整理しました。

## 更新と確認

1. 編集内容とDBをバックアップし、PhaseEQとマルチウェイを終了して配布ファイルを更新してください。
2. マルチウェイで使用する測定データは、各チャンネルへのセットとPhaseEQでの入力表示を確認してください。
3. 帯域分割や音響Targetを変更した後は、PhaseEQの補正結果を確認してマルチウェイへ送信してください。

軽量品質チェックと対象画面のブラウザー操作を確認しています。実機でのマイク測定・外部CD再生・音響結果の受入確認、および重い全件テストは今回のリリース検証には含みません。詳細は[操作ガイド](user-guide.md)を参照してください。
