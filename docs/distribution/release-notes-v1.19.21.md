# PhaseEQ v1.19.21 更新案内

本書はこの版を公開した時点の変更記録です。現在の操作・設定条件は[操作ガイド](user-guide.md)、後続版の変更は[更新履歴](history.md)を参照してください。

PhaseEQ v1.19.21では、表示解析の設定配置と音響ターゲット補正の初期値を変更し、測定データの送信先一覧に過去のチャンネルが混ざる問題を修正しました。

## 主な変更

- 「表示解析のFFT倍率」を「設定 → 環境設定 → 予測応答の表示設定」へ移動しました。倍率1・2・4と保存済みの値は維持します。
- LR2 FIR・LR4 FIR・LR2 IIR・LR4 IIRを選択した直後は、「音響ターゲットとして補正」をONにします。必要に応じてOFFへ変更できます。カイザー窓とスルーは常時OFFです。
- 「マルチウェイに割り当て」の送信先を、現在の帯域構成で有効なチャンネルに限定しました。過去のExchange返却入力や追加アップロード入力を送信先一覧へ含めません。
- 旧一覧から余分な行を除外するときも、同じSystem・サンプリング周波数の残るチャンネルにセット済みの測定データを保持します。元の保存データは削除しません。

## 互換性と更新

保存済みの音響ターゲット補正ON／OFFは、そのまま復元します。方式を選び直すと新しい初期値が適用されます。補正ONでは、その境界のLRカーブをPhaseEQの音響ターゲットへ合成し、Multiway側の通常の分割FIR／IIRは出力しません。

送信先一覧の修正は、過去の返却入力そのものを削除する変更ではありません。独立した追加入力として保持されている音声・フィルター資産は保持します。

編集内容を保存し、PhaseEQとマルチウェイの両方を終了して新版へ更新してください。マルチウェイで対象Systemを表示した後、PhaseEQの「送信先・受信状態を更新」を押して一覧を確認してください。

## 確認内容

軽量品質チェック、LR4方式を含む各LR方式の初期値・手動OFF・保存値保持、現在のチャンネル一覧と測定割り当ての保持、別System・別サンプリング周波数からの混入防止を検証しました。隔離したChromium画面で補正の切り替えと5チャンネルの送信先表示を確認しています。フルテストと実機音響測定は実施していません。
