# PhaseEQ v1.21.13 更新案内

PhaseEQ v1.21.13では、画像付きマニュアルの位相構造補償とリバースヌルの説明画像を見直しました。更新した詳細版と15ページ簡易版を配布ZIPに同梱しています。

## マニュアルの画像と説明

- 簡易版8ページは、同じ3Way・LR4 IIRの条件で、位相構造補償OFF／ONを比較します。ゲインと位相を4図に分け、各Wayのゲインを保ちながら位相が重なる変化を示します。
- 簡易版13ページは、2Way・LR4 IIR・1 kHzの通常合成とリバースヌルを掲載します。逆相合成の谷が見える範囲へ拡大し、灰色の破線がリバースヌルを示すことを明記しました。
- 詳細版の関連図と撮影条件を同期し、画像を確認する際の数値照合と表示確認の基準を整備しました。

## 確認範囲

隔離したChromiumで、48 kHz・Mono・全Speaker Unityの説明用データを使用しました。各Wayのゲイン不変性、補償ON時の同一周波数における位相の一致、逆相合成の谷を描画データと画像で確認しています。PDFの描画・文字数・配布物の整合性と軽量品質チェックも確認しました。

アプリのDSP処理は今回変更していません。掲載図は設計条件から計算した例です。実機DSPへの取込み、再生、音響測定は今回の確認対象に含めていません。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.21.13になったことを確認します。
