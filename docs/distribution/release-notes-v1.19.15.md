# PhaseEQ v1.19.15 更新案内

本書はこの版を公開した時点の変更記録です。現在の操作・設定条件は[操作ガイド](user-guide.md)、後続版の変更は[更新履歴](history.md)を参照してください。

PhaseEQ v1.19.15では、上部の表示を圧縮し、編集欄とグラフに使える高さを広げました。

## 画面の変更

- ナビゲーションの横幅を広げ、編集対象の見出しとChannel選択を横並びにしました。
- 単独作業／接続状態と、プロジェクト・入力情報を1行にまとめました。画面IDやメモは「詳細」から確認できます。
- マルチウェイを開くボタンと送信ボタンを、編集対象の行に配置しました。
- 文字サイズを保ち、上下の余白を減らしました。1600×1100の検証画面では編集領域の開始位置が約529pxから268pxへ上がり、下部ペインの高さは650pxから810pxへ広がりました。画面幅が狭い場合は折り返して表示します。

## 更新と確認

編集中の内容を保存し、PhaseEQとマルチウェイを終了してから更新してください。更新後にブラウザーを再読み込みしてください。

軽量品質チェックと、ブラウザーでの詳細表示・ページ切替・Elliptic数値入力を確認しています。フィルター計算や保存形式の変更はありません。
