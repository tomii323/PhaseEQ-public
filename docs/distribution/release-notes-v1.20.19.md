# PhaseEQ v1.20.19 更新案内

PhaseEQ v1.20.19では、正規ZIPを別フォルダーへ展開した場合の設定・データベースの復帰手順を追加しました。

- 両サーバーを終了し、旧フォルダーを保全してから `data` 全体をコピーする手順を説明しています。
- SQLiteの付随ファイル、ユーザープリセット、設定スナップショット、旧形式の保存先と `PHASEEQ_DATA_DIR` 指定時の扱いを記載しています。
- 復帰後の設定・DB登録内容の確認と、作業セッションZIPだけではDB全体を復元できない点を説明しています。
- 本体の動作と画面構成は変更していません。画像付き操作マニュアルはv1.20.15版を継続して同梱しています。今回の復帰手順は同梱のインストールガイドをご覧ください。
