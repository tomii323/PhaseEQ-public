# PhaseEQ v1.20.2 更新案内

PhaseEQ v1.20.2では、日本語マニュアルと関連ドキュメントを現行UI・実装に合わせて整理しました。音響処理、生成係数、保存形式、アプリの操作は変更していません。

## 主な変更

- 操作ガイドから過去の更新記録を分離し、目的別・画面別に現在の使い方を探せる構成へ整理しました。
- プログラム内の用語辞書に合わせ、画面名・操作名・音響用語を日本語に統一しました。コード識別子、ファイル名、標準略語は保持しています。
- v1.19.11〜v1.20.1の12公開版の変更を照合し、目標特性の選択・保存、未保存編集ロック、グループターゲット編集、自動レベル合わせ、表示解析FFT倍率、時間基準、標準目標特性と件数制限の説明を訂正・補完しました。
- FIR／IIRの出力、音響ターゲット補正、位相整合と極性、FIR ON／OFF、チャンネル切替の説明を整理しました。
- 開発仕様・図の注記に残っていた公開状況と旧UIの案内を修正しました。過去の実験条件・測定値は履歴として保持しています。

## リリース処理の改善

履歴の記載先を固定し、文書の版表記を明示した対象だけで同期します。準備内容を検証してから版ファイルを更新し、再実行時の履歴重複を防ぎます。GitHubの更新案内から同じ公開版の文書を開けるよう、公開本文のリンクも修正しました。

## 更新と確認

作業中の設定を保存してから両アプリを終了し、新版へ更新してください。保存データの移行やフィルターの再生成を要求する変更はありません。

軽量品質チェック、配布文書の契約、リンク・差分を確認します。PDFと画面画像の再生成、実機DSP・音響測定の再受入は今回の対象外です。
