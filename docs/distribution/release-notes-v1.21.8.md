# PhaseEQ v1.21.8 更新案内

PhaseEQ v1.21.8では、画像付きマニュアルと15ページ簡易マニュアルを読みやすく更新しました。画像付き版は簡易版と同じダーク配色へ揃え、操作図と説明を補足しています。

## マニュアルの読みやすさ

見出しの先頭を「■」に揃え、段落と図表の余白を整理しました。コンセプトと主要機能を残し、両マニュアル全体で1ページ約400文字を目安にしています。画像付き版は濃紺背景、明るい本文、シアンとゴールドを使い、表・フロー図・画像枠にも同じスタイルを適用しました。画面画像の縦横比と拡大上限を維持しています。

## 図で確認できる操作

- ターゲットカーブ編集、自動IIR、自動FIR Gain、自動FIR Phaseの役割・設定・確認を補足しました。
- 第6章：IIR EQの追加、一覧での行選択、選択項目の削除を画面図で説明しています。
- 第7章：出力帯域の構成、HP／LPの方式と周波数、音響ターゲットと最終応答の確認を説明しています。
- 第12章：マルチウェイ側で行う構成、測定割り当て、共通ターゲット、分割条件、全チャンネル送信と個別返却、合成・整合、保存・DSP出力を図解しています。

簡易版は15ページを維持し、C-DSP専用手順は紹介と詳細手順への参照を一文にまとめています。

## 同梱文書と検証

[画像付きマニュアル](manual/PhaseEQ_v1.21.8_画像付き操作マニュアル_日本語.pdf)は92ページ、[簡易マニュアル](manual/PhaseEQ_Multiway_QuickGuide_15p_Dark_JA.pdf)は15ページです。画像付き版の本文は全ページ395文字以下、簡易版は400文字以下です。画像内のUI文字はこの本文文字数に含めません。

本文・図定義・描画と配置・共通スタイルを分離して管理します。マニュアルの描画、隔離環境でのIIR追加・選択・削除、通常の軽量品質チェックと配布契約を確認しています。DSP計算・出力係数・保存形式は変更していません。実機の音響性能とDSPへの取込みは今回の検証対象外です。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.21.8になったことを確認します。

操作の詳細は[利用ガイド](user-guide.md)を参照してください。
