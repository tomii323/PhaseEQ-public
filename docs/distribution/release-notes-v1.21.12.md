# PhaseEQ v1.21.12 更新案内

PhaseEQ v1.21.12では、応答グラフの表示準備を見直し、画面切り替え時の待ち時間を短縮しました。PhaseEQ／マルチウェイの主要系列を鮮やかな共通配色へ更新しています。

## グラフの表示速度と配色

- 配色と凡例の翻訳を、完成図をキャッシュする前に適用します。同じ条件の再訪では完成図を再利用し、全データの翻訳や図の再解析を繰り返しません。
- 入力は青、目標は橙、補正後は緑、補正フィルターは紫です。暗背景では明るく、明背景では線を追える濃さの鮮やかな色を使用します。
- 元目標は控えめな灰色・細線、ゲインは実線、位相は破線を維持します。Light／Interactiveで配色・凡例・表示順を揃えています。
- Interactive設定のWeb再表示後の保持、日本語の凡例、数値応答とDSP出力の不変性を確認しました。
- 今後のグラフ追加・変更にも、共通表示属性の解決、完成図のキャッシュ、UI出力の処理順序を適用します。

## マニュアル

画像付き詳細マニュアルと15ページ簡易版の関連画面を再撮影し、新しい配色へ同期しました。両PDFを配布ZIPに同梱しています。

## 確認範囲

隔離したChromiumで、画面切り替えの修正前後の計測、明暗テーマ、日英凡例、Light／Interactive、IIR帯域分割の位相表示と設定保持を確認しました。詳細な条件と結果は開発側の検証記録に保存しています。初回起動や利用者固有の全設定で同じ速度になることは保証しません。実機DSPへの取込み、再生と音響測定は今回の確認対象に含めていません。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.21.12になったことを確認します。
