# PhaseEQ v1.20.23 更新案内

公開日: 2026-10-11

PhaseEQ v1.20.23では、Standalone／ウェイの設定復帰と未接続時のIIR表示を修正し、自動クロップON時のタップ編集を可能にしました。既存の共通FIR処理・出力表示の改善も含め、マニュアルと管理文書を整えました。

## 設定復帰と表示の修正

- Standalone／ウェイ切替の初回と繰返しで、保存した設定と入力欄を同期し、以前のプレビューが再描画を妨げないよう修正しました。切替直前のページを維持する仕様は変更していません。
- ウェイの出力後処理はMultiway管理のOFF、Standaloneは保存値へ復帰します。
- 未接続Standaloneでは、残存したStudio IIRクロスオーバーを表示・計算・書出しに使用しません。旧係数は復元用として保存し、単独の帯域分割設定とは分離します。
- 実効FIR OFFで、内部計算用プレビューFIRを出力として表示しないよう修正しました。
- 同じ対応保存形式ならアプリ版番号だけで復帰を拒否しません。破損・対応外形式の設定は元ファイルを保持し、自動保存による上書きを防ぎます。すべての旧版との互換性を保証するものではありません。

## タップ設定と共通FIR処理

- 自動クロップONでも、Standaloneの手動出力タップ数とMultiway各帯域の手動タップ長を編集できます。Standaloneでは「適用」で反映します。Multiwayの最終長は引き続きAdaptive判定で決まり、手動設定は保持します。
- Standaloneの書き出し欄で48／96／192 kHzを選択できます。ウェイ接続中は継承値を変更できません。
- Standard／Way／Compositeの最終FIR処理を共通化しました。全長合成、Adaptive範囲決定、実係数による対称拡張、テーパー、検証と出力を分離し、係数のゼロ埋めは行いません。
- 基本FIR長をAdaptiveの最小長へ渡し、タップ0・FIR EQなしでも共通の段構成で処理します。応答精度条件は維持します。
- コサインテーパーの端不足を表示し、時間原点はDSP追加Delayで保持します。最終検証に失敗した係数は出力しません。
- 同じタップ数で係数だけが変わる場合のグラフ更新、共通解析グリッド、カイザー周期数・β範囲、StandaloneのFIR LR2／LR4自動長と設定値0の表示を整えました。

## 文書と保守

- 操作ガイド・画像付きマニュアルと、設定復帰・FIR状態・UI可視性の開発管理表を更新しました。
- 未使用の旧FIR処理・専用試験を整理し、承認済みの旧隔離資産を廃却しました。利用者設定・実DBは削除していません。旧内部APIの直接利用との互換性は保証しません。
- 検証は既定の軽量品質チェックと隔離ブラウザーによる操作確認です。フルテスト・実機受入試験は実施していません。
