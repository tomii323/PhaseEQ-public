# PhaseEQ v1.19.12 更新案内

本書はこの版を公開した時点の変更記録です。現在の操作・設定条件は[操作ガイド](user-guide.md)、後続版の変更は[更新履歴](history.md)を参照してください。 単独編集・チャンネル切替時の設定引き継ぎは、v1.20.1で変更されています。

PhaseEQ v1.19.12では、マルチウェイの帯域分割・送信・初回接続を改善し、通常応答のガイド測定と測定原本の保存方式を更新しました。

## マルチウェイとの連携

- 境界ごとの帯域分割に「スルー（外部で帯域分割済み）」を追加しました。外部パッシブ／アクティブネットワーク適用後の測定では、LP／HPを追加せずに利用できます。スルー境界の構造的All-pass補償も行いません。
- PhaseEQの画面上部に送信先付き「マルチウェイへ送信」を追加しました。マルチウェイ側も画面上部に送信先・「PhaseEQへ送信」・編集画面へのリンクを集約しました。
- StandaloneのChannel候補を現在の編集構成に限定しました。古いHi／Lo候補が重複し、まだFIRを返していないChannelへの初回接続が失敗する問題を修正しました。
- Standalone／各Wayを同じセッションで切り替えられます。共通EQを引き継ぎ、移動先のSample Rate・Tap数・帯域分割を適用します。切替検証に失敗した場合は元の設定を保持します。

## ガイド測定と保存・校正

- 通常応答のガイド測定を追加しました。対応するマイク個体感度・入力Gain設定で、ノイズ確認→ESS Pilot→3件取得→統合IR保存へ進みます。標準15曲のCD版（44.1kHz／16bit）は起動時に準備します。
- 歪み・残響・相対測距のガイド解析は未対応です。従来の詳細測定画面も利用できます。
- 新しい測定原本は、統合した未校正IR 1本と別の校正データです。Library保存・Measurements JSONバックアップに含めます。録音Raw・各ショットIRは新規保存パッケージに含めません。
- Libraryで周波数校正を変更し、校正済みIR・FRDを出力できます。PhaseEQ／マルチウェイへ校正済み応答を渡す際の二重校正を防ぎました。
- マイク校正を偏差の減算へ統一しました。逆畳み込みで計算したIRの固定FFT長による切り捨ても修正しました。
- Assignment一覧の表示型混在による警告と、スライダー設定復元時の二重初期化警告を修正しました。

## 更新時の確認

1. 編集内容とLibraryをバックアップしてから、PhaseEQとマルチウェイを再起動してください。
2. スルーは、測定に外部ネットワークの帯域分割がすでに含まれている境界で選択してください。
3. 校正の符号とIR保持範囲の修正により、再計算した応答・FIRが従来版と変わる場合があります。出力前に最終特性を確認してください。
4. 旧測定データの自動移行は行いません。新原本ではGate変更は可能ですが、各ショットの再選定・録音Rawからの再解析はできません。

操作は[ユーザーガイド](user-guide.md)、保存内容は[出力ファイル仕様](output-format.md)を参照してください。
