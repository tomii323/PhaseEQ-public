# PhaseEQ v1.20.1 更新案内

本書はこの版を公開した時点の変更記録です。現在の操作・設定条件は[操作ガイド](user-guide.md)、後続版の変更は[更新履歴](history.md)を参照してください。

PhaseEQ v1.20.1では、FIR／IIRを使い分ける帯域分割と位相整合、音響ターゲット補正、マルチウェイとの接続・出力表示を改善しました。

## 主な変更

- 書き出しにFIR Output、IIR Output、FIR + IIR Outputを表示します。測定入力との合成応答・時間波形にも両者を反映し、直接出力のIIRが差分グラフで上下反転して見える問題を修正しました。
- 帯域分割のLR2／LR4 IIR、1次／2次All Pass、必要な極性をBiquadとして出力します。IIR EQと合わせたCombined IIR chainも利用できます。
- 位相・時間整合に音響ターゲット補正と位相構造補償の自動適用を追加しました。自動適用ONでは分割構成に理論All Pass配置が追従し、適用ボタンは時間整合とDelayを更新します。
- LR2自動極性補償は帯域分割側のターゲット設定に追従し、手動Polarityは独立して直接適用します。位相ターゲットON時の直接All Passの重複適用を防ぎます。
- Standaloneの書き出しに独立したFIR ON／OFFを追加しました。OFFではFIR EQ設定を保持して操作を無効にし、選択中ならIIR EQへ移動します。FIR LR2／LR4は対応するIIRへ、カイザー窓はIIR LR4へ切り替えます。
- StandaloneのLR2／LR4 IIRはFIR OFFでも音響ターゲット補正をON／OFFできます。ONにしただけで目標へ一致するわけではなく、測定を基準にIIR EQ等で調整します。
- 新しいAssignmentへの切り替えを改善し、旧プロジェクトのEQ・入力・Targetが新規Channelへ混入する問題を修正しました。連携状態の確認を「PhaseEQでチャンネルを編集」の一覧へ集約しました。
- マルチウェイの共通設定を「設定」へ集約しました。両アプリ共通のヘルプ待ち時間を追加し、初期値を2.5秒としました。
- カイザー窓βの新規初期値を12.0、標準プリセットのOverlapを0 octへ変更しました。選択中の帯域／分割構成を初期値へ戻す操作を追加し、初期化後の方式表示と計算値の不一致を修正しました。
- IIR EQのErrorで、入力未設定時にも0°を基準としてTargetとの位相差を表示します。位相データがない測定とは区別します。

## 更新時の確認

1. 編集内容を設定ファイルまたはWorking Sessionへ保存し、PhaseEQとマルチウェイを終了します。
2. 新版を展開し、通常ランチャーから両アプリを起動します。
3. 対象System／Channel、FIR ON／OFF、帯域分割方式、音響ターゲット設定を確認します。
4. マルチウェイ連携中は現在の条件でPhaseEQへ送信し、補正を確認・返却して合成応答と出力を確認します。

保存済みの明示値は維持します。旧方式の極性を含む保存データは互換動作を維持し、現在の条件で再送信すると新しい処理を使用します。FIR OFFからONへ戻しても帯域分割方式は元のFIRへ自動復帰しません。FIRとIIRは別ファイル／別段として実装し、完全な出力IIR係数に含まれる極性を重複して適用しないでください。

## 自動クロップについて

今回、自動クロップの探索仕様は変更していません。対象は帯域分割FIRにバッフル・EQファイルを合成したFIRで、帯域分割時の長さを下限に探索します。合成後も同じ長さなら短縮されません。PhaseEQから返却したFIRはこの探索に含まれません。この制約を操作ガイドへ明記しました。
