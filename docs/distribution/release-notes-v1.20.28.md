# PhaseEQ v1.20.28 更新案内

公開日: 2026-10-17

PhaseEQ v1.20.28では、NTM4 IIRクロスオーバーを追加し、位相構造補償の切替動作と利用者向け文書を更新しました。

## 主な変更

- マルチウェイとStandaloneの帯域分割に「NTM4 IIR（Biquad 2段）」を追加しました。LR4 IIRの次に選択でき、FIR出力OFFでも使用できます。
- NTM4選択時はLobe Heightを−20.0〜−80.0 dB、0.1 dB刻みで設定できます。初期値は−36.0 dBです。ノッチの位置と阻止帯域の再上昇を調整し、測定した共振位置と減衰量を見てLR4と比較してください。
- NTM4でも「音響ターゲットに反映」を使用できます。ONでは振幅・位相を目標へ反映し、その境界の直接分割段を外します。補正は手動EQや自動ゲイン・自動位相で別に設定し、帯域外の減衰まで確認してください。
- 3Way以上のNTM4を含む構成では、後段クロスの位相を補うオールパスを既存の位相構造補償から適用します。位相構造補償ON・重ね代0・追加補正なしの相補IIR構成では、複素合成振幅は理論上0 dBです。実スピーカーでは合成応答を測定して確認してください。
- 「位相構造補償を自動適用」のON／OFFが処理へ反映されない経路を修正しました。OFFで自動オールパスを解除し、手動のDelay・極性・Gainを維持します。
- LR4とNTM4の使い分け、調整手順、最終FIRとDelay、操作名を利用ガイドとヘルプへ反映しました。画像付き操作マニュアルは改訂34・98ページです。既存画像には撮影版を明記しています。

## 更新と起動

1. 編集内容を保存します。
2. PhaseEQ／マルチウェイを起動した各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.20.28になったことを確認し、使用する分割方式・Lobe Height・音響ターゲット・位相構造補償の設定を確認します。

操作の詳細は[利用ガイド](user-guide.md#lr4-ntm4-selection)と[画像付き操作マニュアル](manual/PhaseEQ_v1.20.28_画像付き操作マニュアル_日本語.pdf)を参照してください。

係数の安定性、指定Lobe Height、LP／HPの複素合成、多Wayの補償、保存とDSP出力の互換性を自動テストで確認します。画面操作は専用サーバーとデータ領域で検証し、PDFは描画と本文を確認しています。実機DSP・実スピーカーでの受入試験は今回の検証範囲に含めていません。
