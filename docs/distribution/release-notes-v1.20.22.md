# PhaseEQ v1.20.22 更新案内

PhaseEQ v1.20.22では、Multiwayの最長タップ整列とDelay計算を最終FIRへ正しく反映し、Adaptive自動クロップ、タップ数明細、コサインテーパー窓の処理順と説明を整理しました。カイザー窓の周期数目安にはβ＝15、16を追加し、カイザー帯域のテーパー保護枠はAdaptive採用結果を基準にしました。

## Standalone PhaseEQの最終出力タップ数

設定値0は「0（自動割り当て）」と表示し、解決後の実タップ数・時間とは分けて表示します。0 taps／0.00 msのFIRとしては表示しません。

- FIRタップ設定を補正用FIRの生成長ではなく、帯域分割合成後の最終出力長として扱います。正数では全長合成後に中央クロップまたは左右zero追加を行い、予測応答、個別出力、Working Session ZIPを指定タップ数へ統一します。
- `0`はFIR帯域分割またはFIR LR2／LR4音響ターゲットから仮の出力枠を自動割り当てる設定です。FIR LR2／LR4の自然長算出は音響ターゲットON／OFFのどちらでもMultiwayと共通です。Adaptive FIR Croppingは独立したON／OFFです。
- `0`に自動割り当て元がない場合もFIR ON/OFFの保存値を変更せず、チェックを保持した無効表示にします。最終出力タップ数は編集でき、正数を適用するとFIR操作が復帰します。
- コサインテーパー窓は最終フレーム確定後に1回だけ適用します。Adaptiveかつカイザー帯域分割の場合は、Adaptive結果の110%を目標とする保護枠を入力長以内で確保します。

## FIR後処理の整理

- PhaseEQとMultiwayの「FIRのナイキスト成分を除去」と除去強度を廃止しました。画面、保存・復元、FIR出力、Recipe、DSP出力から取り除き、旧データに残る設定は読み飛ばして再保存しません。
- ナイキスト周波数を上限とする通常の周波数処理、RFFT端点、測定・目標応答の制約は変更していません。

## 最長タップ整列とDelay

- 「出力タップ数を最長フィルターに揃える」のON／OFFを、生成済みFIRへ適用する出力ポリシーとして扱います。
- Adaptive自動クロップ後の最終タップ数が確定してから、各チャンネルの最長タップ整列とFIR長差Delayを1回だけ計算します。
- FIRを持つ短いチャンネルは前後へのzero追加で最長タップ数へ揃えます。FIR OFFチャンネルはzeroを追加できないため、最長FIRとの長さ差を外部Delayで補います。
- 「タップ数・Delayの明細」に、最長タップ整列のON／OFF、整列前FIRタップ数、追加zero数、保存・出力する最終FIRタップ数を追加しました。

## Adaptive自動クロップの説明

- 画面の補足説明を現行処理へ合わせ、帯域分割、PhaseEQ返却FIR、バッフル、追加EQ FIRを全長合成した最終FIRを1回だけ解析することを明記しました。
- クロップ前の最終FIRとの差が、Gain 0.05 dB以下、Phase 0.5 deg以下、Complex 0.01以下、削除Energy比1e-6以下の候補だけを採用します。
- 非対称時はzero追加で時間位置をFIR内に保持し、適合候補がない場合は元FIRを維持します。

## コサインテーパー窓

- Multiwayのコサインテーパー窓（α=0.10）は、Adaptive自動クロップと最長タップ整列の完了後、確定した最終FIRタップ枠へ1回だけ適用します。
- Adaptive自動クロップONでカイザー窓の帯域分割と併用する帯域では、カイザー設計値ではなくAdaptive採用タップ数の110%を目標に、Adaptive入力タップ数をzero追加の上限としてテーパー保護枠を確保します。バンドパスで設計目安と実際の必要長が大きく異なる場合も、採用結果に応じた余裕を確保します。
- 110%を満たす最小整数から採用FIRと同じ偶奇へ切り上げ、左右へ同数のzeroを追加してtap-centerを維持します。自動クロップOFF時は実生成したカイザー帯域分割FIR長を基準にします。
- クロップ候補や整列前FIRへ窓を重複適用しません。最終FIRグラフ、作業バックアップ、DSP出力は同じ確定係数を使用します。

## 対象帯域判定と明細表示

- カイザー境界に接する帯域を、画面上のHighからLowの表示順ではなく、LowからHighのクロスオーバー定義順で判定します。
- Adaptive FIR Cropping明細のテーパー列で数値と「—」が混在しても、Arrow変換警告が発生しない表示形式へ修正しました。
- 安全なクロップ候補がなくAdaptive結果がzero追加上限以上になった場合に、テーパー保護枠の計算で停止する問題を修正しました。この場合は安全なFIRを維持し、追加のzeroだけを省略します。
- タップ数計算、Adaptive状態、UI表示変換を分離し、表示上の型変換が計算結果や出力係数へ影響しない構成にしています。

## カイザー窓の設計目安

- PhaseEQとMultiwayの「周期数と減衰スロープの目安」にβ＝15、16の列を追加しました。
- 表は96 kHz・クロス1 kHz・重ね合わせなしで、−20～−100 dB間の平均減衰スロープを評価した設計目安です。

操作方法は[日本語操作ガイド](user-guide.md#composite-engine)をご覧ください。今回の変更はMultiwayの最終出力処理と明細表示が中心で、基本操作フローと主要画面構成は変わらないため、画像付き操作マニュアルはv1.20.15版を継続して同梱しています。
