# PhaseEQ v1.20.35 更新案内

PhaseEQ v1.20.35では、マルチウェイで帯域タップ長を1以上に指定し、自動クロップをOFFにした場合の最終FIR処理を修正しました。

## 修正内容

- 指定タップ長と生成済み係数長から範囲を確定し、中央から1回切り出します。この条件では、保護領域の拡張とアドバンスドクロップを行いません。
- コサインテーパー窓（α=0.10）がONの場合は、切り出した係数へ窓を直接1回適用します。窓がOFFの場合は、切り出した係数を使用します。生成済み係数が指定タップ長より短い場合は、その長さを使用します。
- 指定タップ長0の自動割り当て経路と、自動クロップONの処理は従来の動作を維持します。
- 方針の決定、範囲の計画、係数の処理、検証、出力の確定を分離し、グラフ・保存・DSP出力で共通の最終係数を使用します。

## 検証範囲

軽量品質チェックと配布契約の検査を実施しています。隔離したChromiumでは、PhaseEQとのタップ長の往復受渡し、窓のON／OFFとOFFへの復帰、描画された係数・窓・周波数特性と保存・DSP係数の一致を確認しました。指定タップ長0と自動クロップONの既存処理は回帰試験で照合しています。実機DSPと音響測定は今回の確認に含みません。機器への取込後は、係数長と実測応答を確認してください。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.20.35になったことを確認します。

操作の詳細は[利用ガイド](user-guide.md)を参照してください。
