# PhaseEQ v1.20.39 更新案内

PhaseEQ v1.20.39では、理想スピーカー入力を追加し、Auto IIRの低域判定とMultiwayの初期化・受信処理を整理しました。

## 追加・変更内容

- 理想スピーカー特性（0 dB／0°）を共通ライブラリへ登録し、新規入力の初期値にしました。現在のサンプルレートで応答を生成します。既存の測定データ、明示的な空入力、保存済みの選択は保持します。
- 入力状態と操作ごとの使用可否を共通化しました。理想入力の予想応答表示とMultiwayへの返送で同じ入力状態を使用し、空入力では必要な案内と操作制限を表示します。
- 入力レベルとTargetのレベル合わせを一方向に揃えました。FIR EQは確定IIRを一度適用した応答を使用し、元の入力と保存データを保持します。

## 不具合修正

- Auto IIRの入力整形で、等間隔FFT軸の低域を対数周波数間隔の欠落と判断し、20 Hz開始時に停止する経路を修正しました。IIR／FIRで有効区間の判定を共通化し、実際の欠損、NaN、対象範囲外の制限は維持します。
- MultiwayのChannel設定と編集欄を分離し、初期化・受信時に設定を確定する順序を整理しました。必須項目を空にした編集は保持し、内容が有効になるまで公開と計算を停止します。
- Multiwayの受信監視は、Workspace別の入力内容で更新を判定します。自分で作成した初期入力を変更通知とする経路を整理し、受信全体の検証・適用に成功してからChannel一覧を更新します。保存設定と設定ZIPの復帰を維持します。

## 検証範囲

軽量品質チェックと配布契約を検査しています。隔離したChromiumで、96 kHz・751 tapsの理想入力を使ったAuto IIRの20 Hz開始、空入力の保持、予想応答、Multiwayへの返送を確認しました。

Multiwayを先に起動した環境で、外部入力の受信後も名称・利得・Delay・極性を保持することと、作業ZIPの保存・読込みを確認しました。96 kHz・351 taps・3Way+SUB Stereoの往復送受信では、返送された作業セッションと描画データ・DSP係数を照合しました。

以前観測したChannel名・Groupの空欄化そのものの直接原因は未確定です。全構成での同時起動・起動遅延・競合の実画面確認、実機DSPへの取込と音響測定は今回の確認に含みません。実利用セッションは検証のために操作していません。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.20.39になったことを確認します。

操作の詳細は[利用ガイド](user-guide.md)を参照してください。
