# PhaseEQ v1.20.27 更新案内

公開日: 2026-10-16

PhaseEQ v1.20.27では、マルチウェイの計算負荷案内を修正し、利用ガイドと画像付き操作マニュアルの表記を現行UIへ揃えました。

## 主な変更

- カイザー窓の分割FIRが長くなる設定では、計算が重い場合の操作を案内します。FIR出力OFFや自動更新OFF、IIR・スルーなど、この案内の対象外となる設定では表示しません。DSPの上限は、再計算後の最終FIRタップ数で確認してください。
- 操作手順の見出しを「④ 分割方式と音響ターゲットを設定する」へ変更しました。カイザー窓の直接分割FIR、LR方式の音響ターゲット補正、スルーの使い方を区別しました。
- 画面名、入力欄、詳細表示、保存操作をUIの名称へ揃えました。旧グループターゲットのレベル調整欄の案内は、PhaseEQで目標特性を編集・保存して選択する手順へ修正しました。
- 画像付き操作マニュアルを改訂32へ更新しました。95ページのPDFは表紙に記載したv1.20.26と本版で共通の操作を説明します。画像には撮影版を明記しています。

## 更新後の確認

編集中の内容を保存し、起動元のターミナルで`Ctrl+C`を押してアプリを終了します。同じアプリフォルダーの起動スクリプトを実行し、バージョンがv1.20.27になったことを確認してください。

計算負荷案内の日英表示・設定保持は隔離したブラウザーで確認し、PDFは全ページの描画と本文を確認しました。リリース時の軽量品質チェックで配布契約と回帰試験を確認します。実機DSP・音響での受入試験は今回の検証範囲に含めていません。
