# PhaseEQ v1.20.11 更新案内

PhaseEQ v1.20.11では、本体の更新機能と、編集対象を切り替える際の操作を改善しました。

## PhaseEQ本体の更新

- 公式公開ZIPの展開先では、起動時に新しい正式Releaseを確認します。
- 「設定 → PhaseEQ本体の更新」で更新内容を確認し、「更新をダウンロードして予約」を押します。ZIP全体とファイル別のSHA-256を検証してから予約します。
- 編集内容を保存し、PhaseEQとマルチウェイのサーバーを両方終了して、起動スクリプトから再起動すると更新を適用します。ブラウザーのタブを閉じるだけでは終了しません。
- 設定・測定DB・ユーザープリセット・出力データは保持します。DBは新版で開く際に必要なテーブルや列を追加する場合があります。
- 本体ファイルの置き換え成功時に、今回と記録された前回成功分のバックアップを直ちに削除します。成功後の旧版本体は保持しません。失敗・中断時には復元用バックアップを保持します。
- バックアップ削除に失敗しても新版を維持し、ターミナルへ通知します。未完了の削除は次の更新成功時に再試行します。
- 成功判定はファイルの置き換え完了です。新版の起動やDB読み込みの成功確認は含みません。本体バックアップにユーザーDBは含まれません。
- Git管理中の開発環境、書き込みできない展開先、配布ファイル一覧のない配布物は対象外です。配布ソースに利用者の変更がある場合は更新を停止します。

詳しい操作・予約取り消しは[インストールガイド](installation.md#phaseeq本体の更新)を参照してください。

## 編集対象の切り替え

チャンネル間と単独編集への切り替えで、表示中のメニューを維持します。切り替え先で使えない場合は左側の最も近い利用可能なメニューへ移動します。FIRイコライザーからFIR OFFのチャンネルへ切り替えると、IIRイコライザーへ移動します。切り替え前の画面入力が別の編集対象へ混入することも防ぎます。

各チャンネルや単独編集のEQ設定はそれぞれ保持します。DSPの計算方式や出力形式は変更していません。[操作ガイド](user-guide.md)を参照してください。
