# PhaseEQ v1.20.14 更新案内

PhaseEQ v1.20.14では、単独編集とMultiwayチャンネルのリンク操作を整理しました。

- Stand-aloneは1チャンネルの単独編集とし、左右選択・追加チャンネル・Stereo Link操作を表示しません。
- 旧版の左右リンク付き設定を単独編集へ読み込むと、保存時に選択していたチャンネルの実効EQと入力条件を引き継ぎます。以後は1チャンネルの独立設定として編集・保存します。元の設定ファイルは変更しません。
- PhaseEQ側のリンクON/OFFと設定を、編集対象選択と同じ行の右側へ配置しました。Multiway側の配置は維持します。
- 仕様・操作ガイド・画像付きマニュアルを同期しました。

詳しくは[Stereo Linkの操作](stereo-link.md)と[操作ガイド](user-guide.md)を参照してください。
