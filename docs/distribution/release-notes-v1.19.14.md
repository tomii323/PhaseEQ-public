# PhaseEQ v1.19.14 更新案内

本書はこの版を公開した時点の変更記録です。現在の操作・設定条件は[操作ガイド](user-guide.md)、後続版の変更は[更新履歴](history.md)を参照してください。 Power V4の生成方式はv1.19.17で廃止され、現在はターゲット追従式です。

PhaseEQ v1.19.14では、Target編集、IIRフィルター、設計設定の履歴、測定条件の編集を改善しました。

## IIRフィルター

- IIR EQとTarget IIRに、可変Qの2次HP／LPとEllipticの1〜8次HP／LPを追加しました。
- Ellipticは通過域リップルと阻止域減衰を指定できます。−120 dBの阻止域は正数の120を入力します。Fcは通過域端であり、−3 dB点ではありません。
- 96 kHz、LP、2次、Fc=1000 Hz、リップル0.001 dB、阻止域減衰120 dBでは、20 kHzで約−24.45 dB／−159.92°となります。
- 次数の表示文字列が設定へ混入して落ちる問題と、条件付き入力欄の部分再描画が競合して空画面になる問題を修正しました。
- IIR Auto EQにターゲット追従の自動PEQを追加しました。既存のPower v4方式と切り替えられます。

## Target編集

- モノラルWAV（IR）を読み込めます。IRピークを時間原点として遅延を除去し、元のサンプルレートで応答へ変換します。WAVの低域・高域延長は無効です。
- 一覧選択と入力元・Gain EQ・Phase EQ・レベル調整を1画面へまとめました。未保存変更の確認、選択解除、名前の補完、詳細管理との選択共有を改善しました。
- 位相ON/OFFは入力ファイルの位相にだけ適用し、Phase EQによる調整は保持します。
- 大きなTarget一覧を再描画ごとに再解析する処理を削減しました。
- 同梱TargetからAudiofrog Target Curveを除外し、Harman H4 Target CurveとFlat Referenceの2件にしました。

## 設計履歴と測定一覧

- Standalone・Target・Multiwayへ設計設定の履歴を追加しました。自動取得は既定30分・20件で、手動保存・保護・復元にも対応します。測定入力は最新を使い、生成済みの出力係数は履歴へ保存しません。
- 「測定条件・メモ」に検索付き一覧を追加しました。1件を選んで編集・保存し、選択を引き継いで「測定一覧・使用」へ戻れます。
- 同じサーバーの稼働記録が重複した際の台数表示を修正しました。

## 更新と確認

編集中の内容を保存し、PhaseEQとマルチウェイを終了してから更新してください。更新後はフィルターの系列・次数・Q・リップル・阻止域減衰と、再生成した応答を確認してください。

軽量品質チェック、数値検証、設定復元、対象画面の操作を確認しています。重い全件テスト、実機でのマイク測定・外部CD再生・音響結果の受入確認は含みません。詳細は[操作ガイド](user-guide.md)を参照してください。
