# PhaseEQ v1.20.18 更新案内

PhaseEQ v1.20.18では、更新予約やGit管理ファイルの差分で起動前の更新処理が停止する場合への対策を追加しました。

- 同版・旧版の更新予約は、予約記録と展開済みファイルを保持して無効化します。本体を変更せず、通常の起動へ進みます。予約の取消は更新完了の判定ではありません。
- `.gitignore`・`.gitattributes`の変更は、専用フォルダーへ退避してから正規配布内容に更新します。退避した内容は更新成功後も保持します。
- その他の配布ファイルに変更がある場合は、引き続き更新を停止して保護します。旧版の更新処理が適用を止める場合は、正規ZIPを別フォルダーへ展開して起動してください。
- 操作ガイドを更新しました。画面構成は変わらないため、画像付き操作マニュアルはv1.20.15版を継続して同梱しています。

詳しい操作は[操作ガイド](user-guide.md)を参照してください。
