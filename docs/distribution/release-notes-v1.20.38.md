# PhaseEQ v1.20.38 更新案内

PhaseEQ v1.20.38では、IIR EQのNTM4とLobe Heightの編集を追加し、FIR EQの入力処理と設定復帰を整理しました。

## 追加・変更内容

- IIR EQのHP／LPにNTM4を追加しました。All Pass presetの`Match NTM4 crossover`では、同じFcとLobe HeightのNTM4に対応する位相構造補償を設定できます。`Lobe Height (dB)`は−80〜−20 dB、初期値は−36 dBです。各項目の値を保存・復帰します。
- FIR EQのスピーカー入力表示とAuto Gain／Auto Phaseで、IIR適用後の応答を使用する共通処理へ統一しました。元の測定を保持し、IIRを二重に適用しない構成にしました。
- IIR／FIR Auto EQの共通入力整形は、新規設定の「深いディップを浅くして計算」「帯域別oct平滑化」を両方ONにしました。保存済みの明示OFFと、旧FIR Recipeの再生成条件は保持します。

## 不具合修正

- 自動IIR削除やページ切替後に入力整形などの共通入力設定が以前の値へ戻る経路を修正しました。変更した設定を先に確定し、描画と保存はその設定値を使用します。自動IIR削除では手動IIRと入力整形を保持します。
- Stereo Linkの入力整形は、計算用Configと画面用設定の共有所属をFIR EQへ統一しました。IIR EQのみを共有する場合は各チャンネルの入力整形を保持します。旧データの不整合はConfigを優先して整合し、UIだけに保存された旧設定も読み込みます。リンク解除時は現在の実効設定を各チャンネルへ保持します。
- Multiwayの出力正規化は初期化元を一本化し、保存設定とチェック欄の二重初期化による警告を修正しました。

## 検証範囲

軽量品質チェックと配布契約を検査しています。隔離したChromiumでNTM4のHP／LP・All Pass preset・Lobe Heightの編集と保存復帰、FIR入力の表示と計算の照合を確認しました。設定復帰の修正は、保存データをコピーしたMain / Low・96 kHz・751 tapsで、自動IIR削除後の入力整形保持を確認しました。Stereo Linkは96 kHz・351 tapsの6チャンネルで、共有カテゴリ別の入力整形表示と保存値の一致、解除・再リンク、Standaloneの独立したIIR／FIR・入力整形・Targetの保持を確認しました。

実利用セッションは検証のために操作していません。全入力欄・全共有構成の実画面確認、15,231 taps条件の再検証、実機DSPへの取込と音響測定は今回の確認に含みません。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.20.38になったことを確認します。

操作の詳細は[利用ガイド](user-guide.md)と[Stereo Linkの手順](stereo-link.md)を参照してください。
