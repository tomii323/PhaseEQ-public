# PhaseEQ v1.20.7 更新案内

PhaseEQ v1.20.7では、現行画面に合わせた画像付き操作マニュアルを同梱し、配布内容を整理しました。

## 主な変更

- 現行日本語UIの28画像を収録した、全12章・85ページの操作マニュアルを同梱しました。
- テストプログラム、開発用スクリプト、開発文書を配布ZIPから除外しました。通常起動に必要な補助スクリプトと依存関係制約は引き続き同梱します。
- 配布文書を利用者向けに整理しました。開発手順とテスト資産はソースリポジトリに保持しています。

## 旧版からの移行

アプリの処理・設定形式は変更していません。通常どおりランチャーから起動してください。

操作は[現行の画像付き操作マニュアル](manual/PhaseEQ_v1.20.8_画像付き操作マニュアル_日本語.pdf)と[操作ガイド](user-guide.md)、導入は[インストール手順](installation.md)を参照してください。
