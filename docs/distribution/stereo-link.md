# Stereo Link：チャンネル間でEQ設定を共有する

Stereo Linkは、Multiwayの選択した複数チャンネルのEQ設定を共有する機能です。PhaseEQではリンクON/OFFと`⚙`の設定を、編集対象の選択と同じ行の右側に表示します。MultiwayではPhaseEQへ渡すチャンネルの操作付近に表示します。Stand-aloneは1チャンネルの単独編集とし、左右選択・チャンネル追加・リンク操作は表示しません。

1. チャンネルを選択し、`⚙`を開きます。
2. リンク先チャンネル、共有する設定（IIR EQ／FIR EQ・Auto EQ設定／Target設定）、設定の採用元を選びます。採用元は現在のチャンネルまたはリンク先から選べます。
3. 「選択したチャンネルへリンク」を押し、影響するチャンネルと採用元を確認します。
4. 「OK・設定を書き換える」を押すと、選択したチャンネルが同じ共有設定を編集する状態になります。キャンセル時は既存設定を保持します。

リンク中は「🔗 Stereo Link · Linked」、独立編集時は「⛓ Stereo Link · Unlinked」と表示します。共有設定はどのリンク先からも編集できます。

解除するときはStereo LinkをOFFにし、確認画面でOKを押します。その時点の共有設定を各チャンネルへ独立したコピーとして残します。解除後の変更は他のチャンネルへ反映しません。

測定、Speaker Response、IR、Delay、Polarity、Channel Gain、マイク校正、帯域分割条件、サンプルレートと各チャンネルの出力条件は共有しません。

Multiwayの設定・Working Sessionにはリンク状態を保存します。旧版のStand-alone左右リンク設定を単独編集へ読み込む場合は、保存時に選択していたチャンネルの実効EQと入力条件を引き継ぎ、1チャンネルの独立設定として編集・保存します。元の設定ファイルは変更しません。リンク情報がない従来の設定は独立設定として扱います。Multiwayのリンク中チャンネルへ従来のEQ設定を明示的に読み込んだ場合は、共有設定の編集として適用します。

Multiwayではチャンネル固有の条件と測定に基づいてFIRを作るため、リンク設定の変更後は対象チャンネルをPhaseEQで再生成し、Multiwayへ送信してください。古いEQ設定で作られた返却FIR／IIRが残っている場合は警告し、合成処理への使用を停止します。

確認中に別の画面で設定が変わった場合は、古い変更案を適用しません。キャンセルし、最新状態で改めてリンク内容を確認してください。
