# PhaseEQ v1.20.3 更新案内

PhaseEQ v1.20.3では、英語名称を説明する文書の表記を修正しました。

## 主な変更

- 英語表示名の説明と英和対応表の英語欄を、英語表記へ戻しました。操作ガイドでは、旧英語名 `Driver Profiles` と現在の英語表示 `Speaker Measurements` を区別しています。
- 旧称・内部名の引用は原名を保持し、通常の操作説明は日本語UIに合わせる方針を、文書作成規則とマニュアル作成手順に明記しました。
- 英語名称の規約と、現在の表示言語切替の説明を整理しました。

## 更新について

文書のみの修正です。アプリの動作、保存形式、音響処理、生成係数は変更していません。保存データの移行やフィルターの再生成は不要です。
