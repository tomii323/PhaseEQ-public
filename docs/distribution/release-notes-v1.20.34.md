# PhaseEQ v1.20.34 更新案内

PhaseEQ v1.20.34では、EQ入力欄の復元時に表示される、初期値とSession Stateの重複指定の警告を修正しました。

## 修正内容

- IIR EQ、FIR Gain／Phase、Auto Gain／Phaseが使う共通チェックボックスを修正しました。初期化元をSession Stateへ一本化し、ON／OFFの編集、行切替、非表示からの復帰を保持します。
- 同種のスライダーも初期化元を一本化し、表示中の入力欄へ復元値を反映します。
- 設定の復元、画面描画、編集確定の責務を保ち、個別画面で警告を抑制する処理は追加していません。保存形式とDSP係数の計算経路は変更していません。
- 前版の15ページ簡易操作マニュアルと画像付き詳細マニュアルを引き続き同梱します。

## 検証範囲

軽量品質チェックと配布契約の検査を実施しています。隔離したChromiumでは、本番の共通関数を抽出した検証画面で、行切替、ON／OFF、非表示からの復帰、復元値の反映、編集確定と警告の不在を確認しました。実利用アプリの操作、アプリ全体の往復操作、実機DSPと音響測定は今回の確認に含みません。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.20.34になったことを確認します。

操作の詳細は[利用ガイド](user-guide.md)を参照してください。
