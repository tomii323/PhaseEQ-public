# PhaseEQ v1.19.18 更新案内

本書はこの版を公開した時点の変更記録です。現在の操作・設定条件は[操作ガイド](user-guide.md)、後続版の変更は[更新履歴](history.md)を参照してください。

PhaseEQ v1.19.18では、Auto Gain FIR に最小位相の選択を追加し、Auto EQ 入力整形などの設定保持を改善しました。

## Auto Gain FIR

- 各セクションの「位相モード」で Lin／Min. Phase を選べます。既定は従来の Lin です。
- Min. Phase は振幅補正に対応する最小位相を加えます。後段の Auto Phase が ON の場合は、その位相変化を含めて補正します。
- 共通の FIR 遅延は変わりません。他の位相処理も含む出力全体が最小位相になる設定ではありません。
- 新規追加時の Smoothing は 1/12 oct です。保存済みの値と Auto Phase の初期値は維持します。

## 設定保持の修正

- 「深いディップを浅くして計算」「帯域別oct平滑化」の保存値と再表示を一致させました。
- 旧設定で UI 側に保存されていた入力整形の値を復元します。保存済み Config に明示された ON／OFF を優先します。
- 予測応答の自動更新とターゲット切り替えロックも、再表示時に保存値を反映します。
- 位相モードのない過去設定は Lin として読み込みます。既存の通信・引き継ぎ形式、処理順序は変更していません。

## 更新と確認

編集内容を保存し、PhaseEQ とマルチウェイを終了して新版へ更新後、通常ランチャーから起動してください。Min. Phase を引き継いで再生成する受取側も同じ版へ更新してください。

すでに OFF として再保存されたチェック値は、元の意図を推測して変更しません。更新後に必要な ON／OFF を選び、保存してください。

Lin の係数が変更前と一致すること、軽量品質チェック、実画面での切り替え・保存・レジュームを確認しました。フルテストは実施していません。
