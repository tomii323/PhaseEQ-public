# PhaseEQ v1.19.1 更新案内

PhaseEQ v1.19.1では、GitHub Releaseの自動作成が開始されなかった場合にも、安全に復旧・再実行できるようリリース処理を強化しました。音響設計、保存データ、DSP出力の仕様はv1.19.0から変更していません。

## 主な更新

自動公開の復旧・再実行と、配布文書の検査を強化しました。通常の操作は変わりません。GitHub ReleaseからZIPとSHA-256を取得できます。

## 互換性

v1.19.0の設定、DSP System、Target、Assignment、Resume、Exportとの互換性を維持します。今回の更新によるデータ移行はありません。
