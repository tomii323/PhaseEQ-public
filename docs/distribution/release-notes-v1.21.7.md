# PhaseEQ v1.21.7 更新案内

PhaseEQ v1.21.7では、C-DSP 8x12 DLのDirac/APF操作手順を更新しました。画面のヘルプ、受渡しZIPの`README.txt`、利用ガイドで、参照資料と担当する操作を確認できます。

## 原典とPhaseEQのサポート範囲

APF方式の実践記事とminiDSP公式マニュアルの参照箇所を追加しました。PhaseEQが行う係数生成・ターゲットカーブ出力・機器条件の検査と、機器・Dirac Live側で行う読込み・測定・補正作成・転送を分けて説明しています。記事のAPF入力先はPEQ、PhaseEQのPre/Post入力先はXoverです。

## PEQと測定入力

PEQの設計は任意です。REWなどの使用や10点すべてのPEQ設計を必須条件としていません。

- PEQを使わない場合、PhaseEQへのチャンネル別マイク測定データ入力は不要です。機器の以前のPEQを残さないため、出力された通過係数のPEQファイルを読み込みます。
- PEQを使う場合、REWなどで各チャンネルを測定し、測定結果を対応するチャンネルへ登録した上でPEQを設定します。
- Dirac Live側のマイク測定は別の工程として、PEQの有無にかかわらず実施します。

## ターゲット調整と聴き比べ

聴こえ方・曲目に合わせる微調整は、`Group Target`を調整してファイル出力し、Dirac Liveの全チャンネルへ同じターゲットカーブを読み込む手順を案内しています。

Dirac Liveとの差を比較したい場合は、各チャンネルの使用帯域内の周波数特性をPEQで整えてからDirac Liveを設定することをお勧めします。再生用Postの帯域分割・構造補償AP・PEQ・出力Delayを保持し、Dirac補正をON/OFFして聴き比べます。Dirac Liveの方式表記はメーカー資料に合わせて「混合位相補正」としています。

## 変更範囲と検証

画像付きマニュアルを改訂40として現行利用ガイドから再生成しました。15ページ簡易版はC-DSPの紹介と詳細手順の参照を一文にまとめています。関連開発文書にはPEQあり／なしの準備分岐、ZIP受渡し、機器側の測定と再生切替をフローと表で追加しました。出力仕様に残っていたFIR生成定義v4の説明も、実装済みv5と旧形式の再生成順序へ訂正しました。

係数生成、出力条件、保存形式は変更していません。通常の軽量品質チェックと配布契約を確認します。隔離ブラウザーで日英ヘルプとZIP受渡しを確認しました。実機インポート、Dirac Live測定、ON/OFF時の到達時間の実測は未検証です。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.21.7になったことを確認します。

操作の詳細は[利用ガイド](user-guide.md)を参照してください。
