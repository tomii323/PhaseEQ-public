# PhaseEQ v1.21.5 更新案内

PhaseEQ v1.21.5では、Auto EQ入力整形へ手動EQを反映し、出力帯域分割・書き出しの比較グラフと誤差表示を追加しました。

## これまでのコミットの反映

v1.21.4以降のコミットを含め、次の変更も公開します。

- C-DSP 8x12 DL向けに、Dirac測定用のPre APF・通常出力用のPost・PEQ・チャンネル別目標振幅をまとめた専用ZIPを追加しました。使用条件と取込先は専用ヘルプとZIP内の説明で確認してください。実機への取込とDirac Live測定は未確認です。
- Multiwayで旧形式のグラフデータが保持されている場合、確定済み応答から表示を再構築します。計算待ちの編集内容と出力係数は保持します。
- スピーカー割り当ての実画面検証に関する文書を更新しました。

## Auto EQ入力整形の処理順序

- Auto IIR：測定データ → 手動IIR → 入力整形 → Auto IIR。
- Auto FIR Gain：測定データ → 全IIR → 手動FIR Gain → 入力整形 → Auto FIR Gain。

測定原本は保持し、整形した応答はAuto EQの計算に使用します。Auto FIR Phaseの入力順序は今回の変更対象に含みません。旧FIR Recipeは版別の処理順序で再生成します。Auto IIRの新しい入力順序で補正し直す場合は、設定を確認してAuto IIRを再実行してください。

## 出力グラフと誤差表示

出力帯域分割・書き出しのGain／Phaseへ、次の線を追加しました。

- `IIR Band Split`：出力側のIIR帯域分割・All Pass・極性。
- `Target + Band Split`：目標応答に現在出力へ適用する帯域分割を合成した比較基準。

両ページの`Error`は、スピーカー＋実現応答と`Target + Band Split`の差を表示します。FIR OFFでもIIRのみの出力を比較できます。FIR OFFでは比較基準にFIR帯域分割を含みません。測定位相がない場合はゲインだけを表示します。

既存の出力係数をグラフと比較基準へ使用します。表示追加によるDSP係数の変更はありません。関連するヘルプと[利用ガイド](user-guide.md)も更新しました。

## 検証範囲

通常の軽量品質チェックと配布契約を確認します。隔離したChromiumではAuto EQ入力順序、IIR帯域分割と手動EQを含む出力グラフ、両ページのFIR ON→OFF→ON、描画済み応答と誤差の一致を確認しました。実機DSPへの取込・実測確認は今回の検証に含みません。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.21.5になったことを確認します。
