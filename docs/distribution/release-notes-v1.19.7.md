# PhaseEQ v1.19.7 更新案内

PhaseEQ v1.19.7では、配布ZIPを展開して初めて起動したとき、依存関係の導入前に`numpy`の読込みエラーで停止する問題を修正しました。

## 初回起動の修正

- 新規仮想環境の依存確認を、PhaseEQ本体や`numpy`を事前に読み込まず開始するようにしました。
- 不足パッケージを検出した場合は、macOS／Linux・Windowsともにオンラインインストールへ進みます。
- 不足依存関係による`pip check`の警告を、壊れた仮想環境と誤判定しないようにしました。
- 初回起動時に仮想環境を不要に二度作り直す処理を防止しました。

## 確認した起動経路

- `.venv`が存在しない配布ZIP相当の環境から、仮想環境作成、依存導入、最終import確認まで実行しました。
- 依存関係が揃っている場合に、ネットワークへ接続せず起動する従来の動作は継続します。
- Windows 11 ARMでx64 Pythonを使用する互換処理も継続します。

音響処理、DSP係数、画面操作、保存形式の仕様変更はありません。
