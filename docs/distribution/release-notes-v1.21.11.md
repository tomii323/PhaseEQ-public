# PhaseEQ v1.21.11 更新案内

PhaseEQ v1.21.11では、画像付き操作マニュアルとマルチウェイ簡易操作マニュアルを、現行の応答グラフと操作画面に合わせて更新しました。両PDFを配布ZIPへ同梱しています。

## 画像付きマニュアルを更新

- 詳細版は改訂47・98ページ、マルチウェイ簡易版は15ページです。
- 入力・目標・補正・補正後の応答・参照の役割別配色、ゲインの実線と位相の破線、太いSystem Sum、左右Wayの同色表示を説明しました。
- 出力帯域分割と書き出しでは、元の「目標応答」を灰色の参照線、「目標＋帯域分割」を橙の比較基準として区別します。IIR帯域分割の位相回転を現行画面で示しました。
- 目標編集、EQ、帯域分割、マルチウェイの関連操作画面とグラフを再撮影しました。変更のない過去の操作例には撮影版を明記しています。
- インパルス・ステップ応答の横軸説明を、現行画面のサンプル数（tap）へ合わせました。

README、[利用ガイド](user-guide.md)、配布先リンクを更新しました。今後も表示規約の変更時に、両PDFの影響する画面・凡例・本文・撮影来歴を同期します。アプリの数値処理とDSP出力は今回変更していません。

## 確認範囲

隔離環境での画面撮影、全PDFページの描画、本文・図の対応、リンク、配布契約、軽量品質チェックを確認しています。撮影用ブラウザーと専用サーバーは終了しています。実機DSPへの取込み・再生と音響測定は今回の対象に含めていません。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.21.11になったことを確認します。
