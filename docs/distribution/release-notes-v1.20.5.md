# PhaseEQ v1.20.5 更新案内

PhaseEQ v1.20.5では、マルチウェイのFIR制御、最終出力のタップ数・Delay表示、共通解析FFTの保持を改善しました。

## 主な変更

- 各チャンネルに「DCゲインを正規化」を追加しました。返却されたPhaseEQ補正FIRを設計ターゲットのDC値へ合わせ、帯域分割との合成前に適用します。初期値はOFFで、設定はSystem・履歴・作業再開データに保存します。
- DSP FIR出力OFF時は、FIR LR2をIIR LR2、FIR LR4／カイザーをIIR LR4へ切り替えます。OFF中はIIR／スルーだけを選べます。ONへ戻してもFIR方式には自動復帰しません。EQファイルの登録内容は保持し、OFF中の読み込み・合成・編集を無効にします。
- 各帯域の入力欄に最終FIRタップ数を併記し、「タップ長とディレイ目安」に保存・出力と同じ最終タップ数とDSP追加Delayを表示します。タップ数統一は合成・後処理後にゼロを追加し、FIRなしのチャンネルや偶奇の違いによる0.5 sampleの差も追加Delayで補償します。
- クロス近傍の補正前後比較を、実適用のFIR共通出力ゲインを除いた基準へ揃えました。手動Gain・極性・Delay・位相整合は比較に残します。
- 共通解析FFTをSpeaker Packageの読み込み、チャンネル・Workspace切り替え、サンプルレート変更でも維持します。設定ファイルを明示的に復元した場合は、そのファイルの値と選択表示を復元します。
- EQファイル合成、タップ数・Delayの明細、最終FIRグラフを折りたたみ欄に整理しました。PhaseEQ連携中の後処理の変更先も案内します。

## 更新時の確認

既存のDC正規化設定はOFFとして移行します。旧形式の返却FIRで設計ターゲットのDC値がない場合は正規化を適用せず、再送信を案内します。

タップ数統一を使用する設計では、更新後の最終FIRタップ数とDSP追加Delayを確認し、実機用パッケージを再出力してください。小数サンプルや負のDelayは、保存・出力欄の機種別互換性チェックで確認できます。
