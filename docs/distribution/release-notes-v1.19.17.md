# PhaseEQ v1.19.17 更新案内

本書はこの版を公開した時点の変更記録です。現在の操作・設定条件は[操作ガイド](user-guide.md)、後続版の変更は[更新履歴](history.md)を参照してください。

PhaseEQ v1.19.17では、Auto EQをターゲット追従式に統一し、深いディップへの過剰な補正を抑える計算用入力整形をIIR Auto EQと全FIR Auto Gain EQで共通利用できるようにしました。

## Auto EQ入力整形

- 「深いディップを浅くして計算」「帯域別oct平滑化」は新規・未設定時にONです。保存済みのOFF設定は保持します。
- ディップ圧縮の初期値はしきい値3 dB、圧縮比9:1、ソフトニー3 dBです。深さ12 dBの谷を約4 dBにする目安で、一律に1/3へ変える処理ではありません。
- oct幅は1/Nの分母を入力します。設定欄のヘルプで目安を確認できます。
- 整形した応答はAuto EQの計算専用です。補正後の表示、時間・位相解析、マルチウェイ合成には元の測定応答と実際のフィルターを使います。
- 両方OFFでは従来の計算を維持します。Auto Phase、手動EQ、帯域分割本体、出力ゲイン正規化は整形対象外です。
- Power V4の生成機能を削除しました。保存済みのIIRフィルターは保持します。

## 再生成・表示・動作改善

- 後段とMultiwayのFIR再生成にも同じ整形設定を引き継ぎます。新Recipeはv4です。旧Recipeの再生成と係数ハッシュ検証は維持します。
- Gain / Phase chartsは初期表示とし、説明を「グラフの見方」にまとめました。
- 測定・Target一覧の読み込みと入力データのメモリ保持量を改善しました。メモリ診断は通常UIに表示しません。
- 自動レベル合わせで高く安定した実測帯域を選ぶ代替処理を追加しました。
- Streamlitの要求版と固定依存を1.62系に揃え、起動時の依存競合を修正しました。
- PhaseEQとMultiwayの結果受け渡しを世代別保存とロックで保護し、受信失敗時は前回結果を保持します。

## 更新手順

1. 編集内容を保存し、PhaseEQとマルチウェイの両方を終了します。
2. 新版に更新し、通常のランチャーから起動します。初回は依存更新のためネット接続が必要な場合があります。
3. ブラウザーを再読み込みします。新Recipeを受け取る側も同じ版へ更新してください。

通常の軽量品質チェックと、共通生成・旧Recipe・元測定の不変性を検証しています。実機でのスピーカー歪み低減は未確認です。
