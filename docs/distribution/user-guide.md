# PhaseEQ ユーザーガイド

- 文書更新日: 2026-10-18
- 対象公開版: PhaseEQ v1.20.33
- 文書状態: 現行UIに合わせた操作ガイド

PhaseEQは、スピーカーの測定データから目標特性を決め、IIR／FIRの補正フィルターを作るアプリです。マルチウェイ画面では、各帯域の設計、チャンネルの合成、位相・時間整合、実機DSP向け出力を行います。

本書は日本語表示を基準に、現在の操作を説明します。英語名称そのものを説明する箇所では英語表記を保持し、必要に応じて日本語の意味を添えます。グラフの凡例や出力形式など、画面に英語で表示される名称はそのまま記載します。更新内容は[更新履歴](history.md)、今回の変更点は[v1.20.33 更新案内](release-notes-v1.20.33.md)にまとめています。

マルチウェイの設計からDSP出力までの手順は[簡易操作マニュアル（15ページPDF）](manual/PhaseEQ_Multiway_QuickGuide_15p_Dark_JA.pdf)にまとめています。PhaseEQの「共通設定」、マルチウェイのサイドバー「設定」から同梱PDFをダウンロードできます。

実画面と図解は[画像付き操作マニュアル（PDF）](manual/PhaseEQ_v1.20.32_画像付き操作マニュアル_日本語.pdf)で確認できます。

各章の「目的・場所・完了」を確認し、操作手順に沿って進めます。数値条件や互換性の詳細は補足・詳細資料にまとめています。

初めて使う場合は[概要・仕様](#overview-specifications)を確認してから[最短の設計手順](#basic-workflow)へ進んでください。設計前には[設計パラメーターの決め方](#design-parameters)、書き出し後には[出力データの確認と外部機器での利用](#external-use)をご覧ください。

<a id="overview-specifications"></a>
## 概要・仕様

### 本アプリの役割

PhaseEQは測定データの整理、IIR／FIR補正の設計、予測応答の解析、係数と作業状態の保存を行うアプリです。マルチウェイでは帯域ごとの設計と合成を確認できます。音楽再生機能はありません。出力係数を音楽再生に使うには、対応する外部ソフトウェアまたはDSPが必要です。測定用音源の準備やマイク収録は、音楽再生とは別の機能です。

### 対応範囲と確認先

| 項目 | 本アプリで扱う範囲 | 利用前の確認先 |
|---|---|---|
| 実行環境 | macOS・Windows・Linux向けの導入手順 | インストールガイド。全OS・全機器の組合せを実機確認した意味ではありません |
| 入力 | FRD／CSVなどの周波数応答、対応するWAV測定データ | 測定データの登録と補足4。拡張子だけで読込互換性は決まりません |
| 設計 | IIR／FIR補正、帯域分割、ゲイン・極性・遅延、マルチウェイ合成 | 各操作章と設計パラメーターの決め方 |
| 出力 | FIR係数・WAV、IIR係数／設定値、DSP用パッケージ、作業バックアップ | 出力ファイル仕様と対象機器の公式説明書 |
| 測定 | 対応入力機器によるマイク収録と解析 | マイク測定章。校正、入力機器、外部音源などの準備が別途必要です |
| 再生 | 音楽の再生・外部DSPの遠隔制御は本書の操作範囲外 | 外部ソフトウェア／機器の公式説明書 |

入力データの有効帯域を超えた補完は推定です。予測グラフは入力データと設計条件から計算した結果です。適用後は、部屋・機器を含む実測特性を確認してください。

### 機能の対象を見分ける

本文の**FIR専用**は、FIRを有効にして使う機能です。IIRのみのDSPでは、その手順は省略できます。DSPがFIRに対応していても、対象チャンネルのFIRがOFFならFIR補正は出力されません。

| 対象 | 機能・操作 |
|---|---|
| 共通：FIR／IIR | 測定入力、レベル合わせ、目標特性、予測グラフ、チャンネルゲイン・極性・遅延、保存・DSP互換性確認 |
| IIR用 | IIRイコライザーの手動フィルター・自動IIR、バイクアッド出力 |
| FIR専用 | FIRイコライザーの手動振幅・位相、自動ゲイン・自動位相、EQマスク |
| FIR専用 | タップ数、自動クロップ、コサインテーパー窓、FIR係数・窓関数表示、EQファイル合成、FIRのDC正規化 |
| FIR専用の分割方式 | リニアフェーズLR2／LR4、カイザー窓。IIRのみではIIR LR2／LR4／NTM4を使用 |

LR／NTM4境界の`音響ターゲットに反映`はFIR／IIR共通です。一方、位相・時間整合側の同名設定はONでFIR出力もONになるため、IIRのみではOFFにします。位相の確認、IIRオールパス、極性・遅延の調整までFIR専用という意味ではありません。Stereo Linkも方式にかかわらない[任意操作](#optional-stereo-link)です。

### 出力対応と実機確認の違い

出力先一覧の機器名は、その形式の係数や設定を生成するための選択肢です。全機種・全ファームウェアでの取込や実動作の確認済み一覧ではありません。確認条件の記載がない組合せは、使用前にサンプルレート、係数規約、FIR長、IIR段数、チャンネル割当を対象機器の仕様と照合してください。取込後は、設定の反映と実測応答を確認してください。推奨CPU・メモリーや全機種共通の遅延上限も、未計測の値を固定仕様として示しません。

### Standaloneとウェイ編集の使い分け

Standalone（単独編集）は入力・目標・帯域分割・出力条件をPhaseEQで設定します。ウェイ編集中は、マルチウェイが管理する項目を参照し、各ウェイのEQ補正を調整します。操作できない項目は、対応するマルチウェイ側の設定で変更します。

| 項目 | Standaloneモード | ウェイ編集中 |
|---|---|---|
| 測定入力の選択・適用 | PhaseEQで設定 | マルチウェイのチャンネルセットを使用 |
| 目標の登録・編集 | PhaseEQで設定 | 受信目標を確認。共通目標の変更は[③](#multiway-target-selection)へ |
| 出力帯域分割・プリセット | PhaseEQで設定 | 継承内容を確認。境界の変更は[④](#multiway-boundary-settings)へ |
| FIR ON／OFF・最終タップ数・自動クロップ | PhaseEQの書き出しで設定 | マルチウェイの[FIR出力設定](#multiway-fir-output-settings)で変更 |
| DC正規化・出力極性・窓・FIR自動ゲイン | PhaseEQの書き出しで設定 | マルチウェイの[後処理設定](#multiway-fir-postprocessing)で変更 |
| IIR／FIR EQ | PhaseEQで調整 | PhaseEQで調整し、マルチウェイへ返却 |

FIR専用機能の使用可否は、モードとは別にFIR ON／OFFで決まります。IIRのみのウェイではFIRイコライザーを使用しません。ウェイの基本手順は[⑤ PhaseEQで各ウェイを目標へ近づける](#multiway-phaseeq-adjustment)をご覧ください。

<a id="start"></a>
## 1. 起動する

- 目的：PhaseEQとマルチウェイを同時に起動します。
- 場所：プロジェクトフォルダーの標準ランチャーを使用します。
- 完了：ブラウザーにPhaseEQが表示され、右上からマルチウェイを開けます。

### macOS／Linuxで起動する

`run_PhaseEQ_mac_linux.sh`を実行します。依存関係を確認した後、PhaseEQとマルチウェイが起動します。

```bash
./run_PhaseEQ_mac_linux.sh
```

### Windowsで起動する

`run_PhaseEQ_windows.bat`を実行します。起動待機が完了するとブラウザーが開きます。

```bat
run_PhaseEQ_windows.bat
```

### ブラウザーを手動で開く

PhaseEQの標準URLは`http://localhost:8501`です。ポートが使用中の場合は、ランチャーに表示されたURLを開いてください。

開発時は`streamlit run phaseeq.py`でも起動できます。通常利用では、2つのアプリをまとめて管理する標準ランチャーを推奨します。

画面上の小数表示と内部計算値は精度が異なります。[補足3](#note-03)をご覧ください。

<a id="basic-workflow"></a>
## 2. 最短の設計手順

- 目的：測定データから補正係数までを一つの流れで作成します。
- 場所：`スピーカー測定データ`、`音の補正・フィルター設計`、`書き出し`を順に使用します。
- 完了：予測グラフを確認し、必要な係数と作業セッションZIPを保存します。

ここでは、REWなどで測定済みのデータから補正係数を作ります。まず1つの入力を使い、次の順に進めます。

| 順序 | 操作 | 次へ進む目安 |
|---|---|---|
| ① 入力 | 測定を登録し、`応答処理`で選択・適用する | 測定名と入力カーブが正しい |
| ② 基準合わせ | 必要な前処理を行い、入力と目標のレベルを合わせる | 補正に使う範囲と基準が決まった |
| ③ 目標 | `目標特性`でカーブを選び、編集した場合は登録・更新する | 目指すカーブを確認した |
| ④ 補正 | IIRまたはFIRで調整し、必要な帯域分割を設定する | 担当帯域とクロス付近の結果を確認した |
| ⑤ 出力 | 最終応答を確認し、係数と作業セッションZIPを保存する | 出力先の制約に収まる |

IIRとFIRを併用する場合は、IIR EQ → FIR EQの順に調整します。IIRのみならFIRの手順を省略し、FIRのみならIIRの手順を省略します。各自動補正は担当帯域に合う周波数範囲を設定してから実行し、その都度結果を確認します。

マルチウェイ編集中は[第12節の⑤](#multiway-phaseeq-adjustment)に従います。入力の割り当てと帯域条件はマルチウェイ側で変更し、各チャンネルの結果を返します。

プレビュー、適用、正式保存は異なる操作です。保存状態の違いは[補足1](#note-01)をご覧ください。

<a id="design-parameters"></a>
## 設計パラメーターの決め方

### 決める順序

まず出力先の仕様と測定入力の有効帯域を確認し、サンプルレート、FIR／IIRの構成、クロス周波数、タップ数、補正範囲、レベルの順に決めます。変化を確認しやすいよう、条件は1つずつ変更し、同じ入力・目標特性・表示条件で比較します。

| 決める項目 | 判断の基準 | 変更後の確認 |
|---|---|---|
| サンプルレート | 出力先で実際に使う値を優先。高ければ常に良いわけではありません | 出力先との一致、入力の元ナイキストより上を推定で扱っていないか |
| FIR／IIR | 出力先の対応、位相調整の目的、許容遅延、係数数の制約 | 両方使う場合の段構成と位相、群遅延 |
| クロス周波数・方式 | 各スピーカーの測定で信頼できる帯域と使用可能範囲 | 隣接帯域の位相関係と合成の山谷。スルーは外部で帯域分割済みの場合に選択 |
| タップ数 | 出力先の上限内で低域・遷移帯域・補正の精度と遅延を両立 | 最終係数長、目標との差、インパルス応答の前後の尾 |
| 補正帯域・強さ | 測定が有効な範囲から開始。深い局所的な谷を過大なBoostで埋めない | 元の入力に対する補正結果とヘッドルーム |
| ゲイン・極性・遅延 | 入力と目標の基準を合わせ、各調整の適用箇所を区別 | チャンネル合成、出力係数への反映、外部での二重適用 |

### FIR、IIR、タップ数と遅延

FIRは有限個の係数を持ち、入力sampleと係数を順番に掛け合わせて出力を作ります。直線位相FIRでは各周波数成分の時間関係を揃えやすく、奇数タップの理論中心は`(tap数 - 1) / 2` samplesです。この中心遅延は異常ではなく、DSP実装時の遅延設計に含めます。

IIRは過去の出力も計算へ戻すため、少ない係数で急な特性を作りやすく、一般にFIRより負荷と遅延を抑えられます。一方、周波数ごとの位相回転はFIRと異なります。マルチウェイは境界ごとにFIRとIIRを混在できるため、ゲインだけでなく位相、群遅延、合計遅延を確認します。

必要タップ数はサンプルレート、最低周波数、遷移帯域、補正内容で変わります。長ければ常に良いわけではありません。1023 タップを出発点に、グラフ上の不足、DSP上限、許容遅延の三つを見ながら調整します。

例えば48 kHz・1023タップの対称な直線位相FIR単段では、理論中心の遅延は511÷48000秒、約10.65 msです。これは選択の考え方を示す計算例であり、本アプリの実測値でも、出力機器全体の遅延でもありません。段の合成や追加Delay、外部機器のバッファーなどは別に考えます。

### 設定値と最終出力を区別する

マルチウェイのタップ長0や自動クロップは、固定の係数長を指定する操作ではありません。表示される最終FIR長と出力先の上限を確認します。カイザー窓の周期数・β値の詳細は「カイザー窓の使い方」をご覧ください。具体的な生成規則は各操作章に保持します。

音響ターゲットへの反映は補正目標の設定です。ONにするだけでは自動EQを実行しません。目標に近づけるには手動EQまたは明示的な自動EQを使います。

<a id="driver-profiles"></a>
## 3. スピーカー測定データ：測定データと処理プロファイルを管理する

旧英語名は`Driver Profiles`、現在の英語表示は`Speaker Measurements`です。スピーカーの測定データの確認・選択と、処理設定を含めたプロファイルの保存・復元を行います。

- 目的：スピーカー入力と応答処理結果を処理プロファイルとして保存します。
- 場所：`スピーカー測定データ > 測定一覧・使用`です。
- 完了：上部の`現在の処理プロファイル`に保存対象が表示されます。

<a id="multiway-measurement-assignment"></a>
### 測定データをマルチウェイへセットする

**同じ測定ファイルは複数のマルチウェイプロジェクトで使用できます。** 一度DBに登録した測定データは再登録不要です。マルチウェイで別のプロジェクトを開き、「送信先・受信状態を更新」を押して、そのプロジェクトのチャンネル行を選び、同じ測定データをセットしてください。割り当てはプロジェクトごとに保持され、別プロジェクトでセット・置き換えを行っても、以前のプロジェクトの割り当てには影響しません。

検索は記録されたすべての利用先プロジェクト名が対象です。例えば「リビング用2Way」と「書斎用3Way」で共有している測定データは、どちらの名前で検索しても同じ測定結果が表示されます。「リビング」「書斎」など名前の一部でも検索できます。

1. マルチウェイを開き、使用するチャンネル構成を設定します。
2. 「スピーカー測定データ」の上部メニューで **マルチウェイに割り当て** を開きます。測定一覧の選択を引き継ぎ、このページでも測定データを選び直せます。
3. **送信先チャンネル一覧表の行**を手動で選択します。一覧でチャンネル名・グループ・帯域・セット中の測定名を確認できます。左右や高域／低域の自動振り分けは行いません。
   送信先は現在の帯域構成で有効なチャンネルだけです。過去に返却されたExchange入力や追加アップロード入力は、送信先一覧に含めません。旧一覧からこれらを除外しても、残るチャンネルにセット済みの測定データは保持します。
4. **この測定データをセット**を押します。指定したチャンネルの測定応答に反映され、他チャンネルやフィルター設定は変更しません。
5. マルチウェイ画面は受け渡しを検知して再読み込みします。「送信先・受信状態を更新」で受信済みか確認できます。測定名はマルチウェイ側にも表示します。

同じプロジェクト・チャンネルをPhaseEQで編集中の場合は、受け渡し更新を検知してスピーカー入力も切り替わります。後からそのチャンネルを開いた場合も割り当てを読み込みます。他のチャンネルや単独編集の入力には適用しません。「受け渡しを保存」は保存完了を示し、開いている画面での読み込みは続いて行われます。

**マルチウェイの入力変更はチャンネルセットに統一します。** チャンネル編集中は、PhaseEQの直接適用・入力解除・登録と同時の適用・測定結果の直接適用を無効にします。ファイル登録とDB編集は可能ですが、入力へ反映するには改めてチャンネルへセットしてください。設定や処理プロファイルを読み込んでも、そのチャンネルの入力データは保持します。単独編集では従来の直接適用を利用できます。

PhaseEQの応答処理上部にある**測定データのチャンネル選択へ**から変更先へ移動できます。マルチウェイの各ウェイには現在の入力名と同じ案内を表示し、スピーカーパッケージの選び直しやスピーカーファイルの直接差し替え欄は設けません。以前から保存されている入力は保持します。PhaseEQがすでに開いている場合は、その画面の**スピーカー測定データ → 測定一覧・使用**を使ってください。

**ファイルから直接セットする場合**は「ファイルを登録してセット」でFRD／TXT／CSVを読み込み、登録名とマイク校正済みの指定を確認して、**DBに登録してチャンネルにセット**を押します。ファイルはスピーカー測定データDBにも保存され、次回から一覧で選べます。登録後に受け渡しだけが失敗した場合は、その旨を表示し、同じ画面での再試行で登録を重複させません。

**プロジェクトごとの管理**：送信先プロジェクト名を確認してセットすると、測定データDBのメモに `Multiway project: プロジェクト名` を追記します。元のメモ・測定条件は保持し、同じ名前は重複させません。別プロジェクトで再利用した場合は利用先を追加します。一覧の「マルチウェイのプロジェクト」列で確認し、検索欄にプロジェクト名を入力して絞り込んでください。

記録はセット時点の利用履歴で、プロジェクトの改名・削除には連動しません。名前のない旧版の送信先はメモを追加しないため、マルチウェイ画面を更新して再セットしてください。

送信先の構成が変わった場合は再選択してください。測定データはセット時点の内容を保持します。DBで更新したデータを使う場合は再度セットしてください。後からPhaseEQで処理した応答を返却した場合は、その新しい処理済み応答を優先します。

### 処理プロファイルを検索する

1. `検索`へ名称、スピーカー、左右、測定位置、タグ、メモを入力します。
2. `並べ替え`と`降順`で並び順を選びます。
3. アーカイブ済みも確認する場合は`アーカイブ`をONにします。
4. 一覧の行を選択します。

行の選択だけでは現在の編集状態は変わりません。`選択項目を読み込む`を押すと、選択した入力プロファイルを現在の作業へ復元します。

### 処理プロファイルを新規保存する

1. `応答処理`で入力処理を完了します。
2. `処理プロファイル名`、`スピーカー`、`左右`、`測定位置`を入力します。
3. 必要に応じて`タグ`と`メモ`を入力します。
4. `保存して完了`の新規保存操作を実行します。

保存後は入力の改訂番号が更新されます。目標特性、EQ、FIR、マルチウェイの合成設定は処理プロファイルの保存対象ではありません。

### 処理プロファイルを複製・整理する

- `複製`は選択中のProfileを別IDで複製します。
- `アーカイブ`は通常一覧から外します。データを即時消去する操作ではありません。
- `現在の入力測定データ`は、現在選択中の候補と適用済み測定を区別して表示します。

保存データの境界は[補足2](#note-02)をご覧ください。

<a id="measurements"></a>
## 4. 測定データの登録・条件編集

- 目的：外部ソフトで測定したデータを登録します。
- 場所：`スピーカー測定データ`です。
- 完了：登録名とカーブを確認し、補正入力に使える状態にします。

### 測定データを登録

1. **スピーカー測定データ → 測定データを登録**を開きます。
2. スピーカー測定またはインピーダンスを選び、ファイルを指定します。
3. 登録名・メーカー・型番を必要に応じて入力します。マイク校正済みならチェックを付けます。
4. **登録のみ**、またはスピーカー測定の**登録して応答処理で使う**を押します。

周波数応答はFRD、TXT、CSV、mono WAVに対応します。形式の詳細は[補足4](#note-04)をご覧ください。近接ウーファー・ポート測定は任意欄へ追加できます。現在の入力を保存する場合は、**現在の入力・近接測定をまとめて登録**を開きます。

### 測定一覧・使用

登録済みデータは**測定一覧・使用**に集約します。測定名、メモ、どの利用先プロジェクト名からも検索できます。行を選択するとプレビューし、**応答処理で使う**またはマルチウェイへのセットで使用します。インピーダンスや左右合成の確認用測定は補正入力として使用できません。

### 測定条件・メモ

1. **測定条件・メモ**を開き、一覧で編集したい測定を1件チェックします。検索も利用できます。測定一覧・使用や登録直後のボタンから移動した場合は、その選択を引き継ぎます。
2. 上部の**編集中の測定**を確認します。
3. メモ、測定名、日付、距離、角度を入力します。その他の測定条件は折り畳み欄で編集します。
4. **変更を保存**を押します。
5. 別の測定を編集する場合は保存後に一覧で選び直します。**測定一覧・使用へ戻る**を押すと、選択した測定を引き継いで戻ります。

既存レコードの条件だけを更新し、測定カーブ・校正情報・原本は変更しません。利用先プロジェクトは別枠で表示し、メモを編集しても履歴を保持します。仕様との関連付けは任意です。関連付けた仕様は**関連付けた仕様へ**から確認できます。

### マイク校正

上部の独立した**マイク校正**を開きます。**校正データ一覧・登録**では校正ファイルを登録・選択し、**マイクプロファイル**では対応機種と個体を確認して個体番号・校正ファイルを登録します。

### スピーカー仕様データベース（任意）

上部の独立した**スピーカー仕様データベース（任意）**を開きます。測定ファイルの登録・使用には不要です。

配布版にはPioneer TS-Z172PRS・TS-Z132PRS・TS-S062PRS・TS-W252PRSとDynaudio MD100の仕様を同梱します。仕様DBを開くと未登録の機種だけを追加します。既存の編集内容を上書きせず、アーカイブ・削除した同梱データも再追加しません。

この画面では右側の応答グラフを非表示にし、一覧・編集を画面幅いっぱいに表示します。仕様値は「基本性能」「T/Sパラメーター」「外形・取付寸法」にまとめています。

- **新規登録**：`新規入力`で空の入力欄に切り替え、手入力・Webからの取得・テキスト取込で内容を整え、`新規登録`で追加します。
- **既存の編集**：一覧表の行を選ぶと下の入力欄へ自動で読み込みます。`更新対象`を確認し、変更後に`更新`を押します。
一覧の選択を解除した場合や検索で選択行が表示対象外になった場合は、新規入力に切り替わります。入力内容は残りますが、既存データは更新できません。更新するには一覧から対象を選び直してください。

- **コピーして登録**：`選択した仕様をコピーして新規入力`で内容を引き継ぎ、確認・編集後に`新規登録`を押します。元の仕様は変更しません。

既存の仕様DBと測定との関連付けは維持します。測定データ JSONなどの移行・保全は**設定 → バックアップと復元**で行います。

### AI用入力支援を使う

`仕様抽出用AIプロンプト`は、仕様表を構造化するための補助機能です。生成結果は必ず内容を確認し、メーカーが空の候補をそのまま保存しないでください。[補足51](#note-51)も参照してください。

<a id="response-processing"></a>
## 5. 応答処理：補正入力を準備する

- 目的：測定データを選び、補正設計へ渡すスピーカー入力を作成します。
- 場所：`音の補正・フィルター設計 > 応答処理`です。
- 完了：右側予測グラフに処理済みスピーカー入力が表示されます。

### 入力元：測定を選ぶ（Standaloneモード）

ウェイの入力変更は[測定データのチャンネルセット](#multiway-measurement-assignment)で行います。以下はStandaloneでの直接適用の手順です。レベル合わせ・タイミング・入力処理は、ウェイ編集中も使用します。

1. `入力元`を選びます。
2. 使用するスピーカー測定の行を選びます。
3. `選択項目を適用`を押します。
4. マイク校正を使う場合は同様に選びます。
5. 未校正スピーカー入力へ校正する場合は`マイク校正を適用`をONにします。校正データはマイク偏差として減算します。校正済み測定応答には再適用しません。

一覧行の選択はプレビューです。現在入力を解除する場合は`現在の設定を解除`を使います。DBレコード自体は削除されません。

### タイミング：極性と位相中心を設定する

1. `タイミング`を選びます。
2. 必要な場合だけ`中心合わせ前に反転`をONにします。
3. `位相のセンタリング`の`有効`を確認します。
4. `ピークモード`を選びます。
5. 必要な場合だけ`手動オフセット ms`を調整します。

通常は`絶対値ピーク`を基準にします。入力位相が不安定な場合は`位相の扱い`を変更します。[補足5](#note-05)も参照してください。

### マルチウェイへ渡す時間基準

共通時間基準が「未確認」の場合は、同じマイク位置からの外部測定距離など、利用できる時間基準を確認してください。応答処理の手動時間オフセットは入力の時間原点を動かす操作です。マルチウェイで意図的に遅らせる場合は、チャンネルの遅延設定を使います。

位相データがない測定ではゲインを確認できますが、実測位相に基づく合成・時間評価には使用できません。受信データの応答と時間情報の検証に失敗した場合は、前回の結果を保持します。

### 入力処理：帯域外を補完する

新規設定では低域・高域の補完はONです。保存済みの明示的なOFFは維持します。補完をONにすると、測定範囲外を推定して補正計算へ渡します。低域は2 Hzまで、高域は測定上限から不足する範囲を滑らかに延長します。測定済みの20 kHz以上のデータは保持します。

補完を変更すると自動 EQと生成FIRも変わる場合があります。帯域外は実測ではないため、補完部分だけを根拠に大きな補正を加えないでください。OFFでもグラフ表示専用の補完は行います。[補足6](#note-06)も参照してください。

### 入力処理：スムージングを設定する

1. `処理方式 > スムージング`を選びます。
2. `スピーカー入力の平滑化`で分解能を選びます。
3. スムージングを使う場合はmodeを選びます。

スムージングは帯域補完後、ゲインシフト前に適用されます。細かい測定の凹凸に補正が追従しすぎることを抑えます。

### 入力処理：ゲインシフトを設定する

1. `処理方式 > ゲインシフト`を選びます。
2. `モード`で自動または手動方式を選びます。
3. `手動シフト dB`で差分を調整します。

自動は主帯域を使ってスピーカー入力の基準レベルを整えます。低域ノイズを避ける判定条件は[補足7](#note-07)をご覧ください。

<a id="target"></a>
## 6. 目標特性：目標応答を設定する

この節の登録・編集・保存はStandaloneモード向けです。ウェイ編集中は受信した目標を確認し、共通目標の変更はマルチウェイの[③](#multiway-target-selection)、補正は[⑤](#multiway-phaseeq-adjustment)で行います。

- 目的：補正後に目指すゲイン／位相応答を定義します。
- 場所：`音の補正・フィルター設計 > 目標特性`です。
- 完了：右側の目標応答を確認し、上部の保存ボタンで登録します。

### 目標特性の選択・編集・保存（Standaloneモード）

1. `登録・編集`で、使う目標特性を選びます。新しく作る場合は一覧の選択を解除します。
2. 入力元、ゲインEQ、位相EQ、レベルを必要に応じて調整します。
3. `編集中`の名前とグラフを確認します。
4. 自分の目標特性は`新規登録`または`更新`で保存します。標準目標特性は`コピーして新規登録`を使います。
5. `保存済み`の表示を確認します。

**グラフの更新と、登録内容の保存は別の操作です。** 自動表示更新がOFFなら再計算します。編集した内容を再利用するには登録・更新が必要です。

#### グラフで確認する線

表示モードによって凡例が英語になる場合があります。下記の括弧内は対応する英語名です。

- `選択したTarget（登録済み）`（Selected Target）：一覧で選んだ登録済みカーブ。
- `編集中のTarget（保存対象）`（Edited Target (saved response)）：編集中の保存対象。
- `目標応答`（Target Response）：帯域分割の音響ターゲットなどを加えた設計用目標。

目標特性の応答ファイルには、編集した目標自体を保存します。音響ターゲットの追加成分は含めません。作業セッションZIPの設定には帯域分割条件も保存します。

#### Standalone：出力帯域分割を目標特性へ反映する

Standalone（単独編集）では、元の目標特性にHP／LPの分割カーブを加え、担当帯域の音響ターゲットを設定できます。例えば低域用にはLP、高域用にはHP、中域用にはHPとLPを使います。

1. `目標特性`で、元になるターゲットカーブを選択・編集します。
2. `出力帯域分割ページ`へ移動し、必要なHP／LPを有効にして、方式とクロス周波数を設定します。
3. リニアフェーズLR2／LR4またはIIRのLR2／LR4／NTM4では、各側の`音響ターゲットに反映`をONにする手順を基本とします。カイザー窓とスルーでは使用できません。
4. `目標特性`へ戻り、`目標応答`（Target Response）の振幅・位相を確認します。ONにした側の分割カーブが、元の目標特性へ合成されます。リニアフェーズ方式は振幅を反映し、IIR方式は振幅と位相を反映します。
5. 測定入力と設計用目標を確認し、IIR／FIR EQで補正します。FIR対応DSPでは自動ゲインと必要な自動位相を設定します。IIRのみのDSPではIIRイコライザーで調整します。

| 設定 | 設計用目標（Target Response） | 同じ側の直接分割段 |
|---|---|---|
| ON | 元の目標特性にHP／LPの分割カーブを合成 | 出力へ追加しない |
| OFF | その側の分割カーブを目標へ合成しない | 選択した分割FIR／IIRを出力へ適用 |

**ONは目標を設定する操作であり、自動EQの実行ではありません。** 目標へ近づけるには補正の設定と結果の確認が必要です。ONにした側の分割段をDSP側で重ねて追加しないよう、最終出力を確認します。元の目標特性の保存と、帯域分割条件を含む作業セッションZIPの保存は分けて行います。

帯域分割の詳細は[「高域 / 低域 音響ターゲットに反映」とは](#acoustic-target-behavior)をご覧ください。マルチウェイ編集中の境界設定はマルチウェイ側で変更します。

名前の自動入力や複製などの詳細は[目標特性の保存・管理の詳細](#phaseeq-detail-target)をご覧ください。

### 標準の目標特性

同梱する標準目標特性は「Harman H4 Target Curve」と「Flat Reference」の2件です。以前の版に同梱されていた目標特性や、利用者が保存した目標特性を、更新時に一括削除するものではありません。標準目標特性を変更したい場合はコピーして登録します。

### ターゲット元：入力元を選ぶ

1. `登録・編集`の入力元欄を開きます。
2. FRD／TXT／CSV、REWターゲットカーブ、Dirac Live targetcurve、モノラルWAVのIR、URLから入力します。
3. `ゲイン＋位相`または`ゲインのみ`を選びます。
4. 変換後の目標カーブを確認します。

`ゲインのみ`は元ファイルの位相を使いません。目標編集で追加した位相EQは別に適用します。[補足10](#note-10)も参照してください。

WAVは元のサンプルレートで振幅・位相へ変換し、IRピークを時間原点にします。低域の延長は使えません。高域を延長した部分は推定であり、元WAVの実応答ではありません。

スピーカーとの差分を補正する場合は、先に測定を適用します。入力なしで目標単独のFIRを作る場合とは区別してください。WAVの延長・保存条件は[入力形式の詳細](#phaseeq-detail-input)をご覧ください。

### 目標特性レベル：基準レベルを合わせる

1. `Targetレベル`を選びます。
2. 自動または手動のレベル方式を選びます。
3. 必要に応じて手動シフトを調整します。

スピーカー入力がSPL基準、目標特性が0 dB基準の場合は自動を使用します。目標特性線とスピーカー入力の相対位置を予測グラフで確認してください。

### ターゲット編集：ゲイン／位相を編集する

1. `ターゲット編集`を選びます。
2. `ゲイン`または`位相`を選びます。
3. PEQ、Shelf、チルト、オールパスなど必要な項目を追加します。
4. 各項目のON／OFFと値を確認します。
5. 必要に応じて下部の「新規登録」または「更新」で登録内容を保存します。

グループターゲットは合成結果の比較基準です。受信したチャンネル目標は閲覧専用です。共通目標を変えたら、マルチウェイから再送信してください。[補足34](#note-34)も参照してください。

### 目標特性設定を保存・復元する

`ファイル`で目標特性設定を保存できます。復元時は`目標特性設定を復元`を実行し、目標特性名と編集内容を確認してください。

### ターゲット選択時の編集ロック

設定画面の「ターゲットの選択」で「未保存の編集があるとき、ターゲットの切り替えをロック」を変更できます。既定はOFFです。ONにすると、未保存の編集があるときは保存・破棄・キャンセルを確認します。OFFでは選択先へ直ちに切り替え、未保存の編集を破棄します。登録済みターゲットは変更しません。確認待ちの途中でOFFにした場合は保留中の選択を取り消します。移動したいターゲットを再選択してください。設定は次回起動時にも復元されます。


<a id="iir-eq"></a>
## 7. IIRイコライザー：バイクアッド補正を作成する

IIR／FIRの通常EQ数値は、矢印キーで連続変更できます。入力中は直前のグラフを保ち、入力を止めると最新値で更新します。更新開始まで約0.2～0.3秒、その後に計算時間がかかります。単発変更も同じ動作です。終了前には更新完了を待ってください。自動 EQや連動する設定など、一部の項目は従来どおり都度更新します。

- 目的：スピーカー入力へIIR ゲイン／位相補正を適用します。
- 場所：`音の補正・フィルター設計 > IIRイコライザー`です。
- 完了：右側のIIRイコライザー結果と合成Biquad出力を確認します。

### 一覧の件数と編集

EQ編集リストの追加・複製は種類ごとに128件までです。上限を超える保存済み設定を読み込んでも削除しませんが、さらに件数を増やす操作はできません。測定などのデータベース候補は8,192件ずつ表示し、ページを切り替えて選びます。データベースの総保存件数を制限する値ではありません。

### 手動IIRを編集する

1. `ゲイン`または`位相`を選びます。
2. PEQ、Shelf、オールパスなど必要な項目を追加します。
3. 周波数指定、ゲイン／位相、Qを設定します。
4. 各項目のON／OFFを確認します。

IIRはスピーカー入力の後段へ直列適用されます。IIR係数はFIRフィルターへ畳み込まず、別のバイクアッド出力として保持します。

HP／LPは必要な分割を用意するとき、PEQ／Shelfは振幅の山谷を整えるときに使います。位相調整には対応するオールパスを使います。調整後は、振幅・位相とヘッドルームを確認します。

Variable-Q、Ellipticの設定条件と数値例は[フィルター系列の詳細](#phaseeq-detail-iir)をご覧ください。

### 自動IIRを生成する

自動IIRは、入力と目標の振幅差をPEQで小さくします。「音響ターゲットに反映」ONで分割スロープを補正する場合は、先に必要なHP／LPを手動で用意します。周波数と傾きを調節して目標へ近づけた後、残る振幅差を自動EQで整えます。測定や既存フィルターに同じ減衰が含まれる場合は、重複追加を避けます。

1. 入力と目標を選び、基準レベルを合わせます。自動IIRはレベルを自動正規化しません。
2. 補正範囲と最大フィルター数を指定します。測定と目標の有効範囲内にします。
3. ブースト、カット、Q、ヘッドルームの上限を設定します。初期値はブースト6 dB、カット12 dB、最大Q 5.0です。
4. `自動 EQ用の入力整形`で「深いディップを浅くして計算」「帯域別oct平滑化」をONにし、深い谷や高域の細かな変動へ過度に追従しない設定を確認します。初期値と同じ場合は数値の変更は不要です。保存済みのOFF設定は自動ではONになりません。
5. `IIR自動調整を実行`を押します。再生成する場合は、先に`自動IIRを削除`で自動生成分を消します。手動IIRは残ります。
6. 補正前後のグラフ、振幅誤差RMS、最大ゲインを確認します。生成したPEQは一覧で編集できます。

**ブースト上限0 dBなら、カットだけで補正します。** 手動IIRだけでヘッドルームを超えても、手動値は変更されません。最終ゲインを必ず確認してください。

#### 入力整形は必要な場合だけ調整する

深い谷を浅くした計算用入力や、帯域別の平滑化を使えます。元の測定と目標は変更しません。計算用入力は破線、補正後の線は元測定に実フィルターを適用した結果です。

入力整形はFIR自動ゲインと共通です。IIRでは設定変更だけで生成済みEQは変わらないため、削除して再実行します。FIRでは次の再計算時に反映します。

`設定を初期値に戻す`は生成条件だけを戻します。生成済みフィルター、入力、目標、チャンネルは変更しません。

旧フィルターの扱い、平滑化の初期値、計算条件は[自動IIRの詳細](#phaseeq-detail-auto-iir)をご覧ください。

### 合成Biquad出力を確認する

ゲインと位相の全IIRを適用順のまま出力します。書き出し前にFilter数、安全補正、係数形式を確認してください。[補足11](#note-11)も参照してください。

<a id="fir-eq"></a>
## 8. FIRイコライザー：FIR補正を作成する（FIR専用）

- 目的：ゲイン／位相の手動補正と自動補正からFIRを生成します。
- 場所：`音の補正・フィルター設計 > FIRイコライザー`です。
- 完了：右側の予測応答で選択段階までの応答を確認します。

### 振幅フィルターを編集する（FIR専用）

1. `ゲイン`を選びます。
2. PEQ／Shelf、HP／LP、チルトのグループを選びます。
3. Filterを追加し、周波数指定、Q、ゲインを設定します。
4. ONになっているFilter数を確認します。

一覧の行選択は編集対象だけを切り替えます。ON/OFFや周波数指定・Q・ゲインは変更しません。ONチェックを明示的に外すと、そのFilterはOFFとして保存されます。以前の不具合で既にOFFや別の数値として保存された設定は自動修復しないため、必要に応じて一覧と編集欄を確認してください。

### HP／LPを追加する（FIR専用）

1. `ゲイン`の追加項目から`ゲイン・ハイパス`または`ゲイン・ローパス`を選び、追加します。
2. `HP / LP`の編集欄で種類、応答、周波数を設定します。
3. 応答はリニアフェーズLR2／LR4、またはIIR LR2／LR4から選びます。IIR方式は振幅と位相回転をFIRへ反映します。
4. 予測グラフと実現FIRの応答を確認します。低い周波数や急な減衰では、タップ長・窓・EQ適用帯域によって要求応答との差が増える場合があります。

HP／LPはFIR係数へ含まれます。FIR出力OFFでは適用されません。帯域分割に同じHP／LPがある場合は、重ねて適用する意図があるか確認してください。旧設定の`LR2 (legacy)`は従来の応答を保持します。

### 位相フィルターを編集する（FIR専用）

1. `位相`を選びます。
2. PEQ／Shelf／オールパスまたはチルトを選びます。
3. 周波数指定、Q、位相などを設定します。
4. ゲインマスク内の位相変化を確認します。

### 自動ゲインのセクションを設定する（FIR専用）

IIR併用時はIIRを先に確定します。「音響ターゲットに反映」ONで分割スロープを補正する場合は、必要なHP／LPを追加し、周波数・応答を調節して目標スロープへ近づけます。IIRや外部ネットワーク、既存FIRで同じ減衰を用意済みなら、重ねて追加しません。

新規追加時のスムージングは `1/12 oct` です。保存済み設定・レジュームでは保存された値を使い、自動位相の初期値は変更しません。

各セクションの「位相モード」で `Lin`（既定）／`Min. Phase` を選択できます。Lin は従来の振幅補正を維持し、Min. Phase はその補正に対応する最小位相を加えます。振幅補正の計算・平滑化・制限は共通です。Lin と Min が隣接する場合も既存の境界処理を使って Min の補正成分を接続します。最小位相は範囲外にも位相変化を伴います。

後段の自動位相がON の場合はその位相変化を含めて補正します。FIR 全体の共通遅延や帯域分割、書き出し時のゲイン正規化は変わりません。ほかの位相処理との合成後の FIR 全体が最小位相になることを保証する設定ではありません。

選択は既存の設定保存・レジューム・マルチウェイ 引き継ぎ経路で保持します。位相モードを持たない過去の設定ファイルは Lin として読み込みます。音響ターゲットがONでも、設定した自動ゲイン／自動位相の範囲・方式を使用します。

1. `FIRイコライザー`の`ゲイン`で、追加メニューの`Auto Gain · Section`（自動ゲイン）を追加します。
2. 担当帯域に合う開始周波数と終了周波数、補正量を設定してからONにします。終了条件で周波数を指定する場合は「周波数指定」を選び、測定が信頼できる範囲にします。
3. `Auto EQ用の入力整形`で「深いディップを浅くして計算」「帯域別oct平滑化」をONにし、深い谷や高域の細かな変動へ過度に追従しない設定を確認します。初期値と同じ場合は詳細数値の変更は不要です。保存済みのOFF設定は保持されるため、使用時に確認します。
4. 予測応答の自動更新がOFFの場合は「更新」を押し、計算用入力と元測定からの補正後応答を確認します。FIR自動ゲインの再計算に、自動IIRの削除は不要です。
5. マルチウェイ編集中は「マルチウェイへ送信」で反映します。マルチウェイも同じ入力整形設定でFIRを再生成します。

入力整形は全自動ゲインに共通で、IIR 自動 EQ側の設定とも連動します。各フィルターのスムージング・補正量制限・境界処理はその後に適用されます。圧縮とoct幅の詳しい目安は前章の「自動 EQ用の入力整形」をご覧ください。

整形済みの応答は計算専用です。後段の振幅・位相・時間解析には元測定と実フィルターを使用します。両方OFFでは従来の計算を維持します。出力時の全体ゲイン正規化としての自動ゲインとは別機能です。

### 自動位相のセクションを設定する（FIR専用）

1. `FIRイコライザー`の`位相`で、追加メニューの`Auto Phase · Section`（自動位相）を追加します。
2. 実測位相と時間基準を確認し、信頼できる開始・終了周波数、方式、スムージングを設定します。終了条件で周波数を指定する場合は「周波数指定」を選びます。
3. 周波数範囲を確認してからONにし、自動更新がOFFなら「更新」を押します。
4. 位相ターゲットとの差、群遅延、インパルス応答を確認します。

ゲイン・位相はそれぞれのターゲットカーブに合わせて調整します。自動補正の後も、手動のゲイン／位相フィルターで調節できます。IIRや前段のゲイン補正を変更したら、FIRのゲイン・位相を再計算して確認します。

自動ゲイン／自動位相は確定済み係数を保存する機能ではありません。スピーカー、目標特性、区間、スムージング、タップ条件から再計算します。[補足12](#note-12)をご覧ください。

### マルチウェイの割り当て中のFIRを確認する

割り当てのタップ数が0の場合はFIR OFFです。FIRイコライザー設定を内部に保持したまま操作を無効にし、FIRイコライザーを選択中ならIIRイコライザーへ移動します。FIRの適用と係数出力は行いません。

割り当てが有効な場合、サンプルレートとタップ数はマルチウェイのチャンネル条件へ合わせます。PhaseEQ側で帯域分割条件を変更することはできません。

<a id="output-band-split"></a>
## 9. 出力帯域分割ページ：出力帯域を分割する

この節の設定・プリセット操作はStandaloneモード向けです。ウェイ編集中は継承した帯域分割を確認します。変更はマルチウェイの[④](#multiway-boundary-settings)で行い、PhaseEQへ再送信します。

- 目的：単独PhaseEQ出力のFIRフィルターまたはIIR クロスを設定します。
- 場所：`音の補正・フィルター設計 > 出力帯域分割ページ`です。
- 完了：現在の出力帯域分割（FIR／IIR）と右側の予測応答を確認します。

### 帯域分割フィルターを設定する（Standaloneモード）

1. `帯域分割フィルター`を選び、Hi／BP／低域を指定します。
2. 境界の基準クロス周波数、方式、Overlap [oct]、FIRの場合はcyclesを設定します。カイザー窓の場合はbetaも設定します。
3. 実現応答を予測グラフで確認します。

LR4 IIRを基準に、帯域外の特定の共振を抑えたい場合はNTM4 IIRも比較します。NTM4を選ぶと`Lobe Height (dB)`が表示されます。初めて使う場合は−36.0 dBから比較し、保存済みの値がある場合はその設定を確認します。詳しい調整手順は[LR4とNTM4の使い分け](#lr4-ntm4-selection)を参照してください。

EQマスクは手動／自動のFIR EQ補正へ適用します。出力帯域分割FIRの係数自体にはEQマスクを適用せず、マスク適用済みの補正FIRを生成した後に、Kaiser-window FIRまたはリニアフェーズLR2／LR4を変更せず全長合成します。IIR LR2／LR4／NTM4は別のIIR段として扱います。

基準クロスから実際の遮断周波数と必要タップ数を計算します。正のOverlapはHP／LPを重ね、負のOverlapは離します。目標の線と実現した応答を比較します。

**FIR専用：書き出しのタップ数は、補正FIRと分割FIRを合成した後の最終出力設定です。** 0は自動割り当てであり、AdaptiveのON指定ではありません。現在の最終係数長とDSP上限を確認します。

EQファイル合成はFIR ON時だけ利用できます。FIR OFFでは登録内容を保持し、読み込み・合成を行いません。

タップ0の条件とマルチウェイとの対応は[タップ計算の詳細](#phaseeq-detail-taps)をご覧ください。

### FIR ON／OFFと使用できる帯域分割

書き出しのFIRタップ数の隣でFIR ON／OFFを選びます。単独編集のOFF時はFIR LR2→IIR LR2、FIR LR4→IIR LR4、カイザー窓→IIR LR4へ切り替え、FIR方式は選択できません。ONへ戻しても元の方式へ自動復帰しません。マルチウェイ接続中はFIR ON／OFF・タップ数を引き継ぎ表示し、PhaseEQでは変更できません。

実効FIR OFF時は、内部で計算されたFIR補正の目標・実現特性、FIR出力系列、FIR係数グラフを表示しません。出力帯域分割と書き出しのGain／Phase・時間応答は、有効なIIRとスピーカー応答を表示します。FIR補正に基づくError／Response AdvisorはOFFの案内へ置き換えます。IIR EQの解析は引き続き利用でき、FIRを再び有効にするとFIR表示を復帰します。

カイザー窓βの新規初期値は12.0、標準プリセットの境界別Overlapは0 octです。保存済みの明示値は維持します。「選択中の出力帯域を初期値に戻す」は選択中Hi／BP／低域の帯域分割を初期化し、EQと他の構成を保持します。マルチウェイにも選択中の分割構成を初期値へ戻す操作があります。

### 単独作業とウェイの設定復帰

編集対象を切り替えると、その対象の保存設定へ入力欄と予測応答を同期します。初回切替と2回目以降で復帰手順は同じです。切替直前のページは維持し、利用不可になったページだけ既存の代替ページへ移ります。接続ウェイの出力後処理はMultiway側で管理し、単独作業に戻ると単独の保存値へ復帰します。

「単独作業・未接続」では、旧保存に残っていたStudio用IIRクロスオーバー係数を表示・計算・書出しに使用しません。単独作業自身の帯域分割は選択・編集できます。旧外部係数は復元用に保持します。

保存形式のrevision／schemaが対応範囲なら、アプリ版番号だけで読込を拒否しません。破損・未対応形式は元ファイルを保持し、自動保存による上書きを止めます。復帰後は、設定値と最終応答を確認してください。

### 自動クロップと手動タップ編集（Standaloneモード・FIR専用）

1. FIRを使用することと、DSPのタップ上限を確認します。
2. `周波数特性を確認して自動クロップ`のON／OFFを選びます。選択できない場合は、帯域分割FIRの有無を確認します。
3. 必要な場合は手動タップ数を入力します。単独編集では`適用`で反映します。
4. 再計算後の最終FIRタップ数とDSP追加Delayを確認します。DSPへはmsかsamplesのどちらか一方を入力します。

マルチウェイの自動クロップON中はAdaptiveが最終長を決めます。手動値は保持し、OFFにしたときに使います。接続中のPhaseEQでは継承タップ数を変更できません。

安全条件に合うクロップ位置がなければ、元の全長FIRを保持します。表示用IRの長さをDSP入力に使わないでください。

最長出力への統一、窓、Delay補償、数値基準は[自動クロップの詳細](#phaseeq-detail-crop)をご覧ください。

### 境界ごとの音響ターゲット補正

LR2／LR4／NTM4では、音響ターゲットへの反映を優先します。設定した目標へ実際に近づけるには、EQの生成と結果の確認が必要です。FIR長の算出式と評価条件は[LR4の詳細](#phaseeq-detail-lr4)をご覧ください。

<a id="acoustic-target-behavior"></a>
#### 「高域 / 低域 音響ターゲットに反映」とは

**各スピーカーから出る音の実測特性を、選んだ分割カーブに近づける機能です。** 通常の帯域分割では、スピーカーの特性に分割フィルターの特性が重なります。この設定では分割カーブを目標へ反映します。PhaseEQで手動EQや自動ゲイン／自動位相を設定して、補正後の振幅・位相を目標へ近づけます。

HPをONにすると低域を落とす目標、LPをONにすると高域を落とす目標になります。選択中の元の目標特性に分割カーブを合成するため、元のカーブの傾きなども目標に残ります。

LR2／LR4のFIR・IIR方式とNTM4 IIRで利用できます。これらの方式を選択した直後の初期値はONで、必要に応じてOFFへ変更できます。保存済み設定を復元するときは、保存したON／OFFを維持します。カイザー窓とスルーでは常時OFFで選択できません。HP／LPは個別に設定できます。外部ネットワークを使用している場合は、その適用後の測定データを使い、既存の減衰も含めた実測特性を基準にします。

外部で帯域分割済みという理由だけでONにする必要はありません。追加の分割も選択した分割目標への補正も不要なら、スルーを使います。

| 設定 | PhaseEQの目標特性 | 直接分割段の出力 |
|---|---|---|
| ON | その境界の分割カーブを元の目標特性へ合成 | その境界の分割FIR／IIRを出力しない |
| OFF | その境界の分割カーブを合成しない | 選択した通常の分割FIR／IIRを出力 |

ON時の分割カーブはデジタルIIRから生成します。リニアフェーズLR2／LR4はIIRの振幅を取得し位相を0°にし、IIR方式は元の振幅・位相を保持します。元の目標特性設定を保存したまま派生カーブを計算するため、OFFへ戻しても目標特性編集は失われません。

スタンドアローンでも、帯域分割のHP／LPで「音響ターゲットに反映」を設定できます。設定したON／OFFは、IIRイコライザー、FIRイコライザー、書き出しへ移動しても保持します。バンドパスでHP／LPをLR4 IIRにした場合も、両側の目標カーブを保持したままIIRを編集し、出力できます。

スタンドアローンとマルチウェイの各チャンネルでは、音響ターゲットの設定と補正の生成を分離しています。ONはHP／LPの分割カーブを目標へ合成する設定です。補正は明示的に設定したIIR／FIR EQで行い、FIRのGain・Phase・Auto Gain・Auto Phaseがすべて無効または未設定なら、FIR補正フィルターは0 dB・0°です（処理遅延を除く）。

IIRイコライザーのフィルターでも、音響ターゲットに合わせて応答を調整できます。FIRの自動補正には自動ゲイン／自動位相を追加し、範囲と補正量を設定してください。プレビューと書き出しで同じ規則を使います。既存設定をPhaseEQで開いた場合もこの規則が適用されます。マルチウェイへは再生成した結果を送信してください。

ウェイでの音響ターゲット設定は、マルチウェイの[④](#multiway-boundary-settings)をご覧ください。

#### 操作手順と確認点

**ONにするだけでは補正は完了しません。**

> LR／NTM4方式・クロス周波数を設定してON → 振幅・位相を含む測定を適用\
> → 入力をTargetへレベル合わせ → 手動EQまたは自動ゲイン／自動位相を設定\
> → 更新して最終特性を確認 → 保存・出力

自動表示更新がOFFのときは「更新」を押します。FIR OFFの場合はIIRイコライザーで補正します。マルチウェイ連携中は、境界条件をマルチウェイ側で設定し、各Wayの補正を返して合成を確認します。

Standaloneでは[目標特性への反映手順](#target)に従い、設定した自動ゲイン／自動位相の範囲・補正量を確認します。自動EQが未設定なら自動補正は生成しません。IIRのみではIIRイコライザーを使い、振幅・位相の一致度を確認します。

ウェイの設定変更・再送信・補正結果の返却は[④](#multiway-boundary-settings)と[⑤](#multiway-phaseeq-adjustment)をご覧ください。変更後は⑤で各ウェイを再計算し、補正結果を返却します。

### 出力帯域分割ページのタップ数案内

PhaseEQのHP／LP境界と保存済みマルチウェイ帯域分割にも、選択方式に応じた案内を表示します。カイザー窓ではPhaseEQとMultiwayのどちらも、周期数を2.70〜15.00、β値を7.0〜16.0の範囲で設定できます。目標減衰、周期数から求めたタップ数の目安、現在の生成長を表示します。「カイザー窓の使い方」を展開すると、調整フロー、確認結果に応じた次の操作、周期数・減衰スロープの目安を確認できます。表には代表値を掲載しています。範囲外の保存値は読込時に共通範囲へ補正します。

LR2ではマルチウェイと同じく、LP・HPの5 Hz〜ナイキスト周波数のうち目標応答−80 dB幅以上の範囲で最大誤差0.05 dB以内となる必要タップ数と、現在の生成長を表示します。案内の表示だけでは生成設定を変更しません。いずれもEQ合成・自動クロップ・最終出力長の調整前の境界FIRの値です。IIRやスルーではFIRタップ数案内を表示しません。


### プリセットを使用する（Standaloneモード）

1. `出力帯域分割のプリセット`を選びます。
2. プリセット行を選択します。
3. 適用操作を実行します。

行を選択しただけでは現在のFIRフィルターは変わりません。適用後に「現在のFIRフィルター」が更新されたことを確認してください。

### マルチウェイから再送信したとき

同じチャンネルの新しい割り当てを検出すると、PhaseEQは現在の編集をDraftに退避し、EQ編集を引き継いで最新の帯域条件へ更新します。開いたままでも約2秒間隔で受信を確認し、更新を検知すると自動で画面を更新します。再読み込みは不要です。マルチウェイの接続IDは現在のPhaseEQ画面を示します。以前の返却FIRは、新しい編集を「マルチウェイへ送信」するまで「前回結果を保持・最新版の返却待ち」と表示します。

### ウェイ編集中の確認

帯域分割・プリセットはマルチウェイ側で設定します。PhaseEQでは継承した境界・目標・FIR／IIR条件を確認し、[⑤の手順](#multiway-phaseeq-adjustment)で補正結果を返します。

作業セッションZIPから単独編集へ復元した場合も、保存したマルチウェイ構成を再現します。`単独の帯域分割設定へ切り替え`を押すと隣接HP/LPの編集へ移りますが、マルチウェイの中間帯域合成と全境界に基づくLR2極性補償は外れるため、切り替え前に保存してください。

帯域分割IIRはFIRに含めず別に出力します。ZIPにはOutput-Band-Split／Combined-IIR-ChainのJSONと極性の説明を収録します。外部DSPでLR2極性補償が必要な場合は、表示された符号をSOSとは別に1回だけ適用してください。マルチウェイへの返却時はマルチウェイが補償します。

<a id="live-result"></a>
## 10. 予測グラフ：計算結果を確認する

- 目的：現在ページまでの応答、誤差、時間特性を確認します。
- 場所：PhaseEQ各ページの右側です。
- 完了：表示が最新であり、警告と異常なゲイン／位相を確認済みです。

### 予測応答の表示設定を使う

- 設定画面の「予測応答の表示設定」で「予測応答を自動更新」がONの場合、設定変更後に自動更新します。軽量表示／操作可能な表示モードも同じ場所で変更できます。表示点数は両モードとも1系列2,048点固定です。手動の「更新」ボタンは予測応答の見出し行の右端にあります。
- `予測応答を自動更新`がOFFの場合、`更新`で再計算します。
- 更新前の結果を表示している場合は案内が表示されます。

### ゲインと位相を確認する

`最小 dB`と`最大 dB`でゲイン表示範囲を選びます。位相は`位相マスク`より低いゲインの点を非表示にできます。

表示内容は現在ページにより変わります。スピーカー入力、目標特性、IIR、FIR、書き出し FIRなどの段階は[補足20](#note-20)をご覧ください。

### 詳細表示を切り替える

`詳細表示`から次を選びます。

- `誤差`：IIRページはIIR結果と目標特性の差。FIRページは選択段階の実現FIRと理想補正の差（最終音響目標特性との差とは別）
- `応答アドバイザー`：応答の注意箇所と推奨確認事項
- `ウェーブレット`：時間周波数応答
- `群遅延`：連続位相から求めた群遅延
- `ステップ応答`：入力に対するステップ応答
- `インパルス応答`：入力に対するインパルス応答
- `FIR係数・窓関数`：現在のFIR係数と窓関数
- `入力詳細`：スピーカー入力、目標特性、マイク校正の出典

ウェーブレットと群遅延の解釈は[補足21](#note-21)をご覧ください。

### 位相・群遅延・ウェーブレットを順に読む

1. `応答処理`の位相のセンタリングで、スピーカー入力の時間基準を先に整えます。
2. 位相では、360°の表示境界よりも、通過帯域の傾きと補正前後の変化を確認します。
3. 群遅延では、位相の傾きを時間として確認します。ゲインが小さい遮断帯域は判定対象外です。
4. ウェーブレットでは、周波数帯ごとのPeak時刻とCentroidを見て、遅れや長い尾を確認します。

位相マスクは、信号がほとんどない領域の不安定な位相を非表示にするための判定補助です。位相、群遅延、ウェーブレットは別の処理結果ではなく、現在の応答を異なる観点から表示しています。

<a id="export"></a>
## 11. 書き出し：係数と作業状態を出力する

- 目的：最終FIR、IIR バイクアッド、設定、作業セッションZIPを保存します。
- 場所：`音の補正・フィルター設計 > 書き出し`です。
- 完了：「現在の出力」を確認し、必要な出力ファイルを保存します。

### 出力ファイルの名前を決める

`出力ファイル名のラベル`はFIR、IIR、作業セッションZIPのファイル名に使用します。処理プロファイル名とは独立しています。

### FIRフィルター出力を設定する（Standaloneモード・FIR専用）

1. `FIRフィルター`を選びます。
2. DCゲインを正規化、極性、コサインテーパー窓、自動ゲインを確認します。
3. 「現在の出力」のFIRフィルター概要を確認します。

マルチウェイの割り当て中は、マルチウェイ側を正本とする項目を変更できません。返却時に極性やコサインテーパー窓を暗黙適用しません。

単独書き出しと合成返却で異なる後処理は[補足13](#note-13)をご覧ください。

### 書き出しのグラフを確認する

| 線 | 表示する内容 |
|---|---|
| FIR出力 | 自動ゲインなどの後処理を含む最終FIR。FIR OFF時は表示しません |
| IIR出力 | IIRイコライザーと直接出力の帯域分割・オールパス・極性 |
| FIR＋IIR出力 | FIRとIIRを一度ずつ適用した合成応答 |
| スピーカー＋実現応答 | 測定入力へFIRとIIRを適用した予測応答 |

時間波形にも両者を合成します。Current page deltaはFIR書き出し処理による変化、誤差はFIR係数と理想FIRの差です。IIRイコライザーページの誤差は、IIR適用後の入力と目標特性との差で、意味が異なります。位相のない測定では位相誤差を算出しません。

### 出力形式を選ぶ

`出力形式`で必要なFIR係数形式を選びます。目標応答の出力形式は目標特性ページで設定します。

### ダウンロードから保存する

`ダウンロード`には次の出力があります。

- 設定
- IIRイコライザーの`汎用IIRパラメーター`とバイクアッド
- 出力帯域分割ページ IIR
- Combined IIR chain
- FIRフィルター
- 作業セッションZIP
- マルチウェイ連携

IIRはFIR係数へ畳み込まれません。後段DSPでは、IIRとFIRを設計どおりの順序で個別に適用してください。

### バイクアッドを直接入力できないIIR DSPへ転記する

1. `IIR EQのみ`、`出力帯域分割のみ`または`合成IIRチェーン — IIR EQ → 出力帯域分割`の対象を確認します。
2. `汎用IIRパラメーター`を押してMarkdown文書を保存します。
3. 文書の`Apply order`順に、種類、周波数指定、ゲイン、Q、次数をDSPへ入力します。
4. `Enabled: No`の行は設定へ適用しません。
5. DSP上の実現応答を測定し、PhaseEQのゲイン／位相と比較します。

文書にはサンプルレート、フィルター系列、手動／自動の由来、オールパス プリセットも記録します。Shelf Q、クロス family、オールパスの定義と設定可能範囲はDSPごとに異なるため、文書の値を入力できない項目は無理に近似せず、対象DSPの仕様と実現応答を確認してください。通常のEQ・帯域分割は設計値を記録し、追加のオールパス・極性段はバイクアッド係数表で記録します。係数入力に対応しないDSPでは、この追加段をそのまま転記できない場合があります。

### 作業セッションZIPを保存する

`作業セッションZIPをダウンロード`で現在作業を保存します。このZIPを別PCへコピーし、移行先PhaseEQの`設定 → バックアップと復元 → PhaseEQ作業セッションZIP`で選択して`ZIPから環境を復元`を押すと、スピーカー入力、マイク校正、目標特性、EQ、FIR条件を含む編集状態を復元できます。

完全に同じ再計算結果が必要な場合は同じPhaseEQ versionを使用してください。ZIPは作業再開用であり、測定データ DBやドライバーデータベース全体のバックアップではありません。[補足2](#note-02)をご覧ください。

### マルチウェイへ送る

1. `Composite Engine`欄で割り当て状態を確認します。
2. サンプルレートとタップ数が異なる場合は再計算します。
3. 画面上部の送信先チャンネルを確認して、`マルチウェイへ送信`を押します。書き出し下部にも同じボタンがあります。送信時は書き出しへ移動し、既存の条件確認・保存処理を行い、結果を画面上部にも表示します。単独編集／目標特性の編集では上部の送信ボタンは表示しません。
4. `Composite Engineへ戻る`で戻ります。

単独編集では合成接続操作を使用できません。マルチウェイの対象チャンネルから`PhaseEQへ送信（全チャンネル）`を実行し、開いた割り当て画面で返却してください。現在の再現可能なFIR 生成定義、IIR、処理済みスピーカー応答、目標特性、作業状態の扱いは[補足30](#note-30)をご覧ください。

### ウェイ編集中のFIR後処理

DC正規化・出力極性・窓・FIR自動ゲインは、PhaseEQ側では操作せず、マルチウェイ側で設定します。詳細は同梱ユーザーガイド第12節の[マルチウェイのFIR後処理](#multiway-fir-postprocessing)をご覧ください。

### 最終FIRの窓と係数表示（Standaloneモード・FIR専用）

自動クロップとコサインテーパーはKaiser／FIR LR2／FIR LR4で共通です。基本係数は公称長で生成し、110%長で再生成しません。元FIRの実係数で左右を拡張し、窓の遷移を追加領域内で完了します。グラフ・バックアップ・DSP出力には同じ最終係数と補償Delayを反映します。係数単体を利用する場合も、表示されたクロップ補償Delayを設定してください。

PhaseEQは「書き出し」で「コサインテーパー窓」をON/OFFできます。初期値OFF。Adaptiveの有効長を110%へ拡張し、奇数タップへ切り上げます。331 tapsなら左右17 tapsの実係数を追加して365 tapsとし、追加した部分だけへ窓をかけます。中央331 tapsは変更しません。端に十分な係数がなければ左右同数で追加範囲を制限します。

安全な奇数範囲が得られない場合や最終検証が不適合の場合は、別の係数へ置き換えず出力を停止します。画面のα=0.10表記は維持しますが、最終長の両端各5%を機械的に変更する処理ではありません。

詳細表示 → FIR係数・窓関数では、実係数のlinear値、絶対値のdB re 1.0、窓形状を表示します。横軸は0〜タップ数−1のタップ位置です。dB線は各タップの係数振幅を示します。従来のインパルス応答表示は時間原点を保持したタップ数分の範囲です。

ウェイ編集中の窓と係数表示は、同梱ユーザーガイド第12節の[マルチウェイの最終FIR設定](#multiway-final-fir-settings)をご覧ください。

## 出力データの確認と外部機器での利用

### 本アプリでの完了範囲

本アプリでの作業は、入力と目標を確認し、設計・予測グラフの比較、係数の書き出し、作業状態の保存までです。音楽再生は外部ソフトウェア／DSPの役割です。機種別の配線、取込画面、再生操作は対象製品の公式説明書をご覧ください。機器が手元になくても、出力内容と作業保存までを確認できます。

### 書き出し後の共通確認

1. 対象チャンネル、サンプルレート、FIR係数長、IIR段数と係数規約を、出力先の仕様と照合します。
2. FIRのみ、IIRのみ、両方のどれを設計したか確認します。FIRファイルだけでIIRも適用されるとは限りません。
3. ゲイン、極性、遅延がどの係数・設定へ含まれるか確認し、外部側で同じ処理を二重に加えないようにします。
4. 出力の設計名・時刻・Manifestなどで、確認した設計と保存ファイルの対応を確かめます。作業セッションZIPも保存します。
5. 実機で使用する場合は、変更中のミュート、チャンネル対応、保護設定を確認し、低音量から確認します。大きなBoostや出力先のクリッピングにも注意してください。

特定機種の接続や取込が成功したという実機検証結果は、本書の一般手順からは判断できません。出力形式への対応と、実機動作確認済みであることを区別してください。

### アプリ内で比較する検証例

次は同じ入力と目標を使って比較するための手順例です。掲載値は実測の合格基準ではありません。実際に得た結果を設計条件とともに保存してください。

| 比較例 | 変える条件 | 確認する表示 | 判断の仕方 |
|---|---|---|---|
| タップ数の比較 | 許容範囲内でタップ数だけ変更 | 最終FIR長、目標との差、インパルス応答 | 目標への近さだけでなく遅延・前後の尾・出力先の上限を確認。長い方が必ず良いとは限りません |
| クロス付近の合成 | 隣接チャンネルの極性またはDelayだけ変更 | 個別チャンネル、System Sum、位相 | 山谷が生じた帯域と位相関係を比較。一律の合格dB値を当てはめず、目標応答と照合します |
| 出力段の確認 | FIR／IIR／FIR＋IIRの表示を切替 | 書き出しグラフと選択した出力形式 | 必要な各段が有効か、保存した係数が対象の段に対応するか確認します |

確認後は比較前の設定へ戻すか、採用した設定で再計算してから書き出します。数値計算上の予測、出力係数の確認、実機の電気的出力、マイクによる音響実測は別の検証です。本書のアプリ内比較を実機測定済みの証拠として扱わないでください。

### 最初の2Way設計の完了チェック

各Wayの測定入力を選択し、クロスと目標を設定して、必要なIIR → FIRの順に設計します。各チャンネルをマルチウェイへ返し、個別応答と合成を確認します。Systemを保存し、作業バックアップを取得してから、実機DSP用パッケージを出力します。実機再生・再測定は、この設計例の必須完了条件に含めません。各操作は「最初のシステムを作る」「PhaseEQでチャンネルを編集する」「保存・出力を選ぶ」をご覧ください。

<a id="composite-engine"></a>
## 12. マルチウェイ：マルチウェイを構成する

- 目的：各スピーカーユニットの担当帯域と音量・つながりを調整し、全体を希望するターゲットカーブへ近づけてDSPへ出力します。
- 場所：PhaseEQの`マルチウェイを開く`からマルチウェイ画面へ進みます。
- 完了：各チャンネルの補正結果を返却し、合成結果とDSP互換性を確認して実機DSP用ZIPを保存します。

画面上部の操作案内に続けて「終了：保存して、起動元のターミナルで Ctrl+C。」を表示します。終了する前に編集内容を保存してください。

### 測定済みデータからDSP出力までの道順

[15ページ簡易版](manual/PhaseEQ_Multiway_QuickGuide_15p_Dark_JA.pdf)の対応箇所は、構成p.05、測定・目標p.06、分割方式p.07、位相構造補償p.08、入力p.09、IIR p.10、FIR p.11、返却p.12、合成p.13、保存・出力p.14、実機p.15です。

ここでは、REW／ARTAなど外部のマイク測定ソフトで各ユニットを測定済みであることを前提にします。録音操作は不要です。測定済みのデータを使用します。チャンネルディバイダーは、低音・中音・高音を担当するユニットへ音を振り分けるフィルターです。各ユニットを全周波数で同じ特性にするのではなく、担当帯域の音を整えてから、全部を合わせた特性を目標へ近づけます。

### FIRを初めて使う場合

**FIR対応DSPの手順を基本に進めます。IIRのみのDSPでは、④の方式と⑤の補正操作を切り替えます。** FIRは振幅と位相を調整できる係数列、IIRは少数のフィルター段を組み合わせる方式です。FIRの長さと遅延の考え方は[設計パラメーターの決め方](#design-parameters)と[補足14](#note-14)をご覧ください。

| 順序 | 行うこと | 次へ進む目安 |
|---|---|---|
| ① 構成とDSP | ウェイ数、左右、SUB、DSP出力との対応を決める | 出力数とDSPの制約が分かった |
| ② 測定入力 | 外部測定ファイルを登録し、各チャンネルへセットする | 全チャンネルの測定名が正しい |
| ③ 全体の目標 | 希望するターゲットカーブを登録・選択する | 合成後に目指すカーブが決まった |
| ④ 担当帯域 | 分割方式とクロス周波数を選び、LR／NTM4方式では音響ターゲットへの反映も設定する | 各ウェイの役割が決まった |
| ⑤ PhaseEQ調整 | 入力と目標を確認し、IIR → FIRの順に必要なEQを調整して返す | 全チャンネルの結果を返却した |
| ⑥ つながり | 音量、極性、位相・時間整合を確認する | クロス付近の山谷を確認した |
| ⑦ 全体確認 | システム合成とターゲットを比較する | 残る差と原因を確認した |
| ⑧ 保存・出力 | 設計を保存し、実機DSP用ZIPを出力する | 互換性エラーがない |
| ⑨ 実機へ反映 | 外部DSPへ読み込み、出力先と設定を確認する | 意図したユニットへ設定が入った |

### ① 構成とDSPを確認する

2Way／3Wayなどのウェイ数、モノラル／ステレオ、SUBの有無を決めます。各チャンネルが「左の低域」「右の高域」など、どのユニットにつながるかを記録します。DSPの出力数、サンプルレート、FIRの最大タップ数、IIRの段数、追加遅延の上限を確認し、その範囲で設計します。クロス周波数はユニットの実測と使用可能帯域に合わせ、画面例の数値をそのまま使わないでください。

### ② 外部ソフトの測定データを各チャンネルへセットする

1. REW／ARTAなどから書き出した、各ユニットのFRD／TXT／CSVを用意します。基本は周波数Hz、ゲインdBの2列、位相を使う場合は3列目に位相degreeを入れます。対応するモノラルWAVのインパルス応答も使えます。
2. 左右・ウェイの測定名、測定位置、測定時の音量、外部分割や保護フィルターの有無を確認します。ユニット間の音量差と時間差を比較できる測定条件を使います。
3. `スピーカー測定データ`へ登録し、`マルチウェイに割り当て`で送信先チャンネルの行を選び、`この測定データをセット`を押します。ファイルから始める場合は`ファイルを登録してセット`を使えます。
4. 全チャンネルの測定名を確認します。左右や高域／低域は自動で振り分けられません。詳しい登録・セット操作は[測定データをマルチウェイへセットする](#multiway-measurement-assignment)をご覧ください。

**位相の列があることと、測定間の時間基準が揃っていることは別です。** 振幅だけのデータでは、実測位相に基づく合成や時間整合を確認できません。各測定の時間原点が別々の場合も、到達時間差を確認済みとして扱わず、⑥で時間基準を確認します。推定した位相は実測位相と区別してください。

外部ネットワーク適用後の測定を使う場合は、既存の帯域分割を記録します。追加分割も選択した分割目標への補正も不要な境界は`スルー（外部で帯域分割済み）`にします。同じ分割を重ねないでください。

<a id="multiway-target-selection"></a>
### ③ スピーカー全体のターゲットを決める

まず、低域から高域までの目標とする周波数バランスを決めます。マルチウェイの`PhaseEQのTargetを開く`から目標を読み込み・編集し、`新規登録`または`更新`で保存します。マルチウェイへ戻り、`登録済みTargetを更新`で一覧を更新して使用する目標を選びます。

このグループターゲットは、全体の合成結果と比較する基準です。④で各ウェイの担当帯域と目標への反映方法を決め、⑤で必要な補正を生成します。

<a id="multiway-boundary-settings"></a>
### ④ 分割方式と音響ターゲットを設定する

カイザー窓、LR2／LR4のFIR・IIR、NTM4 IIR、スルーから分割方式を選び、各ウェイの担当帯域を決めます。`音響ターゲットに反映`はLR／NTM4方式で使用する設定です。

LR4は広い帯域外を単調に減衰させる基準、NTM4はノッチ付近の共振を抑える選択肢です。[使い分けと調整手順](#lr4-ntm4-selection)に沿って比較します。

**LR／NTM4方式で音響ターゲットをONにする場合は、⑤で補正を作成します。**

> ON → PhaseEQへ送信 → 各Wayの測定を適用・レベル合わせ\
> → 手動EQまたは自動ゲイン／自動位相を設定\
> → マルチウェイへ返却 → 再計算して合成確認

FIR OFFの場合はIIRイコライザーで補正します。方式・クロス周波数・ON／OFFを変更したら、再送信して各Wayの補正を更新します。


| 項目 | FIR対応DSP：基本の手順 | IIRのみのDSP：変更する操作 |
|---|---|---|
| FIR出力 | `DSP FIR出力を有効にする`をON | 同じ設定をOFF |
| 分割方式 | カイザー窓、リニアフェーズLR2／LR4、IIRのLR2／LR4／NTM4 | LR2 IIR、LR4 IIRまたはNTM4 IIR |
| 各境界の目標 | LR／NTM4方式は`音響ターゲットに反映`のONを優先。カイザー窓は対象外 | LR／NTM4方式は同じくONを優先 |
| ⑤の補正 | 必要なFIR EQ（自動ゲイン・自動位相など） | 選択した分割目標に合わせるHP／LPと必要なEQ |

1. FIR出力のON／OFFを決めてから、各境界の分割方式とクロス周波数を確認します。FIRをOFFにすると方式がIIRへ変わり、ONへ戻しても元の方式へ自動復帰しません。
2. LR2／LR4／NTM4では、境界ごとの`音響ターゲットに反映`をONにする手順を優先します。FIR対応DSPでもIIRのLR／NTM4方式を選べます。カイザー窓とスルーではこの設定を使いません。
3. カイザー窓は分割FIRを直接出力し、周期数・β値で分割形状を調整します。外部で帯域分割済みの境界はスルーを選びます。
4. FIRを使うチャンネルは、マルチウェイ側のタップ設定と最終出力長を確認します。FIR出力ONだけで全ウェイの補正FIRが有効になるとは限らないため、⑤へ送るチャンネル条件も確認します。

LR／NTM4方式でONにすると、共通ターゲットに各ウェイの分割カーブを加えます。低域には高音を落とすLP、高域には低音を落とすHP、中域には両方を含む目標を作ります。リニアフェーズLRはLRの振幅形状を直線位相の目標として使い、IIRのLR／NTM4は振幅と位相を目標に含めます。

**ONにするだけでは補正は完成しません。その境界の分割FIR／IIRは直接出力されないため、⑤で補正を作り、担当帯域外が減衰していることまで確認します。** 通常の分割フィルターを直接出力したい場合はOFFにする別手順を使います。ON／OFFやクロス条件を変更したら、チャンネルへ再送信して補正結果を更新してください。

分割条件が決まったら「位相構造補償を自動適用」のON／OFFで、合成Gainと隣接Wayの位相を比較します。主にIIRを含む3Way以上で使用します。簡易版p.08と、本節後半の「位相構造補償の使い方」を参照してください。目標へ反映する条件も含めて確認してから⑤へ送信します。

<a id="multiway-phaseeq-adjustment"></a>
### ⑤ PhaseEQで各ウェイを目標へ近づける

各チャンネルで「入力を確認 → レベルを合わせる → 目標を確認 → 補正する → 出力を確認 → 返す」を繰り返します。まず1チャンネルを最後まで返してから次へ進むと、未返却のチャンネルを見落としにくくなります。

**入力確認⑤-1 → IIR調整⑤-2 → FIR調整⑤-3 → 最終確認・返却⑤-4の順です。** IIRのみのDSPは⑤-3を省略し、FIRのみなら⑤-2を省略します。簡易版のp.09 → p.10 → p.11 → p.12と同じ順序です。

#### ⑤-1 共通：対象・測定・目標を確認する

1. マルチウェイの`PhaseEQへ送信（全チャンネル）`を押します。PhaseEQを開き、上部の`編集中のChannel`で対象を選びます。チャンネルごとに別画面を開く必要はありません。
2. 左右・ウェイ・測定名・サンプルレート・FIR使用有無を確認します。入力が違う場合は測定データのチャンネル割り当てへ戻ります。
3. `応答処理`の`レベル合わせ`で、入力の基準レベルを目標へ合わせます。自動で基準帯域を決められない場合は、担当帯域内の信頼できる実測範囲を手動指定します。これは計算用の基準合わせであり、元データや実機の再生音量を変える操作ではありません。
4. 目標特性とグラフで、自分のウェイに対応するHP／LP形状を確認します。受信した目標は閲覧専用です。共通ターゲットの登録・編集、境界の変更はマルチウェイ側から行い、変更後に再送信します。

#### ⑤-2 IIR：HP／LPを用意し、自動EQで調整する

1. `IIRイコライザー`を開きます。IIRのみのDSPではFIR出力OFFと、位相・時間整合側の「音響ターゲットに反映」OFFを確認します。FIR併用時もIIRを先に調整します。
2. 音響ターゲットONの境界は直接の分割段が外れています。LR2／LR4の目標で、測定入力に必要な分割が含まれていなければ、手動IIRで低域にLP、高域にHP、中域にHPとLPを追加します。目標と同じLR2／LR4とクロス周波数を出発点にし、補正後の音響特性を見て調整します。外部ネットワーク適用後の測定では、その減衰も含めて判断し、同じ分割を重ねません。
3. 必要な分割と手動IIRを残したまま、担当帯域の残る山谷をPEQ／Shelfで調整します。自動EQは、担当帯域に合う開始・終了周波数、最大本数、ヘッドルームを設定してから`IIR自動調整を実行`します。入力整形の「深いディップを浅くして計算」「帯域別oct平滑化」をONにし、深い谷や高域の細かな変動への過大な補正を避けます。自動生成したPEQは手動調整も可能です。位相は必要に応じて手動オールパスなどで調整します。
4. 再生成するときは`自動IIRを削除`で自動生成分を削除してから実行します。手動のHP／LPは保持されます。HP／LP、EQ、オールパスなどを含む最終出力のバイクアッド段数がDSPに収まるか確認します。

NTM4の目標には、ノッチを含む振幅・位相が含まれます。同じクロス周波数の手動LR4では、その形状を再現できません。NTM4の分割段を直接使う場合は、境界の「音響ターゲットに反映」をOFFにします。ONで補正する場合は、ノッチ付近と帯域外の減衰も含めて補正後の応答を確認してください。

IIRでは任意の振幅・位相へ完全には一致できません。帯域外の減衰やクロス付近のつながりが不足する場合は、分割条件や目標、手動フィルターを見直します。改善できないまま目標線だけを根拠に出力へ進まないでください。

#### ⑤-3 FIR：自動ゲイン・自動位相で調整する（FIR専用）

1. 「音響ターゲットに反映」ONなら、`FIRイコライザー > ゲイン`で必要なHP／LPを追加し、周波数・応答を調節して目標スロープへ近づけます。⑤-2のIIRや外部ネットワークで準備済みの場合は、同じ減衰を重ねません。
2. `ゲイン`で`Auto Gain · Section`（自動ゲイン）を追加し、担当帯域に合う開始・終了周波数、補正量を設定してからONにします。「深いディップを浅くして計算」「帯域別oct平滑化」をONにし、深い谷や高域の細かな変動へ過度に追従しない設定を確認します。初期値と同じ詳細数値の再設定は不要です。
3. `位相`で`Auto Phase · Section`（自動位相）を追加します。実測位相・時間基準を確認し、信頼できる開始・終了周波数を設定してからONにします。終了条件は必要に応じて「周波数指定」を選びます。
4. ゲインと位相、それぞれのターゲットとの差を確認します。自動更新がOFFなら`更新`を押します。手動のゲイン／位相フィルターでも調節できます。IIRを変更した場合はFIRを再計算します。

担当帯域内、クロス付近の傾き、担当帯域外の減衰、群遅延・インパルス応答を確認します。狭い補正範囲、不足したカット量、短いFIRでは目標へ十分に近づかない場合があります。未測定の帯域を推定だけで合格としないでください。

自動ゲイン／自動位相が未設定またはOFFなら、その補正は作られません。音響ターゲットONは目標を作る設定です。必要なEQを追加・設定して補正を生成します。

#### ⑤-4 共通：最終結果を確認して返す

`書き出し`など最終出力の予測で、有効なFIR／IIRを含む結果を確認します。担当帯域内の目標との差、クロス周辺、担当帯域外の減衰、過大な補正、FIR長またはIIR段数を確認します。位相は音量が十分ある範囲で評価します。

確認できたら`マルチウェイへ送信`を押し、マルチウェイの一覧で返却を確認します。次のチャンネルへ切り替え、⑤-1から繰り返します。画面内の未保存ドラフトは編集中の内容です。返却結果として使うには送信が必要です。全チャンネルを返し終えてから⑥へ進みます。

### ⑥・⑦ つながりを整え、全体をターゲットと比較する

帯域分割の目標とは別に、整合側にも`位相・時間整合：音響ターゲットに反映`があります。こちらをONにするとFIR出力もONになります。**IIRのみのDSPでは整合側をOFFのまま**にし、DSPで対応できる直接IIRのオールパスと遅延を使います。オールパスに対応しないDSPでは、その利用も無効にして出力互換性を確認します。FIRで整合目標を反映する場合は、ONにした後に⑤へ戻って補正を作り直します。④のLR／NTM4境界側のONと混同しないでください。

1. マルチウェイで`再計算`し、各チャンネルの補正が反映されていることを確認します。各ユニットの音量配分はチャンネルゲインで確認します。⑤の入力レベル合わせだけで実機の音量差が解消したと判断しません。
2. 実測位相と測定の時間基準を確認し、必要な時間基準を選んで`全Channelの位相・時間整合を適用`します。共通時間基準が未確認の場合は、同じマイク位置からの外部測定距離など、利用できる基準を確認します。整合処理はゲインを調整しません。
3. `System Sum`とグループターゲットを比較します。クロス付近の大きな山谷はEQだけで埋めず、極性・遅延・隣接ウェイの位相関係・分割条件も確認します。位相・時間整合側の目標への反映を変えた場合も、⑤へ戻って補正を更新します。
4. ステレオはLとRをそれぞれ確認し、L+Rで左右の結果を並べて比較します。全体の傾き、接続部、群遅延、インパルス応答を確認します。振幅だけの入力から実測位相・時間整合まで合格と判断しないでください。

### ⑧・⑨ 保存し、実機DSPへ渡す

`System Library`へ設計を保存し、再開用の`作業バックアップ`も保存します。`実機DSP用パッケージを保存`で出力先DSPとデバイスプロファイルを選び、チャンネル別互換性表と警告を確認して`実機DSP用ZIPをダウンロード`を押します。互換性エラーがある場合は設計を見直してから出力します。

解析用Group応答は予測結果、作業バックアップは再開用です。DSPへ渡すのは実機DSP用パッケージです。FIR OFFのチャンネルにはFIRファイルを出力しません。IIR、極性、ゲイン、遅延などは選択した出力形式に従います。

外部DSPへの読み込みは対象機器のソフトウェアで行います。PhaseEQが自動転送する操作ではありません。出力とユニットの対応を確認し、パッケージに含まれる分割・極性・遅延を実機で重複適用しないでください。予測と実際の音は区別し、必要な場合はREWなどで設定後の合成応答を確認します。今回の入力データだけで、設定後の実機音を確認済みとは扱いません。

### 目標へ近づかないときの戻り先

| 状況 | 戻って確認すること |
|---|---|
| 担当帯域内の山谷が残る | ⑤の測定入力・レベル合わせ・補正範囲・EQ |
| クロス付近だけ大きな谷や山がある | ④の分割条件と⑥のゲイン・極性・時間・位相 |
| 音響ターゲットONなのに帯域外が落ちない | ⑤の有効な補正、IIRのHP／LP、FIRの範囲とカット量 |
| 目標やクロスを変えても古い結果のまま | 全チャンネルへ再送信し、⑤で再生成・返却 |
| DSPの互換性エラーが出る | ①の制約と、最終FIR長・IIR段数・遅延・出力対応 |

### 設定項目1～8の役割

| 区間 | 主な操作 | 操作の目安 |
|---|---|---|
| 1 分割方式と基本条件 | ウェイ、クロス周波数と方式（サンプルレートは設定内） | 最初に設定 |
| 2 バッフル補正 | 低域側のレベル補正 | 必要な場合だけ |
| 3 FIR出力・タップ長 | FIR ON／OFF、自動クロップ、帯域別タップ数、出力タップ数統一 | FIR使用時 |
| 4 EQファイル合成 | 帯域別の外部FIRイコライザー | 必要な場合だけ |
| 5 表示・再計算 | ゲイン範囲、位相マスク | グラフ確認前 |
| 6 FIRファイル出力 | 形式、正規化 | FIR ON時の出力条件を決定 |
| 7 設定管理 | snapshot、設定読込、DSP Packageからの作業再開 | 設計の節目 |
| 8 システム構成・PhaseEQ連携 | システム、出力レイアウト、チャンネル、目標特性、整合、書き出し | 全体構成と完成 |

表示言語、ヘルプ待ち時間、サンプリング周波数、FIR出力条件、グラフ表示条件は左サイドバーの「設定」へ集約しています。左サイドバーの設定項目1～7でフィルター条件を設定し、同じサイドバーの設定項目8で実際のチャンネルへ割り当てます。メイン画面には再計算操作、確認表、グラフ、ダウンロードを表示します。設定変更後に自動がOFFなら、必ず`再計算`を押してから判断してください。

グラフの`軽量表示`はSafariや低速PC向けの軽量表示、`操作可能な表示`は拡大・パン・ツールチップを使う表示です。どちらも2 Hz以下の共通周波数グリッドで確定した計算結果を、対数周波数軸へ1系列2,048点で間引いて表示します。モード切替だけではFIRや合成応答を再計算しません。6つのStudioグラフ領域は同じ高さと順序を維持するため、切替時に後続の表やダウンロード欄が上下へ移動しない構成です。計算精度、保存値、出力係数は変更しません。

設定項目7の`設定ファイルを読み込む／作業を再開`は共通の読込入口です。設定JSONまたは`settings.json`を含む設定ZIPは、内容のプレビュー後に適用します。`作業バックアップ`または`実機DSP用パッケージ`のZIPはDSP Packageとして検証し、システム、チャンネル、目標特性、マルチウェイ設定、PhaseEQ作業状態を復元します。

### 最初のシステムを作る

1. サンプルレートと分割方式を選びます。
2. 各境界の帯域分割方式と周波数を設定します。
3. 設定項目3でFIR出力のON／OFFを決めます。
4. FIRを使う場合は、続けて自動クロップまたは帯域タップ長を確認します。
5. 必要な場合だけバッフル補正、自動クロップ、帯域FIRイコライザーを設定します。
6. 設定項目8で出力レイアウトとチャンネルを設定します。
7. `再計算`でグラフを更新します。

分割方式は`全帯域`、`Fullrange+SUB`、`2Way`～`4Way`と各`+SUB`です。FIR／IIRを境界ごとに混在できます。

`全帯域`は帯域分割を行いません。`Fullrange+SUB`は同じ境界からSUB ローパスと全帯域 ハイパスを生成します。

### 音響ターゲット変更後の補正とタップ数

3Way以上では境界ごとに音響ターゲットのON／OFFを混在できます。既に送信済みの係数や保存済みの旧FIR Recipeは、各チャンネルをPhaseEQで開いて再送信するまで維持します。

FIRを使用するONの境界でも、設定した自動ゲイン／自動位相の補正範囲・補正量を使用します。Auto EQが未設定なら自動補正は生成しません。この境界の分割FIR／IIRを補正FIRへ重ねて出力することはありません。位相・時間整合のオールパスは、その音響ターゲット設定に従って直接出力または目標へ反映します。遅延と手動極性は独立した直接設定として残ります。

方式、クロス周波数、NTM4のLobe Height、共通目標特性、ON／OFFを変更したら、マルチウェイから再送信して各ウェイの補正結果を更新してください。OFFに戻した場合も、PhaseEQで再計算してマルチウェイへ返却します。

必要タップ数の3次式は分割FIR設計用です。音響ターゲットへの補正FIR長は、測定応答と位相、補正量にも依存します。目標との一致度を最終特性で確認してください。FIR出力がONの場合は、音響ターゲットをONに切り替えると未設定のウェイへ補正用タップ数を仮割り当てします。FIR出力がOFFの場合はOFFを維持し、IIRイコライザーで補正します。全境界の分割FIR出力がなくなると自動クロップはOFFになり、ウェイごとに長さを設定できます。

### 位相構造補償と音響ターゲット

「位相構造補償を自動適用」ONでは、ウェイ・分割方式・周波数・NTM4のLobe Heightの変更に合わせて理論配置の1次／2次オールパスを更新します。「オールパス構造補償」の選択状態には依存しません。適用ボタンは自動時間整合と遅延を実行します。OFFでは、選択した時間基準と構造補償設定に従って従来通り適用します。

#### 位相構造補償の使い方

「位相構造補償を自動適用」のすぐ下にある同名の折りたたみ欄で確認できます。初期状態は閉じています。

**クロス付近の位相差と、合成Gainの山谷を抑える機能です。**

主にIIR LR2／LR4／NTM4を含む3Way以上で使用します。3WayのMidには上下両方のクロスが作用するため、隣接Wayと比べると別のクロスによる位相回転が残ります。不足する位相回転を、各Wayの振幅を保つオールパスで補います。

##### 設定の流れ

1. 分割方式・周波数を設定し、「位相構造補償を自動適用」をONにします。理論配置は測定や適用ボタンの操作なしで更新します。
2. ON／OFFを切り替え、クロス付近の合成Gainと隣接Wayの位相差を比較します。
3. 必要に応じて測定に基づく時間整合を適用します。自動適用がONの間、適用ボタンは時間整合とDelayだけを更新します。
4. 合成波、Delayとバイクアッド使用数を確認し、保存・DSP出力します。ONからOFFへの切替では自動オールパスを解除し、Delay・手動極性・Gainは維持します。

##### クロス付近の変動例

簡易版p.08は、v1.20.32の3Way＋SUB混在構成について、実画面由来の500〜5000 HzのGain・位相をON／OFFで比較しています。以下は別条件のLR4 IIR計算例です。画面例の差をすべての構成へ当てはめず、自分の分割方式・測定・合成で確認してください。

96 kHz・3Way・全境界IIR LR4・重ね代0、スピーカー特性・EQ・追加Delayなし、位相・時間整合の音響ターゲットOFFでの計算例です。実測値ではなく、各クロス点で同じ値となる例を示します。

| クロス周波数 | 隣接Wayの位相差 OFF → ON | 合成Gain OFF → ON |
|---|---:|---:|
| 300 / 3,000 Hz | -16.2° → ≈0° | -0.09 dB → +0.00 dB |
| 1,000 / 3,000 Hz | -55.7° → ≈0° | -1.23 dB → +0.05 dB |

表のGainは0 dBからの差です。1,000／3,000 Hzの例では、各クロスの上下1オクターブにある最大約−2.25 dBの落ち込みが、ON時は約＋0.09 dB以内の変動になりました。300／3,000 Hzの例では、同範囲の変動はON時に0.001 dB未満です。

クロス間隔が近い場合は、補償による違いが大きくなる場合があります。このLR構成では、補償後も多Wayの合成Gainに小さな変動が残ります。各WayのGainを直接増減せず、位相の関係を整えて合成時の落ち込みを抑えます。

合成PhaseにはIIR由来の位相回転が残ります。スピーカー固有の位相、設置距離、室内反射は、測定と時間整合・EQで別に調整します。補償前後の測定と試聴で効果を確認してください。

##### 必要なリソース

直接IIRで適用する場合、追加オールパス1段はSOS／バイクアッドの1枠です。全境界がIIRの場合の、1チャンネル当たりの最大追加段数を示します。

| 構成 | 最大追加段数／チャンネル |
|---|---:|
| 2Way | 0段 |
| 3Way | 1段 |
| 3Way＋SUB／4Way | 2段 |
| 4Way＋SUB | 3段 |

LR2／LR4だけの3WayではLowとHighに各1段、Midは追加なしです。NTM4を含み全境界を直接IIRで分割する3Way構成では、低域から順に分割したHP経路を使い、Lowへ後段クロスの補償APを1段追加します。この構成ではMidとHighに補償APは追加しません。FIR・スルー・音響ターゲットを含む構成では、各Wayの隣接境界だけで分割し、離れたIIR境界の位相はAPで補います。NTM4の補償APのQ値は、その境界のLobe Heightから自動計算します。FIR・スルーの境界自体からAPを生成せず、構造補償のためにHPを追加しません。直接IIRで適用する場合、この機能だけで追加FIRタップは不要です。出力先のバイクアッド枠とオールパスへの対応を確認してください。

このチェックは設定済みDelayを変更しません。オールパスには周波数ごとの群遅延があり、LR4用1段の中心1 kHz付近では約0.45 ms（96 kHz時）です。一定時間を全周波数へ加えるDelayとは区別して確認します。

「位相・時間整合：音響ターゲットに反映」をONにすると、オールパスを直接出力へ追加せず、PhaseEQの目標へ渡します。測定を適用し、補正を設定・更新して返却してください。この経路では補正FIRの長さと実現精度も確認します。

#### 音響ターゲットと補正結果の返却

「位相・時間整合：音響ターゲットに反映」ONではオールパスをPhaseEQの目標へ含め、マルチウェイとPhaseEQの直接オールパス出力から除外します。OFFでは直接IIRとして出力します。時間整合遅延はマルチウェイに残します。

LR2の自動極性補償は帯域分割側の音響ターゲットON／OFFへ追従します。手動極性は独立して直接適用します。PhaseEQの完全な出力帯域分割／Combined IIR係数には必要な極性を含むため、同じ極性反転を外部DSPで重ねないでください。

補正結果が未返却、または設定変更後の更新待ちでも、FIRの理論遅延差を補償して再計算し、最終FIRを確認・保存できます。位相目標への補正は返却待ちとして表示します。ONで目標へ移したオールパスは直接出力から除外したままです。返却済みの補正がある場合は現在の処理に残るため、新しい条件との一致を確認してください。

補正を反映するには、未返却の場合はPhaseEQで測定を適用し、補正を設定・更新して返却します。設定変更後は対象チャンネルをPhaseEQへ再送信し、補正結果を更新・返却してください。古い条件の補正FIRは適用完了と扱いません。送信・編集中・返却・測定の状況は「PhaseEQでチャンネルを編集」の一覧で確認します。「3. チャンネル設定」の独立したPhaseEQ連携欄は廃止しました。

### バッフル補正のFIR／IIR自動選択

設定項目2でバッフル補正をONにすると、現在のチャンネル構成から実現方式を自動選択して画面に表示します。

- 対象の全チャンネルにFIRがある場合：全チャンネルをLinear-phase FIRで補正
- FIRなしチャンネルを1つでも含む場合：全チャンネルを共通IIR ハイシェルフで補正

同一システム内でバッフル補正方式だけをFIR／IIR混在にはしません。IIR方式では実現した周波数、ゲイン、Qを区間 2、チャンネル一覧、帯域分割・設計応答で確認できます。位相・時間整合、バイクアッド使用数、作業バックアップ、実機DSP用パッケージにも同じIIR SOSを使用します。

IIR方式はFIRのゲイン特性を近似しますが、最小位相のため絶対位相と群遅延はFIR方式と異なります。全チャンネルへ同じIIRを適用するため、バッフル補正によるチャンネル間の相対位相差は作りません。

### 帯域分割方式を選ぶ

各境界は高域側からSUB側へ並び、`分割方式 → クロスオーバー周波数 → FIR周期数 → カイザー窓β値`を一つのまとまりとして表示します。周期数は2.70〜15.00（小数点以下2桁表示）、β値は7.0〜16.0で設定します。範囲外の値を含む設定を読み込むと下限または上限へ補正します。IIRまたはスルーを選んだ境界ではFIR周期数とβ値を保持したまま使用不可にします。

`クロスオーバー重なり [oct]`は各境界の`詳細設定：重ね合わせ`を開いた場合だけ表示します。

外部のパッシブ／アクティブネットワーク適用後をマイク測定した場合は、対象境界で **スルー（外部で帯域分割済み）** を選びます。その境界にLP/HPを追加せず、EQ・ゲイン・極性・遅延は引き続き利用できます。全境界がスルーの場合、自動の位相・時間整合は無効です。時間調整には各チャンネルの遅延を使用します。内部FIR/IIRとの混在時は自動整合を利用でき、クロス周波数を解析位置として使います。外部方式を推定したLR極性補償やオールパスは追加しません。

境界ごとに次のいずれかを選択できます。

- `カイザー窓リニアフェーズFIR`：周期数、β値、重ね合わせで調整する直線位相FIRです。β値の下に目標減衰とタップ数の目安を表示します。タップ数はFs÷クロス周波数×周期数を生成処理と同じ方法で奇数化した値です。
- `LR2リニアフェーズFIR`：LR2の振幅形状を直線位相FIRで生成します。
- `LR4リニアフェーズFIR`：LR4の振幅形状を直線位相FIRで生成します。
- `LR2 IIR（Biquad）`：1バイクアッドのIIRです。
- `LR4 IIR（Biquad 2段）`：2バイクアッドのIIRです。
- `NTM4 IIR（Biquad 2段）`：ノッチを持つ2バイクアッドのIIRです。Lobe Heightで分割形状を調整します。
- `スルー（外部で帯域分割済み）`：その境界の追加LP／HPなしで測定応答を使用します。

#### LR2 FIRのタップ数

リニアフェーズLR2 FIRは、LP・HPそれぞれの目標応答が−80 dB幅以上となる範囲を、5 Hz〜ナイキスト周波数で評価します。最大誤差0.05 dB以内となる奇数タップ数を自動算出し、帯域分割FIRの生成処理に使用します。PhaseEQ補正用の0指定は、その長さ×2＋1を仮割り当てします。周期数・β値は使用しません。LR2でも手動タップ長を指定でき、0は自動算出した実生成長×2＋1を補正用に仮割り当てします。

自動クロップON時は手動指定を使用しません。手動で短縮した場合は、自動算出時の誤差条件を維持できるとは限らないため、生成後の周波数特性を確認してください。自動クロップは最終FIRの安全境界を評価するため、帯域分割FIR長を固定下限にしません。

96 kHz・重ね合わせ0・クロス周波数20 Hz〜20 kHzでは、基準5.3周期に3次補正を掛けてタップ数を求めます。`x = クロス周波数Hz / 1000`、`K = max(1, −0.002812x³ + 0.088255x² − 0.266863x + 1)`として、`96000 / クロス周波数Hz × 5.3 × K`を現行の規則で奇数化します。

余裕代5%の近似式を使います。生成後も誤差を確認します。不合格の場合や適用範囲外では従来の数値探索を使用します。

表示する誤差はEQ合成・出力調整前の境界FIRを数値評価した値です。全周波数での数学的な最小タップ数の保証ではありません。自動探索上限32,767 タップまでに条件を満たせない場合は理由を表示して生成を停止します。旧割り当ては旧アルゴリズムで再現し、マルチウェイで新たに送信すると自動算出方式の割り当てになります。

DSP FIR出力をOFFにすると、PhaseEQと同じくFIR LR2→IIR LR2、FIR LR4／カイザー→IIR LR4へ切り替わります。OFF中はIIR LR2／IIR LR4／NTM4 IIR／スルーを選べます。ONへ戻しても方式は自動復帰しません。周波数、音響ターゲット、保存済みタップ値は保持します。

FIR クロスのタップ長0は実生成した分割FIR長×2＋1を補正用に仮割り当てする設定で、正の指定タップ値もそのまま保持します。IIR方式はFIR タップを消費しません。LR2の極性補償を自動化する場合は`LR2極性補償`をONにします。方式を変更した後は再計算し、境界付近のシステム合成と位相を確認します。

2Way、3Wayなどを切り替えた場合、帯域別タップ長はモードごとに保持されます。同名の高域／低域でも別モードの値を上書きしません。

### 帯域分割の設定手順

FIRは、音量の周波数バランスや位相、帯域の分割を調整するフィルターです。本アプリの帯域分割FIRは直線位相を使います。直線位相は、各周波数成分を共通の遅延で扱う特性です。補正用FIRでは位相も調整できるため、FIRがすべて直線位相という意味ではありません。

タップ数はFIRの長さを表す数値です。長くすると必要な特性を作る余裕が増えますが、DSPの処理量や遅延も増えます。必要な特性とDSP上限に合わせて選びます。FIR ONはFIR補正を有効にする操作です。補正内容は手動EQまたは自動ゲイン／自動位相で設定します。

**設定の流れ**

> 出力先DSPの対応・上限を確認 → 分割方式を選ぶ → クロス周波数を設定\
> → 初期値で再計算 → 各帯域と合成グラフを確認\
> → 必要な箇所を一つだけ変更 → 最終タップ数・遅延を確認して保存

1. **方式を選びます。** FIR非対応、または負荷・遅延を抑えたい場合はIIRを選びます。緩やかにつなぐ場合はLR2 IIR、帯域分離を強める場合はLR4 IIRを選びます。FIRでは、緩やかな接続はLR2 FIR、LR形状で分離を強める場合はLR4 FIR、急峻さ・減衰を調整したい場合はカイザー窓を選びます。外部で帯域分割済みの場合はスルーを使います。
2. **クロス周波数を設定します。** 各スピーカーの測定で信頼できる帯域と使用可能範囲に合わせます。周期数・β値・タップ数は初期値を使い、重ね代は0で確認します。LR／NTM4方式で通常の分割を出力する場合は「音響ターゲットに反映」をOFFにします。実測特性を選択した分割目標へ補正する場合はONにし、別の「音響ターゲット補正の使い方」に沿ってEQを設定します。
3. **グラフで確認します。** 各帯域の分離・帯域外の減衰、合成のクロス付近の山や谷を確認します。PhaseEQでは自動表示更新がOFFなら「更新」、マルチウェイでは「再計算」を押します。条件は一つずつ変更し、同じ表示条件で比較します。
4. **出力前に確認します。** 最終FIRタップ数をDSPの上限と比べます。必要タップ数の目安は分割段の長さ、最終FIRタップ数は補正・合成・クロップ後に保存する係数の長さです。映像との同期やリアルタイム用途では、機器側の遅延も含めて確認します。保存した係数を対応DSPへ適用し、実測で最終確認します。

帯域分割フィルター単体の合成Gainが平坦でも、スピーカーを含む実測特性まで平坦になるとは限りません。

### 帯域分割フィルターの使い分け

NTM4 IIRは、マルチウェイとスタンドアローンの分割方式でLR4 IIRの次に選択できます。選択時だけ表示される「Lobe Height (dB)」で、ノッチ後の阻止帯域ピークを−20.0〜−80.0 dBの範囲で調整します。初期値は−36.0 dB、刻みは0.1 dBです。クロス周波数やサンプリング周波数は既存の設定を使い、FIR OFFでも出力できます。

LP／HPは各2バイクアッドです。全境界を直接IIRで分割する3Way以上では前段HPを引き継ぎ、「位相構造補償を自動適用」がONのときに後段の合成位相を揃える補償APを追加するため、出力時の総段数も確認してください。この全境界直接IIR構成で位相構造補償ON・重ね代0・追加補正なしの場合、フィルターの複素合成振幅が理論上0 dBになります。FIR・スルー・音響ターゲットを含む構成では隣接境界だけで分割し、構造補償として離れた境界のHPを追加しません。スピーカー・EQ・Gain・Polarity・Delayを含む応答や混在構成は、合成グラフで特性を確認してください。NTM4でも「音響ターゲットに反映」を使用できます。ONではLobe Heightを含む振幅・位相を目標へ反映し、直接の分割段を外します。LR4と同じ手順で測定を適用し、EQを調整して結果を確認してください。

<a id="lr4-ntm4-selection"></a>

#### LR4とNTM4の使い分け

**LR4は標準の比較基準、NTM4は特定の帯域外成分を抑える選択肢です。** 例えばウーファーの帯域外に分割振動による共振があり、NTM4のノッチ（深く減衰する周波数）と位置が合えば、その成分をLR4より強く抑えられる場合があります。ユニットの種類だけで決めず、測定した共振位置と減衰量で選びます。

| 比較する点 | LR4 IIR | NTM4 IIR |
|---|---|---|
| 向く用途 | 広い帯域外を単調に減衰させる | ノッチ付近の不要な共振を抑える |
| 減衰の形 | 遠方は約24 dB/oct | ノッチ付近で深く減衰し、その後再上昇。遠方は約12 dB/oct |
| 形状の調整 | クロス周波数を設定 | クロス周波数とLobe Heightを設定 |
| 直接分割段 | LP／HP各2バイクアッド | LP／HP各2バイクアッド |

傾きはアナログ原型の目安です。両方式ともクロス点は各約−6.02 dBですが、実スピーカーの合成には測定と位相・時間整合が必要です。NTM4のノッチ後の再上昇や遠方の減衰も確認します。ツイーターの低域保護では、ノッチ付近だけでなく、さらに低い帯域の出力とユニットの許容範囲も確認してください。

#### NTM4の調整手順

1. **LR4で基準を確認します。** 各ユニットの使用可能帯域に合わせてクロス周波数を決め、帯域外の共振、合成振幅、位相を確認します。
2. **NTM4へ切り替えます。** 初期値はLobe Height −36.0 dBです。クロス周波数などの比較条件を揃えます。通常の分割段を出力して比較する場合は`音響ターゲットに反映`をOFFにします。
3. **Lobe Heightを一つずつ変更します。** ノッチが問題の共振に近づくか、ノッチ後の再上昇で別の不要成分が残らないかを各帯域のグラフで確認します。
4. **合成を確認します。** マルチウェイで3Way以上の直接IIR分割を使う場合は`位相構造補償を自動適用`をONにし、再計算します。振幅、位相、群遅延、Delay、バイクアッド使用数を確認します。実測ではクロス付近の軸上・軸外応答も比較します。
5. **保存・出力して確認します。** DSPへ適用した後の実測特性と、レベルを揃えた試聴で判断します。明瞭感や定位などの効果は、ユニット・配置・調整によって変わります。

`音響ターゲットに反映`をONにする場合は、選んだNTM4応答を目標に含め、直接の分割段を外します。ONだけで補正は作成されません。測定と目標を確認してEQを調整し、マルチウェイでは返却後に再計算します。方式・クロス周波数・Lobe Heightを変更した場合も補正を更新します。

#### Lobe Heightの読み方

Lobe Heightは、ノッチ後に再上昇する阻止帯域ピークの高さです。ノッチの深さや全帯域の減衰量を指定する値ではありません。次表は48 kHz・クロス1 kHz・重ね代0での計算例です。

| Lobe Height | HPの低域側ノッチ | LPの高域側ノッチ | 調整の目安 |
|---|---|---|---|
| −20 dB | 約744 Hz | 約1.34 kHz | クロスに近いノッチ、再上昇は大きい |
| −36 dB（初期値） | 約496 Hz | 約2.01 kHz | 最初の比較に使う設定 |
| −80 dB | 約142 Hz | 約6.63 kHz | クロスから遠いノッチ、再上昇は小さい |

−20 dB方向ではノッチがクロスへ近づき、−80 dB方向では遠ざかります。−80 dBほど常に急峻になる、という関係ではありません。ノッチ位置はクロス周波数とサンプリング周波数にも依存するため、使用する設定でグラフを確認します。

マルチウェイの方式選択欄のヘルプでも、現在選択できる方式の利点と使い分けを確認できます。LR／NTM4方式では「音響ターゲット補正の使い方」に選択中の方式の特徴を、スルーでは補足ヘルプに外部分割を活用する説明を表示します。

#### 全方式の比較

帯域分割フィルター単体の性能による比較です。合成Gainは、重ね代0・設計条件と時間基準が揃った場合を示します。

| 方式 | 合成Gain | 合成Phase | 帯域分離・調整の特徴 | タップ数・負荷・遅延 | 選ぶ目的 |
|---|---|---|---|---|---|
| カイザー窓FIR | 平坦性を保つ設計 | 直線位相 | 約24〜192 dB/octが目安。周期数・β値で減衰と遷移幅を調整 | 必要な性能へタップ数を配分できる。急峻・深い減衰には長さが必要 | 直線位相を保ち、LR4より急峻な分離や用途に合う分割形状を実現したい |
| LR2 FIR | 平坦性を保つ設計 | 直線位相 | 約12 dB/octで、隣接帯域を緩やかにつなぐ | 緩やかな形状と必要長のバランスを取りやすい | 緩やかな接続と直線位相を両立したい |
| LR4 FIR | 平坦性を保つ設計 | 直線位相 | 約24 dB/octで、LR2より帯域を分離 | 強い分離と直線位相のため、タップ数・遅延の余裕が必要 | LR形状で帯域分離を強め、直線位相も保ちたい |
| LR2 IIR | 極性補償後に平坦 | 周波数に応じて位相回転 | 約12 dB/octの緩やかな分割 | 分割段は1バイクアッド。FIRタップ不要 | 軽い処理で緩やかに分割したい |
| LR4 IIR | 平坦 | 周波数に応じて位相回転 | 約24 dB/octで、LR2より帯域を分離 | 分割段は2バイクアッド。FIRタップ不要 | 低負荷と帯域分離を両立したい |
| NTM4 IIR | 平坦 | 周波数に応じて位相回転 | ノッチ後の阻止帯域ピークを−20〜−80 dBで調整 | LP/HP各2バイクアッド。3Way以上は自動適用ONで補償APを追加 | ノッチとLobe Heightで帯域外の特性を調整したい |
| スルー | 追加分割なし | 追加分割による位相変化なし | 外部ネットワークの分割特性を使用 | 追加の分割用タップ・バイクアッド不要 | 外部で完成した帯域分割を活用したい |

カイザー窓の約24〜192 dB/octは、96 kHz・クロス1 kHz・重ね代0、−20〜−100 dB間の平均減衰スロープの目安です。LRの固定次数による傾きとは異なり、全区間で一定ではありません。

FIRのタップ数は、必要な減衰・再現精度と、DSP容量・許容遅延の釣り合いで選びます。IIRの隣接帯域が同相でつながることは、合成Phaseが直線になることを意味しません。

LR4 IIRは、広い帯域外を単調に減衰させる標準の比較基準です。NTM4 IIRは、ノッチ付近の共振を抑えたい場合に比較します。Lobe Heightを下げるとノッチはクロスから遠ざかり、再上昇が小さくなります。ノッチ後と遠方の減衰、合成特性も確認してください。

### カイザー窓の使い方

**初期値での確認**

周期数・β値は初期値、重ね代は0から始めます。周期数はFIRの長さ、β値は帯域外減衰の設計目安です。周期数を増やすと生成長が増えます。β値を変えると減衰と遷移幅が変わるため、周期数表も確認します。

> 初期値で再計算 → グラフで確認 → 下の表で次の操作を選ぶ\
> → 一つだけ変更して再計算 → 最終タップ数・遅延を確認して保存

| 確認した結果 | 次の操作 |
|---|---|
| 希望する減衰スロープに合わせたい | 周期数表でスロープとβ値を選び、交点の周期数を入力欄へ直接入力します |
| 帯域外の減衰を深くしたい | β値の「目標減衰」を確認して調整し、周期数表を見直します |
| タップ数・遅延が大きすぎる | 周期数を少し下げ、必要な分離・減衰が保たれるか再確認します |
| 合成グラフのクロス付近に山・谷がある | 隣接帯域の設定、極性、位相・時間整合を先に確認します |
| 必要な特性とDSP上限を満たしている | その設定を保存します |

一度に複数の値を変更せず、変更前後を同じグラフ条件で比較します。

**クロス付近のつながりと帯域外の減衰を、カイザー窓のリニアフェーズFIRで調整するときに使います。**

β値は帯域外減衰の設計目安、周期数はFIRの生成長を決める基準です。β値の「目標減衰」はdB、表の「減衰スロープ」はdB/octで、異なる指標です。

**操作手順**

1. 分割方式をカイザー窓リニアフェーズFIRにし、クロス周波数を設定します。
2. 目標減衰の表示を参考にβ値を選び、下の表で希望する減衰スロープの行とβ値の列から周期数を選びます。例えばβ＝10で−48 dB/octを目安にする場合は4.10周期です。
3. 周期数を入力し、必要な場合だけ重ね代を調整して再計算します。PhaseEQでは自動表示更新がOFFなら「更新」を押します。
4. 各帯域と合成応答でクロス付近のつながり、帯域外の減衰、最終タップ数と遅延を確認します。長いFIRは計算負荷と遅延が増えるため、出力先DSPの上限に合わせて調整します。

#### 周期数と減衰スロープの目安

カイザーHPの周期数だけを調整した比較です。**96 kHz・クロス1 kHz・重ね合わせなし**で、
**−20〜−100 dB間の平均減衰スロープ**を評価しました。表の数値は設定周期数です。

| 減衰スロープの目安 | β＝8 | β＝10 | β＝12 | β＝14 | β＝15 | β＝16 |
|---|---:|---:|---:|---:|---:|---:|
| −24 dB/oct | 2.73 | 3.42 | 4.00 | 4.50 | 4.73 | 4.96 |
| −48 dB/oct | 3.21 | 4.10 | 4.79 | 5.44 | 5.73 | 6.00 |
| −72 dB/oct | 3.85 | 4.85 | 5.73 | 6.50 | 6.88 | 7.21 |
| −96 dB/oct | 4.48 | 5.62 | 6.69 | 7.62 | 8.04 | 8.46 |
| −192 dB/oct | 6.88 | 8.90 | 10.65 | 12.21 | 12.90 | 13.56 |

周期数は2.70〜15.00、小数点以下2桁で表示します。キーボードと±ボタンの増減ステップは0.1です。表のすべての値を設定できます。

- 平均の傾きの目安であり、途中の傾きが一定になることや、LRの振幅曲線との一致を意味しません。
- −100 dBは傾きを測る端点です。生成後は阻止帯域全体の減衰も確認してください。
- 掲載値は小数点以下2桁に丸めています。丸め前の値で測定した平均傾きの誤差は、−24 dB/octのβ＝8・10・12で約1.26・1.05・1.27%、その他は1%以内でした。
- 別のサンプルレートやクロス周波数では、生成後の減衰スロープを確認してください。周期数を細かく変えても、奇数化後のタップ数が同じなら特性は変わりません。

マルチウェイでは「音響ターゲットに反映」の直下にある「カイザー窓の使い方」をクリックして展開します。音響ターゲット補正の使い方と同じ開き方です。ここではカイザー窓の操作手順、周期数・β値と減衰スロープの目安、タップ数・遅延の要点を確認できます。PhaseEQの帯域分割でも同じ説明を展開できます。初めて設定する方への説明・設定フローと方式別の使い分け一覧は、マルチウェイでは「使い方の流れ」の直下、PhaseEQでは出力帯域分割ページの「帯域分割フィルターの使い分け」で確認します。

<a id="multiway-fir-postprocessing"></a>
### マルチウェイ連携中のFIR後処理

PhaseEQの「01 FIRフィルター」では、連携中の後処理は適用せず、操作も無効になります。連携先の案内は画面にまとめ、各ヘルプでは処理そのものを説明します。

| 設定 | マルチウェイでの変更先・動作 |
|---|---|
| DCゲインを正規化 | 「3. チャンネル設定」の各チャンネル。返却された補正FIRを同じ設計ターゲットのDC値へ合わせてから帯域分割と合成します。初期値OFF。 |
| 出力FIRの極性反転 | 「3. チャンネル設定」の極性。マルチウェイではFIR係数への焼き込みではなく、IIRを含むチャンネル全体の極性を設定します。 |
| コサインテーパー窓 | 「保存・出力 → 最終DSP用FIR設定・特性」。最終FIRへ適用します。 |
| FIR自動ゲイン | 「設定 → FIR出力設定」の「各出力帯域の最大ゲインを -0.3 dB に調整」。全帯域へ共通倍率を適用するため、PhaseEQ単独の減衰専用処理とは異なります。 |

DC正規化はFIR OFF時には無効表示となり、設定は保持します。補正FIRが未返却・バイパスの場合は適用しません。補正FIRのDCゲインの絶対値が1e-12未満、または設計ターゲットのDC振幅が1e-9（−180 dB）以下の場合も変更しません。極性とタップ数は保持し、帯域分割の高域通過特性をDC正規化で打ち消しません。旧形式の返却FIRにターゲットDC値がない場合は未適用の案内を表示します。PhaseEQで開き、マルチウェイへ再送信してください。窓や出力ゲインなど後段の処理により、最終出力のDC値は変わる場合があります。

<a id="multiway-final-fir-settings"></a>
### 最終FIRの窓と係数表示（マルチウェイ・FIR専用）

合成は「保存・出力」→「最終DSP用FIR設定・特性」に窓のON/OFFと各チャンネルのゲイン／位相グラフをまとめています。グラフは初期状態で閉じた「最終FIRグラフ」欄にまとめ、必要なときに展開します。窓を切り替えると最終出力係数に追従します。これはFIR単体の特性であり、スピーカー・別段IIR・チャンネルゲイン／遅延・機器固有の量子化を含む総合特性ではありません。位相はタップ中心基準の±180°表示です。

不要なときは「各チャンネルの最終FIR特性を表示」をOFFにできます。


合成接続中はPhaseEQ側の窓をOFFに固定します。合成の「保存・出力」で最終DSP出力用の窓を設定してください。係数グラフは「FIR係数・窓関数を表示」で確認できます。既存の解析用グループ応答はこの最終窓を含みません。

<a id="multiway-fir-output-settings"></a>
### FIR出力とタップ長を設定する

**FIR専用：IIRのみのDSPではFIR出力をOFFにし、タップ長・自動クロップ・出力長統一の調整は不要です。**

1. 設定項目3の先頭にある`DSP FIR出力を有効にする`で使用有無を決めます。
2. ONの場合は、同じ設定項目3で`自動クロップ`または帯域別タップ長を選びます。
3. 帯域分割FIRだけを補助出力する場合は、必要に応じて`出力タップ数を最長フィルターに揃える`をONにします。実機DSP用の最終FIRとの違いは下記を確認してください。
4. `設定 → FIR出力設定`で出力形式と、必要に応じて-0.3 dB正規化を設定します。
5. DSPの最大タップ数、サンプルレート、チャンネル数に収まるか確認します。

実機DSP用の共通最終FIR処理では、保存済みの最長タップ整列設定にかかわらず、係数をゼロ埋めしません。クロップ開始位置と元の時間基準を保持し、経路間の時間差をDSP追加Delayで補償します。帯域分割FIRだけの補助出力では、最長タップ数に揃える設定を使用できます。

`DSP追加Delay`には手動Delayと位相整合Delayも含まれるため、それらが設定されている場合は合計値も確認してください。

FIR クロスに接続する帯域でタップ長0は、実生成した分割FIR長×2＋1を補正用に仮割り当てします。IIRだけの帯域または全帯域で0はFIR OFFです。FIRを使いたい場合は1以上を明示してください。[補足31](#note-31)をご覧ください。

全帯域でFIR帯域分割がない場合、自動クロップはOFF表示となり選択できません。DSP FIR出力をONにして各ウェイのタップ長を指定します。

カイザー窓の分割FIRが長くなる設定では、自動更新中に計算負荷の案内を表示します。計算が重い場合は`自動`をOFFにし、調整後に`再計算`を押してください。案内は計算量の目安です。DSPの上限は、再計算後の最終FIRタップ数で確認します。FIR出力OFFやIIRのみの場合、この案内は表示しません。

### 出力レイアウトを設定する

区間 8は、`System選択 → 出力レイアウト → Channel設定 → System保存 → PhaseEQ編集`の順で表示します。現在編集中のシステムは設定項目8の先頭で常に確認できます。

1. `チャンネル構成`でモノラルまたはステレオを選びます。
2. +SUB構成では共通SUBまたは左右独立SUBを選びます。
3. 各チャンネルの`Compositeへ含める`を確認します。
4. スピーカーパッケージ、ゲイン、極性、遅延を設定します。

生成帯域以外のFIR、スピーカー IR、FRDを追加する場合は、`追加チャンネル入力`の`入力を追加`を押します。モノラルではMain、ステレオでは表示中のL／Rを初期グループとして設定するため、通常はファイルを選ぶだけで追加できます。必要な場合だけチャンネル名、ウェイ、グループ、ゲイン、極性、遅延を変更します。

ステレオの表示はL、R、L+Rです。SUB単独表示はありません。詳細な表示規則は[補足32](#note-32)をご覧ください。

ステレオのグループターゲットは左／右共通です。L、R、L+Rのどの表示から編集しても同じ目標特性を使用し、左右すべてのPhaseEQ 割り当てへ引き継ぎます。

PhaseEQのファイル読み込み欄にある`ターゲットファイルの位相を適用する`をOFFにすると、入力ソースの位相だけを0°として扱います。位相EQで追加した位相調整とゲイン編集は維持されます。保存した目標特性をマルチウェイで使用するときも同じ処理になります。`Target source content = Gain only`を選択した場合も入力ソースの位相は無視されます。

グループターゲットのレベルは、PhaseEQの`目標特性`で編集して保存します。マルチウェイでは保存した目標特性を選び、再送信後に各チャンネルの補正を更新します。

全チャンネルの`Compositeへ含める`がOFFの場合、合成対象がないためシステムグラフは表示されません。少なくとも確認するチャンネルをONにして再計算してください。

### マルチウェイ システム ライブラリへ保存する

1. チャンネルとグループを設定します。
2. システム保存欄の`System名`を入力します。
3. 新規の場合は`新しいSystemとして保存`を実行します。
4. 既存システムの更新は`現在のSystemを更新`を実行します。

システムには管理番号、改訂番号、チャンネル参照、Studio設定を保存します。測定ファイルやFIR実体を複製する機能ではありません。

### PhaseEQでチャンネルを編集する

補正と返却は[⑤ PhaseEQで各ウェイを目標へ近づける](#multiway-phaseeq-adjustment)の順で行います。ここでは送信対象と保存・再開の違いを説明します。

`PhaseEQへ送信（全チャンネル）`は、現在の構成で有効な全帯域チャンネルを一括送信します。追加音声入力や現在の帯域チャンネルに結び付かない過去の返却データは送信対象に含めず、合成用の入力として保持します。`PhaseEQで開く`がグレー表示なら、すでに開いているPhaseEQのタブを使います。

FIR OFFではタップ数を0として送ります。この場合もIIR、目標特性、スピーカー応答、作業セッションは往復できます。[補足31](#note-31)をご覧ください。

同じチャンネルを再度割り当てした場合、新しい割り当てにまだ作業セッションがなくても、そのチャンネルで最後に`マルチウェイへ送信`した編集内容を再開します。一度保存した割り当てを再編集中でも、次に保存するまでは直前の公開結果をマルチウェイのグラフとDSP経路で維持します。別チャンネルのEQや、一度も保存していない割り当ては読み込みません。保存していない編集内容は、別ブラウザやアプリ再起動後の再開対象になりません。

複数チャンネルを編集するときは、チャンネルごとに新しいPhaseEQ画面を開かず、PhaseEQ上部の`Composite Channel workspace → 編集中のChannel`で切り替えます。切替前の未保存編集は、そのブラウザ画面内のチャンネル別ドラフトへ退避され、同じチャンネルへ戻ると復元されます。ドラフトは`マルチウェイへ送信`を押すまでマルチウェイへ反映されず、ブラウザ終了やアプリ再起動をまたぐ保存物でもありません。

切替候補は、マルチウェイが共有した現在のチャンネル構成と発行済み割り当てから作成します。単独編集では直近に表示したマルチウェイ構成、チャンネル編集中はそのシステム・サンプルレートの構成を使用します。過去の構成や無効なチャンネルは表示しません。返却FIRの有無を接続条件にしないため、未返却やFIR OFFでも初回から切り替えられます。更新後はマルチウェイを一度再表示すると、現在の構成がPhaseEQへ共有されます。

### マルチウェイの割り当ての往復を理解する

1. マルチウェイ側でウェイ、グループ、帯域分割、FIR状態、サンプルレート、タップ数を確定します。
2. 割り当てを送ると、PhaseEQは対象チャンネルとマルチウェイ条件を常時表示します。
3. PhaseEQではスピーカー入力、目標特性、IIRイコライザー、FIRイコライザーを編集します。
4. `マルチウェイへ送信`で同じ割り当てへ結果を返します。
5. マルチウェイで再計算し、チャンネル応答とシステム合成を確認します。

割り当て中の帯域分割、極性、SUB構成はマルチウェイ側が正本です。PhaseEQは個別チャンネルを編集し、帯域分割を重ねて返しません。役割分担と保存範囲は[補足30](#note-30)をご覧ください。

### PhaseEQの接続状態を確認する

PhaseEQ画面は次の3モードを区別します。

| 表示 | 用途 | 合成操作 |
|---|---|---|
| `Standalone PhaseEQ` | 単独の新規設計 | 使用不可 |
| `現在編集中のComposite Channel` | 割り当てされたチャンネルの編集・返却 | 使用可能 |
| `Target Edit専用モード` | 選択グループの目標特性だけを編集 | 通常の合成操作と他ページは使用不可 |

割り当て画面にはチャンネル、ウェイ、グループ、状態、短縮IDと`Assignment参照状態`を表示します。`最新と一致`は現在のチャンネルに最後に送信した割り当て、`別Assignmentを参照`は古い割り当て画面です。後者は注意表示だけで、現段階では保存・返却を禁止しません。返却先を短縮IDで確認してください。

マルチウェイのチャンネル一覧では、`Assignment状態`、改訂番号、`接続ID`、`最新ID`、`参照状態`、`PhaseEQ画面`を別々に確認できます。単独編集または目標特性の編集画面を、チャンネル 割り当て接続として数えません。画面の生存確認だけではグラフを再描画せず、実際の返却改訂番号が変化したときだけ1回自動受信・再計算します。

### 単独編集とチャンネルの切替

切り替え後も、切り替え前に表示していたメニューを維持します。単独編集とチャンネルの往復も同じ扱いです。切り替え先でそのメニューが使えない場合は、左側の最も近い利用可能なメニューへ移動します。例えば、FIRイコライザーからFIR OFFのチャンネルへ切り替えると、IIRイコライザーへ移動します。

「編集中のチャンネル」で単独編集またはマルチウェイから送信したチャンネルを選びます。単独編集は独立した編集状態です。戻ると自身の一時退避設定を復元し、退避がない場合は初期設定で開きます。

各チャンネルへ戻ると、その画面で一時退避した最新の設定を、保存済み作業セッションより優先して復元します。FIRのゲイン・位相、IIR、自動EQはそれぞれの編集対象に保持され、他のチャンネルや単独編集の値を共有しません。

別のプロジェクトから新しい割り当てを受け入れると、そのプロジェクトの設定を使用します。古いプロジェクトのチャンネルや入力・EQを混ぜません。チャンネルの編集ではマルチウェイが指定したサンプルレート、FIR ON／OFF、タップ数、帯域分割を使用します。

読込・検証に失敗した場合は元の設定を保持します。接続先を確認し、マルチウェイから割り当てを再送信してください。切替だけでは補正結果を返しません。編集後は「マルチウェイへ送信」を実行します。

一時退避は現在のブラウザーセッション内のデータです。終了前には設定ファイルまたは作業セッションZIPを保存してください。

### グループターゲットを設定する

1. マルチウェイで対象グループと登録済みの目標特性を選びます。
2. 追加・編集が必要な場合は「PhaseEQのTargetを開く」から、単独編集の目標特性画面へ進みます。チャンネルから引き継いだ目標特性を直接編集する操作ではありません。
3. PhaseEQで「新規登録」または「更新」を行います。
4. マルチウェイに戻り、「登録済みTargetを更新」で一覧を更新し、使用する目標特性を選びます。
5. グループターゲット線とシステムの合成応答を比較します。各チャンネルの目標も変更する場合は、現在の条件でPhaseEQへ再送信し、補正結果を返却します。

グループターゲットは比較用の基準線で、合成応答に乗算しません。PhaseEQへ送信すると、選択した目標特性の定義をチャンネルへ引き継ぎます。旧形式の専用編集セッションは互換用であり、通常の操作入口には使用しません。

### 位相・時間整合を実行する

1. 全有効チャンネルとスピーカー応答を確認します。
2. 設定変更後は`再計算`を押します。
3. 時間基準、解析範囲、`All-pass構造補償`を選びます。
4. 外部アプリの距離を使う場合は`外部測定距離`を選び、同じマイク位置から各Driverまでの距離[mm]を入力します。チャンネル数が多い場合は`距離を一括入力`へ画面の表示順にカンマ、空白または改行区切りで貼り付けます。換算には公称音速343.42 m/sを使用し、気温入力は行いません。
5. 表示された最遠基準と換算遅延を確認し、`全Channelの位相・時間整合を適用`を実行します。
6. 解析結果で遅延、オールパス判定、残差を確認します。
7. 適用を取り消す場合は`全Channelを元に戻す`を実行します。直前の自動遅延／オールパスを復元し、自動がOFFでもインパルスを含むグラフを再計算します。手動遅延は維持します。

オールパスはゲインを変えず、特定の周波数範囲の位相と群遅延を変えるIIRフィルターです。通常の遅延が全周波数へ同じ時間差を与えるのに対し、オールパスはIIRクロスを通った帯域と通っていない帯域の位相回転差を補います。[補足36](#note-36)をご覧ください。

「位相構造補償を自動適用」がOFFの場合は、使用するDSPでオールパスを実装できれば`理論配置`、実装できなければ`使用不可`を選びます。ONの場合は理論配置が自動適用され、この選択には依存しません。整合処理はゲインを変更せず、表示中のL／R／L+Rに関係なく全有効チャンネルを一括処理します。

表示するチャンネルがL／R／L+Rのどれでも実行対象は変わりません。理論中心、因果化Offset、遅延の扱いは[補足33](#note-33)をご覧ください。

スピーカー応答を使う場合は、整合対象の全チャンネルへ設定してください。一部だけ設定した状態では、入力未設定チャンネルを誤って0 ms基準にしないため実行できません。全チャンネルが未設定の場合は、スピーカーの音響時間差を含めないFilter-only整合として実行できます。

`自動選択`は、全チャンネルで有効なPhaseEQ ツイーター基準があれば優先し、なければクロス近傍の位相から時間差を推定します。`外部測定距離`はこれらより優先されます。最も遠いDriverを基準に、近いDriverへだけ非負遅延を追加します。測定基準点がチャンネルごとに異なる距離は混在させないでください。

時間基準はシステム全体で1種類だけ使います。`外部測定距離`を選んだ場合はツイーター基準を重ねず、全チャンネルの距離が揃うまで適用しません。`自動選択`でもツイーター基準が一部チャンネルだけ有効な場合は部分適用せず、システム全体をクロス位相推定へ切り替えます。

### 4種類の応答を区別する

- `Crossover / Design Response`：スピーカーとPhaseEQを反映した各ウェイと、設計段階のウェイ Sumを確認します。
- `Channel Response`：ゲイン、極性、遅延、整合処理を含む個別の最終チャンネルを確認します。
- `System Sum`：同じ出力系統に属する有効チャンネルを、ゲインと位相を含む複素応答として合成した結果です。
- `グループTarget`：システムの目標を比較する表示線です。チャンネル応答やシステム合成へ乗算しません。

システム合成は各線のdB値を足したものではなく、位相差による加算と打ち消しも含みます。暗黙のレベル正規化は行わないため、山谷がある場合はチャンネル ゲインだけでなく、極性、遅延、位相、クロスも確認します。

### グラフで合否を確認する

`表示するチャンネル`でL、R、L+Rを切り替え、次の順で確認します。

1. ゲイン：各ウェイの接続と、クロス付近のシステム合成に大きな山谷がないか確認します。
2. 位相：通過帯域とクロス付近で、隣接ウェイの位相関係を確認します。
3. 群遅延：通過帯域内の段差や異常な突出を確認します。
4. インパルス応答／ステップ応答：極性、peak位置、長い前後の尾を確認します。
5. ウェーブレット：帯域ごとの到達時間と時間方向の尾を確認します。

ゲインが小さい領域の位相と群遅延は不安定になりやすいため、`位相／群遅延のゲイン下限`以下を合否判定に使いません。グループターゲットは比較線であり、チャンネル応答やシステム合成へ乗算されません。

PhaseEQとマルチウェイは、入力=青、目標特性=橙、処理後=緑、位相補正=紫を共通の意味色として使います。マルチウェイの`PhaseEQ EQ`はゲインを青の破線、位相を紫の一点鎖線で表示します。色だけでなくラベルと線種も併用し、Hiなど各ウェイのPhaseEQ FIR／IIRが反映されていることを確認してください。

### リバースヌルを一括確認する

リバースヌルは、隣接Wayの一方を反転した合成の谷から、クロス付近の重なりと位相関係を確認する表示です。

**操作手順**

1. 結果グラフの`表示するチャンネル`を選び、`Magnitude`に切り替えます。
2. `リバースヌルを重ねて表示`をONにし、通常の`System Sum`と破線の`Reverse Null`を比較します。ON／OFFは確認線の表示だけを変え、保存データとDSP出力は変更しません。
3. 各クロス付近の谷の位置と深さを確認します。L+Rでは左右それぞれの確認線を表示します。
4. 確認後はOFFにして確認線を解除します。

**極性の扱い**

有効なWayの現在の応答を低域から維持・反転・維持…として合成します。3WayではLow維持／Mid反転／Hi維持、SUB付きではSUBから交互に反転します。Gain・Delay・設定済み極性を含む編集データ、保存データ、DSP出力は保持されます。確認用のON/OFFは保存対象に含みません。

**谷の見方と調整**

クロス付近で隣接Wayの音量が近く、通常合成で位相が揃っていれば、一方の反転で打ち消しが生じ、深い谷を確認できる場合があります。深さだけで整合の良否を決めず、通常合成と位相も併せて確認します。

谷が浅い場合やクロス位置からずれる場合は、隣接WayのGain・Delay・設定済み極性と、Phaseグラフの位相関係を確認してください。調整する場合はChannel設定を一項目ずつ変更し、通常のSystem Sumも比較します。Phaseでは確認用の線を表示せず、Magnitudeへ戻すと現在のON/OFFに従って表示します。

他Wayの重なりや分割方式によって谷の深さは変わるため、一律の合格dB値は設けません。実機での結果は、出力後の実測応答で確認してください。

**使用条件**

Magnitudeで有効なWayが2つ以上ある場合に使用できます。有効なWayが1つの場合やMagnitude以外では操作できません。帯域情報の不足などで表示できない場合は、警告内容と各Channelの構成を確認してください。通常のSystem Sumは引き続き表示します。

### 全帯域とSUBを確認する

`全帯域`は帯域境界がないため、位相・時間整合の対象外です。FIRを使う場合はFIR出力をONにし、全帯域のタップ長を1以上へ設定します。

`Fullrange+SUB`は全帯域 ハイパスとSUB ローパスの1境界を生成します。LまたはRでは、その側の全帯域と対応するSUBを一度だけシステム合成へ含めます。共通SUBも二重加算しません。

SUB単独の表示区分はありません。L／Rで片側の接続を確認し、L+Rで左右のウェイと左右別システム合成を並べて比較します。ウェーブレットも同じ表示区分です。

### 保存・出力を選ぶ

マルチウェイの下部では、用途ごとに出力を分けています。

- `解析用Group応答を保存`：グラフ確認や解析に使う応答、IR、レポートです。
- `作業バックアップを保存`：別環境または後日に同じ作業を再開するZIPです。
- `実機DSP用パッケージを保存`：miniDSPなどへ投入する最終出力です。
- `補助出力：帯域分割FIR係数だけを保存`：帯域別FIRだけが必要な場合に開きます。

システム ライブラリへの保存は設計改訂番号の管理です。ファイルをダウンロードする操作ではありません。

### 実機DSP用パッケージを出力する

1. `出力先DSP`を選びます。
2. `デバイスプロファイル`を選びます。
3. チャンネル別互換性表と警告を確認します。
4. `実機DSP用ZIPをダウンロード`を1回押すと、生成して保存します。互換性エラーがある場合は押せません。

DSPまたは元設計を変更した場合は、画面更新後にダウンロードします。作業バックアップZIPも準備操作なしで取得できます。FIR OFF チャンネルの出力規則は[補足35](#note-35)をご覧ください。

<a id="optional-stereo-link"></a>
### 任意操作：Stereo Linkでチャンネル間のEQ設定を共有する

**基本の調整を終え、複数チャンネルへ同じEQ設定を共有したい場合だけ使います。通常の設計やDSP出力に必須ではありません。** 必要に応じて、[Stereo Linkの操作](stereo-link.md)をご覧ください。

Stereo Linkは、Multiwayの選択した複数チャンネルのEQ設定を共有する機能です。PhaseEQではリンクON/OFFと`⚙`の設定を、編集対象の選択と同じ行の右側に表示します。MultiwayではPhaseEQへ渡すチャンネルの操作付近に表示します。Stand-aloneは1チャンネルの単独編集とし、左右選択・チャンネル追加・リンク操作は表示しません。

1. チャンネルを選択し、`⚙`を開きます。
2. リンク先チャンネル、共有する設定（IIR EQ／FIR EQ・Auto EQ設定／Target設定）、設定の採用元を選びます。採用元は現在のチャンネルまたはリンク先から選べます。
3. 「選択したチャンネルへリンク」を押し、影響するチャンネルと採用元を確認します。
4. 「OK・設定を書き換える」を押すと、選択したチャンネルが同じ共有設定を編集する状態になります。キャンセル時は既存設定を保持します。

リンク中は「🔗 Stereo Link · Linked」、独立編集時は「⛓ Stereo Link · Unlinked」と表示します。共有設定はどのリンク先からも編集できます。

解除するときはStereo LinkをOFFにし、確認画面でOKを押します。その時点の共有設定を各チャンネルへ独立したコピーとして残します。解除後の変更は他のチャンネルへ反映しません。

測定、Speaker Response、IR、Delay、Polarity、Channel Gain、マイク校正、帯域分割条件、サンプルレートと各チャンネルの出力条件は共有しません。

Multiwayの設定・Working Sessionにはリンク状態を保存します。旧版のStand-alone左右リンク設定を単独編集へ読み込む場合は、保存時に選択していたチャンネルの実効EQと入力条件を引き継ぎ、1チャンネルの独立設定として編集・保存します。元の設定ファイルは変更しません。

画面を開き直したときやチャンネルを切り替えたときは、現在の共有設定を読み込みます。設定ファイルを明示的に読み込む場合は、保存されたEQと選択チャンネルのリンク構成を確認し、OKで復元します。無関係なグループは変更しません。保存されたチャンネルが現在のシステムに存在しない場合や編集対象と一致しない場合は復元を停止します。リンク情報がない従来の設定は独立設定として復元します。

編集中に別の画面でEQやリンク構成が変わった場合は、自動で上書きせず編集案を保持します。「最新の共有設定を読み込む」で最新値へ戻すか、「編集中の設定の反映を確認する」で影響するチャンネルを確認してから反映してください。設定ポップオーバーは確認画面と同時に表示しません。

Multiwayではチャンネル固有の条件と測定に基づいてFIRを作るため、リンク設定の変更後は対象チャンネルをPhaseEQで再生成し、Multiwayへ送信してください。古いEQ設定で作られた返却FIR／IIRが残っている場合は警告し、合成処理への使用を停止します。

確認中に別の画面で設定が変わった場合は、古い変更案を適用しません。キャンセルし、最新状態で改めてリンク内容を確認してください。

## 13. マイク測定：連続ESSで測定する

### ガイド測定：標準音源から始める

`マイク測定`の初期画面は「ガイド測定」です。フルレンジ／ツイーター、左右同時／左のみ／右のみを選ぶと、使用する曲番号が決まります。「測定する側」は初回に「左のみ」を選択表示し、保存済みの設定がある場合はその選択を復元します。音源は44.1 kHz・16 bit・ステレオWAV（CD用）に統一しています。48 kHz・24 bit版は生成しません。

初回起動時に標準15曲を順次準備し、全曲の準備完了後に全15曲をまとめてダウンロードできます。CDは全15曲を曲順表どおりに収録すると案内番号と実際の曲番号が一致します。

**音源ZIPの保存手順**

1. **マイク測定用音源のダウンロード**を押します。ダウンロードは全曲一括のみです。
2. ボタン内でZIPを準備し、そのままダウンロードを開始します。別の準備ボタンはありません。全15曲は約371 MiBです。保存結果はブラウザーのダウンロード一覧で確認してください。
3. **ブラウザーで保存完了を確認してから「接続・配置へ」進んでください。** この時点で準備ZIPのメモリーを解放します。音量確認へ進む場合も同様です。暗騒音取得・測定の開始前には、不要になった転送用ZIPも解放します。測定実行中には削除処理を行いません。

一時ZIPはメモリー内だけで扱い、ディスクには残しません。元のWAV音源とブラウザーに保存したZIPは削除しません。「音源を選ぶ」に戻って再ダウンロードする場合は、ボタンを押した時にZIPを再生成します。別のブラウザー接続が同じZIPを使用中の場合、その接続の転送用データは保護します。

### 初回必須：音源の準備

初回の測定前に、必ず測定用CDまたはWAVプレーヤーの音源を準備してください。一度準備すれば、次回からは同じ音源を使えます。

#### 測定用CDの作り方

1. 上のボタンで音源ZIPをダウンロードし、保存完了後に展開します。
2. 展開したフォルダーの「曲順表.txt」とWAV音源15曲を確認します。
3. CD作成ソフトで**オーディオCD**を選び、WAV全15曲をファイル先頭の番号順（01〜15）に追加します。ZIPやフォルダーをそのまま書き込むデータCD形式は使いません。
4. 曲順を確認して対応する空のCDに書き込み、使用するCDプレーヤーで曲番号を指定できることを確認します。再生確認は音量を下げて行い、その後停止してください。

**準備完了後**は下の測定項目と測定する側を選び、「接続・配置へ」進みます。

#### WAVプレーヤーで使う

1. 上のボタンで音源ZIPをダウンロードし、保存完了後に展開します。
2. 展開したWAV音源15曲を、WAV対応プレーヤーに取り込みます。
3. 「曲順表.txt」を参照し、ファイル先頭の番号（01〜15）で音源を選べることを確認します。
4. シャッフル・自動音量調整・曲間クロスフェードをOFFにして、再生を停止します。

**準備完了後**は下の測定項目と測定する側を選び、「接続・配置へ」進みます。

**毎回の測定前に確認**

再生機器とスピーカー、マイクの接続・配置を確認し、再生を停止してから「接続・配置へ」進んでください。片側測定では反対側をミュートし、ツイーター単体では保護フィルターを確認します。暗騒音取得後、画面の指示に従ってNo.01で音量を合わせ、指定された測定曲を再生します。全15曲の連続再生は不要です。

**準備後の測定手順**

1. 音源を選び、「接続・配置へ」進みます。
2. 保存済みマイク個体と校正を選び、出力ごとの接続先、近接1 cm／30 cm／1 m／試聴位置、マイクの向きを確認します。
3. 外部再生を止めて暗騒音を取得します。No.01の全帯域ノイズを再生して音量を調整します。片側測定では非対象側を個別ミュートします。
4. 再生を停止して指定ESS曲へ切り替え、音量を固定したまま「測定を待機」を押し、プレーヤーで再生します。Pilot確認後、同条件で採用できた3件を統合します。
5. 取得終了後に外部再生を停止し、グラフと帯域を確認して「測定結果を保存」。片側応答は「PhaseEQで使う」へ進めます。左右同時は合成応答の確認用として保存します。

マイクの音量キャリブレーションは要求しません。現在のガイドはUMIKのSens Factorと入力ゲインを解決できる構成に対応し、ゲイン読取りはCoreAudioに依存します。OmniMic等の未対応感度形式やゲインを確定できない構成は理由を表示します。歪み・残響・相対測距の専用解析ガイドも準備中として表示し、取得は開始できません。

測定中の音量異常・入力切断では取得を止め、外部再生停止と準備への復帰を案内します。再確認後は0/3から取得し、別条件の結果を混ぜません。全帯域ノイズの低レベル化だけでは裸のツイーター等を保護できないため、単体測定では保護フィルターの接続を確認してください。

### 詳細・従来の測定

以下は「測定画面」で「詳細・従来の測定」を選んだ場合の操作です。旧音源・自由設定と従来の入力方式を使用できます。ガイドの共通No.01とは別の手動生成経路です。

- 目的：既知ESSを外部再生し、連続録音からshot単位の応答を作成します。
- 場所：`マイク測定`です。
- 完了：測定結果を測定データへ保存、または測定データ セッションZIPへ保全します。

### マイク入力：入力機器を選ぶ

1. サンプルレートを選びます。
2. `測定入力機器`で`USBマイク`または`アナログマイク＋オーディオインターフェース`を選びます。
3. `ESS基準`で、実際に再生するESSファイルの実波形を使うか、PhaseEQ内部の公称ESSを使うか選びます。
4. マイク機種を選びます。既知USBマイクだけAuto-detectを使用できます。
5. USBマイク本体、またはオーディオインターフェースと物理入力チャンネルを選びます。
6. `録音構成`で実際の録音構成を確認します。アナログマイクはmono、対応USBマイクは同じマイク信号の2ch dual-gainです。
7. 入力状態を確認します。

`ESSライブラリの実波形`は、WAV／FLACから抽出した実際の再生波形を解析基準にします。`PhaseEQ公称ESS`は設定値から内部生成した理論波形を使います。この選択はマイク方式や録音ch数を変更しません。

同じ設定を使う別PhaseEQがある場合は、測定前に停止してください。CoreAudioなどの入力競合を避けるためです。

### ESS設定：測定信号を準備する

1. `ESS生成`または`ESSライブラリ`を選びます。
2. 生成プリセットまたは登録済みESSを選びます。
3. 出力チャンネルを確認します。
4. ESSとmanifestを準備します。

生成WAV／FLACは外部プレーヤーで再生します。PhaseEQは測定信号の自動再生や実機DSPの自動変更を行いません。

IR peak方式とタイミング marker方式の違いは[補足40](#note-40)をご覧ください。

### 測定開始・収録設定：音量を確認する

1. `音量確認用ノイズ`では、通常は`ピンクノイズ・スピーカー 500–2,000 Hz`を選びます。SUBは`ピンクノイズ・サブウーファー 30–80 Hz`を選びます。
2. 出力する左右と`ノイズRMS dBFS`を確認し、3秒のWAVを生成します。既定レベルは選択ESSのPeakをRMS換算した値です。
3. アンプまたはDSPの音量を十分に下げてから、PhaseEQの測定を開始します。
4. 最初の5秒間は暗騒音測定のため無音を保ち、完了後に音量確認WAVを再生します。
5. リアルタイム入力レベルのRMSバー、Peak、Headroomを見ながら調整します。校正済みの場合は音圧レベル約75 dB SPL、入力Headroomは6 dB以上を目安にします。
6. ノイズを止め、正式測定にはESSを再生します。音量確認WAVはESSライブラリ、測定結果、位相解析へ入りません。

音量確認信号はPink noiseだけを使用します。リアルタイムバーはRMSをバー、PeakとClippingまでのHeadroomを数値で表示し、約0.1秒ごとに更新します。USBマイクではdBFSが低く表示される場合があるため、dBFS値だけで音量を上げず、SPL、S/N、Headroomを合わせて判断してください。

### ツイーター基準の距離測定を準備する

`ツイーター基準・外部ESS`は、固定ツイーターの基準音と測定対象のESSを必ず左右別の出力で再生します。
`マーカーL / ESS R`または`マーカーR / ESS L`で生成したPhaseEQ ESSとmanifestを選択してください。`左右両方`、
`ESSと同じ`、同一側出力、manifestのない音源では開始できません。

PhaseEQは外部DSP、Audio Interface、アンプを自動設定しません。画面の`距離測定の外部機器セットアップ`を上から確認します。

1. 画面に表示されたmarker側出力を固定ツイーターへ接続します。
2. 反対側のESS出力を測定対象へ接続し、他のスピーカーをMuteします。
3. ツイーターの保護HPFまたは保護コンデンサーを有効にします。
4. 時間整合用測定ではDSP 遅延、オールパス、補正FIR、自動 EQをOFFにします。
5. スピーカー保護に必要なクロスだけを残します。
6. `DSP／オーディオ設定メモ`へ出力番号、HPF、クロス、ゲイン、Mute、遅延状態を記録します。
7. 三つの確認欄をONにして開始します。
8. 最初は低い再生音量でPink noiseのリアルタイムバーを確認し、その後のPilot ESSでS/N、Clipping、再生レベルを最終確認します。

ESSまたは左右ルーティングを変更すると、誤った条件の流用を防ぐため確認欄は自動的に解除されます。基準ツイーターを
測定対象にする場合もmarkerとESSの論理出力は分離し、外部DSP側で両方が同じ物理ツイーターへ届くよう設定します。

最終遅延やオールパスを有効にした状態の測定はシステム確認用です。その結果をマルチウェイの自動時間整合へ再使用すると
補正が二重になるため、ツイーター基準のSolver入力には使用しないでください。

### マイク校正・音圧校正：校正を設定する

1. マイク校正を選びます。
2. 校正角度を確認します。
3. 範囲外の扱いを選びます。
4. USBマイクでは、マイク校正の適用だけで測定を開始できます。絶対音圧が必要な場合は、メーカー感度または音響校正器による音量校正を追加します。
5. アナログマイクでは、`オーディオインターフェース入力`と物理入力chを選び、音量校正方法を選びます。
6. 音響校正器がある場合は`Acoustic calibrator`を選び、校正器音圧とマイクプリアンプゲインを入力して`マイク感度を1秒で推定`を実行します。
7. 音響校正器がなく音圧計がある場合は`SPL meter comparison`を選びます。`ピンクノイズ・スピーカー 500–2,000 Hz`を一定音量で再生し、音圧計をZ/Flat・Slow、対応しない場合はC・Slowに設定します。
8. 音圧計とマイクを同一位置へ順番に置くか、両カプセルを隣接させます。音圧計の読みを`基準音圧 dB SPL`へ入力し、再生を止めずに`音圧計比較を1秒取得`を実行します。
9. マイクRMSと音圧計の差から求めた音圧変換offsetを確認し、`音圧校正を採用`を押します。

マイク校正は周波数別ゲイン／位相補正、音量校正はdBFSから音圧レベルへの変換であり、別の校正です。USBマイクは前者を必須、後者を任意とします。アナログマイク＋オーディオインターフェースは両方を必須とし、`Acoustic calibrator`または`SPL meter comparison`の採用を「音量方向のマイク校正済み」として測定ロックを解除します。

入力機器、物理ch、サンプルレート、入力ゲイン、校正方法、基準音圧を変更すると採用済み音量校正は自動的に無効になります。OSから読めない物理ゲインノブは自動検出できないため、校正後は変更しないでください。音圧計比較では、音圧計の読取りからマイクの1秒録音が終わるまでスピーカー音量を固定します。校正確定後の再生音量変更は測定値へ反映されるため、校正自体を無効にはしません。

入力機器名だけではUSBマイクと一般的なオーディオインターフェースを確実に区別できません。既知USBマイクはマイクDBから自動判定し、アナログマイクは`マイク機種`で機種を明示選択します。マイク校正・音圧校正範囲外でも測定自体はナイキスト周波数まで継続できます。補正方法と信頼度を確認して使用してください。

### ゲート/合成：時間窓を設定する

1. Gate条件を設定します。
2. Full／Gated／Mergedのプレビューを確認します。
3. 自動Mergeが成立しない場合はFullを使用します。

Mergeは派生結果です。FullとGatedが主結果として保持されます。

### 測定開始・収録設定：測定を開始する

1. 品質判定を選びます。
2. 開始前の不足条件を確認します。
3. ESSを再生します。
4. `開始`を押して録音します。
5. 必要なshot数を取得したら`停止`を押します。

開始が無効な場合は、ボタン直下の案内を上から解消します。ESS、入力機器、サンプルレート、チャンネル、校正条件などが表示されます。

### 測定結果：結果を確認する

`生データ`、`最終結果`、`ノイズ低減済み`と、ゲイン／位相、インパルス応答、ウェーブレット、アプリ診断を切り替えます。採用 shot数、Coherence、Repeatability、アライメントを確認してください。

品質判定と標準生成の基準は[補足41](#note-41)をご覧ください。

### セッション：結果を保存する

1. 保存する応答とチャンネルを選びます。
2. 測定データ名と用途を確認します。
3. `ライブラリへ保存`で測定データへ登録します。
4. 測定パッケージには統合未校正IRと別校正データを保存します。生データ録音と各回のIRは含みません。通常の利用ではライブラリ保存を使い、パッケージは移動・バックアップ時に使用します。

一時保存と長期保存の違いは[補足42](#note-42)をご覧ください。

### 測定データの保存と校正

#### 保存・復元できる範囲

結果画面「ライブラリへ保存」で標準統合結果を保存し、ライブラリ「入力に使用」でPhaseEQへ適用します。ライブラリ「測定原本・校正・外部出力」では周波数偏差を変更でき、校正済みIR・FRDを出力できます。位相校正・個体感度・入力ゲインは測定時設定を保持します。

保存対象は常に標準です。Shotやノイズ低減済みの表示選択で、保存される原本は切り替わりません。測定パッケージのダウンロードは停止・統合後に利用できます。保存済み原本からGateを変更できますが、各ショットの再選定や録音再解析はできません。

通常応答のガイド測定は、ノイズ確認→ESS Pilot→3件取得→自動終了・統合IR保存に対応します。標準15曲のCD版（44.1kHz／16bit）は起動時に準備します。歪み・残響・相対測距のガイド解析は未対応です。従来の詳細測定では1件以上でも保存できます。

#### 保存するもの

測定結果ごとに、統合した未校正IRを1本保存し、マイク校正データと測定条件・時間情報を別に保持します。録音生データと各回のIRは一時処理用とし、恒久保存しません。

通常は結果をライブラリから選ぶだけで、校正済み応答をPhaseEQへ渡します。マルチウェイでも同じ校正済み応答を使い、マイク校正を重ねて適用しません。校正データを変更するときは、保存した未校正IRから再計算する仕様です。各回の採否変更や録音からの解析やり直しは対象外です。

#### 外部へ渡すもの

| 出力 | 内容 |
|---|---|
| FRD | マイク校正済みの周波数応答 |
| 測定IR | 必要時に生成した校正済みIR。校正状態・音圧基準・時間原点を記録 |
| 測定パッケージ | 別PCへの移動・バックアップ用。未校正統合IR、別校正データ、測定条件・時間情報 |

測定パッケージは通常利用には不要です。外部媒体だけに原本を置いた場合、その媒体を接続するか、必要データをローカルに保持して利用します。参照先だけが残っていても再計算はできません。

#### 校正値の意味

マイク校正ファイルの値はマイクの偏差です。測定値から偏差を引きます。偏差+3 dBなら−3 dB補正します。入力時に利用者が符号を反転する必要はありません。感度と入力ゲインは音圧換算のための別情報です。


<a id="preferences"></a>
## 14. 環境設定：共通解析条件を設定する

- 目的：PhaseEQ全体で共有するAnalysis FFTを設定します。
- 場所：`設定 > 環境設定`です。
- 完了：適用後に`共通設定を保存して完了`で正式保存します。

1. `共通解析FFT`を選びます。
2. `解析FFTを適用`を押します。
3. 予測グラフの更新を確認します。
4. `共通設定を保存して完了`を押します。

適用中の共通解析FFTは、Speaker Packageの読み込み、マルチウェイのチャンネル切り替え・自動Workspace復元、サンプルレート変更で保持します。チャンネル側の旧設定や既定値で上書きしません。設定ファイルを明示的に読み込んだ場合は、そのファイルのFFT値を復元し、選択欄も復元値に揃えます。

FIRタップ長は「書き出し」の`書き出し → FIRタップ数`で指定し、`FIRタップ数を適用`で適用します。適用後も書き出し画面に留まります。形式やダウンロードの表示中も設定できます。

単独編集のFIRタップ数は1～262,143 タップで、偶数・奇数の両方を指定できます。割り当て接続中はマルチウェイがタップ数を所有するため入力欄が無効になり、受信値を使用します。必要なFIR長が共通FFTを超える場合、実行時FFTだけを一時的に引き上げます。共通設定値とFIR タップは自動変更しません。

### 予測応答の表示設定

「設定 → 環境設定 → 予測応答の表示設定」で、自動更新、表示モード、表示解析のFFT倍率を選びます。自動更新をOFFにしたときは、予測応答見出しの手動更新ボタンで計算します。

Gain／Phaseなどの周波数表示は2 Hz以下の共通グリッドで解析後、対数周波数軸へ1系列2,048点で間引きます。点数は軽量表示／操作可能な表示共通の固定値で、生成係数や保存データは変更しません。「表示解析のFFT倍率」は1／2／4から選択し、IR・ステップ応答・群遅延・ウェーブレットの解析長を変えます。通常は1を使用します。

倍率を上げると計算時間とメモリ使用量が増えますが、FIRタップ数や出力係数は変わりません。共通解析FFTとは別の設定です。

対話表示では拡大・移動ができます。グラフ上の軸操作は表示だけに作用し、EQ設定を変更しません。左右に並ぶ編集欄とグラフは、上部メニューの下からブラウザー表示領域の下端まで広がり、それぞれ独立してスクロールできます。ウィンドウの高さや上部メニューの折り返しに合わせて表示領域を調整します。狭い画面では縦に並べて表示します。

### 表示言語とヘルプの待ち時間

PhaseEQでは **設定 → 環境設定 → 表示言語 / Language**、マルチウェイでは左サイドバーの **設定 → 表示言語 / Language** を開き、**日本語** または **English** を選びます。初期設定は日本語です。メニューだけでなく、操作説明やヘルプも切り替わります。

ヘルプの表示待ち時間も共通設定です。初期値は2.5秒、0〜5秒で変更できます。

同じデータ保存先を使うPhaseEQとマルチウェイでは共通の設定です。もう一方の画面は次の画面更新で反映します。すぐに反映したい場合はWeb画面を再読み込みしてください。アプリを再起動しても選択を保持します。

言語を変更しても、選択中の目標特性や測定データ、フィルターの設定値は変更しません。ユーザーが入力した名前・説明、ファイル名、測定データそのものは翻訳しません。DSP用の設定ファイルや割り当てに表示言語は含まれません。ブラウザー・Streamlit標準部品や外部機器／ライブラリの診断文は、提供元の表記を使用する場合があります。


### GitHubからPhaseEQ本体を更新する

公式公開ZIPで起動したPhaseEQは、起動時に新しい正式Releaseを確認します。更新は「設定」→「PhaseEQ本体の更新」で内容を確認し、「更新をダウンロードして予約」から準備します。設定を保存し、PhaseEQとマルチウェイのサーバーを両方終了してから起動スクリプトで起動し直すと適用します。設定・測定DB・ユーザープリセット・出力データは保持します。オフラインでは現在の版を使用できます。

詳しい手順と復元時の扱いは[インストールガイド](installation.md#phaseeq本体の更新)をご覧ください。

本体ファイルの置き換え成功時に、今回と記録された前回成功分のバックアップを直ちに削除します。成功後の旧版本体は保持しません。失敗・中断時は復元用バックアップを保持します。削除できなかった場合はターミナルに通知し、新版を維持したまま次の更新成功時に削除を再試行します。

`.gitignore`と`.gitattributes`だけに変更がある場合は、変更内容を`.phaseeq-updates/metadata-recovery-*`へ退避してから正規配布内容へ更新します。この退避は成功後も保持し、保存先をターミナルに表示します。実行コードやその他の配布ファイルに変更がある場合は、変更を保護するため更新を停止します。

現在の版と同じ、または古い版の更新予約は、予約記録を`.phaseeq-updates/cancelled-*.json`へ退避して無効化します。展開済みファイルと本体は変更せず、通常の起動へ進みます。この取消は、本体が正規配布内容と一致することの確認ではありません。

成功判定は本体ファイルの置き換え完了であり、新版の起動やDB読み込みの成功確認は含みません。ユーザーDBは本体バックアップに含まれず、そのまま引き継ぎます。新版がDBを開く際に必要なテーブルや列を追加する場合があります。

<a id="backup-restore"></a>
## 15. バックアップと復元：データを保全する

- 目的：用途別に設定、作業ZIP、測定データ、ドライバーデータベースを保存・復元します。
- 場所：`設定 > バックアップと復元`です。
- 完了：復元後の現在の入力と設定を確認します。

### 正規ZIPから起動し直す場合

設定とDBをまとめて引き継ぐ手順は[インストールガイドの復帰手順](installation.md#正規zipを別フォルダーへ展開した場合の設定データベースの復帰)をご覧ください。両サーバーを終了してから旧 `data` を保全し、新フォルダーへコピーします。作業セッションZIPだけではDB全体を復元できません。

### Database backupを保存する

- `測定データJSON`は測定データ DBの移行・保全に使います。
- `ドライバーデータベースJSON`はスピーカー仕様の移行・保全に使います。
- Import後は登録件数と対象データを確認します。

### 作業セッションZIPを復元する

1. `PhaseEQ作業セッションZIP`を指定します。
2. 内容検査の結果を確認します。
3. `ZIPから環境を復元`を押します。
4. 入力、目標特性、EQ、FIR、出力条件を確認します。

ZIP内の可搬復元情報、設定path、SHA-256、設定改訂番号／schemaを検査し、破損、改変、欠落、非対応versionがある場合は現在状態へ部分適用しません。旧作業セッションZIPは従来の設定JSON探索で読み込めます。読込みは測定データ、ドライバーデータベース、DSPシステム Databaseへ自動登録しないため、必要なDBはJSONで別に保全してください。

### settings.jsonを復元する

1. `settings.json`を指定します。
2. 対応改訂番号であることを確認します。
3. `読み込んだ設定を適用`を押します。

非対応または破損した設定は現在状態へ適用しません。旧改訂番号の扱いは[補足50](#note-50)をご覧ください。

### Local snapshotsを使う

- `現在設定を保存`で現在設定を保存します。
- `保存済み設定を復元`で選択snapshotを復元します。
- `削除`は選択snapshotだけを削除します。

### 設計設定の履歴

PhaseEQの編集画面、目標特性の「登録・編集」内の「登録・更新」欄、マルチウェイのプロジェクト操作にある小さな「履歴」から、以前の設定を確認・復元できます。目標特性の「書き出し・読み戻し」と「詳細管理」には履歴ボタンを表示しません。通常の自動保存では通知を表示しません。

- 自動履歴の初期設定は **ON・30分間隔・対象ごと20件** です。「設定 → 履歴」で変更できます。
- 編集後、パイプラインの反映が完了し、最後の変更から30秒以上経過した状態で取得します。変更がない場合は増えません。測定画面の使用中は取得を延期します。
- マルチウェイは現在の割り当てと各ウェイの返却設定が一致してから取得します。未送信・同期途中の設定を自動で送信することはありません。
- 手動保存・保護した履歴は自動整理しません。「詳細」で保護・メモを設定できます。
- スピーカー入力は最新データだけを保持し、履歴ごとには複製しません。過去の入力と異なる場合は、現在の入力で復元することを確認します。測定ライブラリの登録データは削除しません。
- EQ・帯域分割・レベル・時間整合・出力条件を保存します。生成済みFIR/IIR係数は保存せず、復元後に再生成します。アプリの演算処理が変更された場合、当時と同一の係数になるとは限りません。
- 目標特性の復元は編集画面に戻す操作です。登録済み目標特性へ反映するには「更新」が必要です。
- マルチウェイの設定復元後は、通常の「PhaseEQで開く／送信」の経路で各ウェイの設定を反映し、フィルターを再生成・返却してください。過去の出力係数は復元しません。
- 未対応の履歴形式や破損したデータは適用しません。履歴の原本と現在の設定を保持します。

従来のスナップショット・共通Target/Systemの保存済みデータは保全しています。新しい履歴への自動削除対象には含めません。


<a id="troubleshooting"></a>
## 16. トラブルシューティング

### PhaseEQが開かない

標準ランチャーの`ready`表示とURLを確認します。`localhost`で表示できない場合は、同じポートの`127.0.0.1`を試してください。

### app.pyが見つからない

起動ファイルは`phaseeq.py`です。通常はmacOS／Linuxの`run_PhaseEQ_mac_linux.sh`、Windowsの`run_PhaseEQ_windows.bat`を使用します。

### 同じ設定でPhaseEQが複数起動している

画面上部の別instance通知を確認します。不要なinstanceの`Stop port ...`を押すと、対象へ通常終了を要求します。

### PhaseEQ画面がどのチャンネルか分からない

画面上部の`現在編集中のComposite Channel`でチャンネル、ウェイ、グループ、短縮IDを確認します。同じシステム内の別チャンネルへ移る場合は、新しい画面を開かず`Composite Channel workspace → 編集中のChannel`を使用してください。マルチウェイ側ではチャンネル一覧の`接続ID`、`最新ID`、`PhaseEQ画面`を照合します。

`別Assignmentを参照`または`参照中（別ID）`は、同じチャンネルの古い割り当て画面を開いている状態です。現時点では操作を禁止しないため、返却前にチャンネル名と短縮IDを確認してください。

### 新しい出力改訂番号の通知が繰り返される

通常は、PhaseEQで`マルチウェイへ送信`した返却改訂番号が変化したときだけ1回表示されます。PhaseEQ画面の起動、終了、チャンネル切替、単独編集／目標特性の編集表示だけでは通知やグラフ再描画を行いません。実際の返却を行っていないのに繰り返す場合は、マルチウェイとPhaseEQを同じData directoryで起動しているか確認し、チャンネル一覧の改訂番号が増加しているかを確認してください。

### 測定ファイルを読み込めない

FRD／TXT／CSVの列順と数値データを確認します。基本形式はfrequency、ゲイン、任意の位相です。

### 開始ボタンを押せない

測定開始・収録設定の開始直下に表示される不足条件を確認します。ESS、入力機器、サンプルレート、チャンネル、マイク校正・音圧校正を上から設定してください。

### スピーカー入力を選んでも補正へ反映されない

測定データの行選択はプレビューです。応答処理で対象を選び、`選択項目を適用`を押してください。

### 目標特性とスピーカー入力のレベルが合わない

目標特性の`Targetレベル`で自動を選びます。必要な場合は手動シフトで差分を調整します。

### グラフが細かく暴れる

スピーカー入力の平滑化または自動 EQのスムージングを強くします。最初は1/3 octまたは1/2 octを試してください。

### 設定を変えてもグラフが更新されない

予測グラフまたはマルチウェイの`自動`を確認します。OFFの場合は`更新`または`再計算`を押してください。

### FIRファイルが出力されない

FIR出力、割り当てのタップ数、書き出し形式を確認します。実効FIRがOFF、または割り当てられたタップ数が0の場合は、FIRファイルを生成しません。タップ数0の自動割り当ては[補足31](#note-31)で確認してください。

### マルチウェイへチャンネルが戻らない

割り当てのサンプルレートとタップ数を確認します。PhaseEQで条件を合わせて再計算し、`マルチウェイへ送信`を実行してください。

### 実機DSP用ZIPをダウンロードできない

互換性表のerrorを確認します。DSPまたは設計を変更した場合は画面更新後に`実機DSP用ZIPをダウンロード`を押してください。

<a id="important-notes"></a>
## 17. 使用上の注意

- FIRは有限長のため、目標特性を完全に再現できるとは限りません。
- 細かすぎる補正は過補正と長い時間応答の原因になります。
- 大きなBoostはDSP、DAC、アンプのheadroomを減らします。
- グループターゲットは表示基準であり、合成応答へ乗算しません。
- DSP Packageへ出力する前に、ゲイン、位相、インパルス応答、群遅延を確認してください。
- 実機の最大タップ数、バイクアッド数、係数形式は所有するDSP仕様を確認してください。

<a id="supplements"></a>
## 18. 補足説明

本文から参照する詳細情報をまとめています。補足番号は固定し、将来の追加で既存番号を振り直しません。

<a id="note-01"></a>
### 補足1：プレビュー、適用、更新、保存の違い

- プレビューは候補の表示で、現在の適用状態を変更しません。
- 適用は編集内容を現在の処理経路へ反映します。
- 更新／再計算は現在条件で計算結果を更新します。
- 保存して完了は確認済み状態を処理プロファイルまたは設定へ正式保存します。
- Working Copyと自動復元は障害復旧用で、正式保存とは異なります。

<a id="note-02"></a>
### 補足2：処理プロファイル、作業セッションZIP、DB backupの範囲

処理プロファイルはスピーカー入力と処理済み入力プロファイルを管理します。目標特性、EQ、FIR、ウェイ合成の全履歴を一つの処理プロファイルへ固定保存するものではありません。

作業セッションZIPは現在作業の再開用です。測定データ DB、ドライバーデータベース、アプリ内測定の録音生データを完全には含みません。

長期保全では作業セッションZIP、測定データ JSON、ドライバーデータベース JSON、必要な測定データ セッションZIPを用途別に保存します。

<a id="note-03"></a>
### 補足3：表示値の丸め

PhaseEQとマルチウェイは、指定桁の次を一般的な四捨五入で表示します。表示の丸めは内部計算値、保存値、書き出し係数を変更しません。

sample単位へ量子化する遅延などは、各処理の確定段階で別に丸めます。表示の小数桁とDSP量子化を混同しないでください。

<a id="note-04"></a>
### 補足4：測定入力ファイル

FRD／TXT／CSVはfrequencyとゲインの2列を基本とします。位相を使う場合は3列目へ位相 degreeを指定します。

コメントや一部のheaderは読み飛ばします。列順、周波数単位、数値の小数点形式はファイル内で統一してください。

スピーカー入力とNear-fieldはmono WAV impulseも読み込めます。マイク校正はTXT／OMM、インピーダンス測定はfrequency／ohm／任意位相を使用します。

<a id="note-05"></a>
### 補足5：位相のセンタリングと位相の扱い

位相のセンタリングはスピーカー入力からIRを作成し、ピーク位置を時間基準へ近づけます。WAV入力では元IRを優先し、周波数応答だけの場合はIRを再構成します。

測定位相を使用しにくい場合は、位相を使わない方式またはゲインから最小位相を生成する方式を選べます。手動 offsetは検出結果へ追加する微調整です。

<a id="note-06"></a>
### 補足6：低域／高域の延長

低域・高域の標準補完は測定端から不足帯域を推定します。旧形式に保存された筐体モデルや傾きモードの項目は保持されますが、標準補完の計算には使用しません。補完をONにして旧設定を再計算した場合、以前の係数と異なることがあります。比較に必要な完成済みFIRは別ファイルで保管してください。

低域・高域延長の旧方式を含む対応形式の設定・Working Session・Targetは、読み込み時に共通Lo／Hi方式へ正規化します。明示的な延長ON／OFF、元の応答データ、EQ編集は保持し、旧傾斜モード・箱モデルなどの方式指定は新設定へ引き継ぎません。再保存・自動保存は新方式で行います。読み込んだ元ファイル自体は上書きしません。元データを含まず既に応答へ焼き込まれた延長やFIR係数から、元の測定帯域を逆算することはしません。

表示・解析、Target編集、音響ターゲット合成、DSP Systemの元応答変換、Compositeの測定応答／Targetは、範囲外の推定に同じLo／Hi処理を使います。帯域内の補間方式と元データは保持します。マイク校正、Auto EQの補正境界、FIR／IIR伝達関数の境界処理はそれぞれの用途の設定に従います。

<a id="note-07"></a>
### 補足7：スピーカー入力 ゲインシフトの自動判定

自動は「目標特性に自動で合わせる」と共通の判定で、スピーカー実測の高音圧で平坦な帯域を0 dBへ合わせます。実測範囲の上位音圧（98パーセンタイル）から3 dB以内・傾き3 dB/oct以内が1/3 oct以上続く区間を選び、中央値を基準にします。低いノイズ部と未測定の補完帯域は除外し、80 Hz未満の低域スピーカーも判定対象にします。IR・位相の有無で基準は変わりません。

平坦部が見つからない場合は、高く安定した実測帯域を代わりに選びます。それでも有効な基準を得られない場合は自動シフトせず、手動指定を案内します。手動の微調整値は保持します。

手動シフトは自動結果への差分、または手動モードの全体シフトとして使用します。目標特性レベルのシフトとは処理対象が異なります。

<a id="note-10"></a>
### 補足10：ターゲット元のゲインのみ

目標特性の「登録・編集」の入力元欄の「低域の延長」「高域の延長」は個別にON/OFFできます（既定OFF）。Lo・Hiとも応答処理の「帯域外補完」と共通です。Lo GainはDCで振幅ゼロへ滑らかにつながる形で2 Hzまで延長します。Lo Phaseは端部の傾きを線形Hzで延長します。Hiは設計側のナイキスト周波数まで延長します。Hi Gainは末尾1/6・1/2 octで傾きを推定し、1/3 octで接続します。

遠方の傾きは−24〜0 dB/octに制限し、推定点が不足する場合は端値を保持します。Hi Phaseはアンラップした端部の傾きを線形Hzで延長します。元データの帯域内は変更しません。設定は目標特性プリセットにも保存され、マルチウェイのプレビューとチャンネルへ引き継がれます。OFFでは元の目標特性データ範囲を維持します。

音響ターゲットONでも、自動補正の範囲は各自動ゲイン／自動位相の設定に従います。目標特性の入力元の延長と、EQの補正範囲は別の設定です。補正範囲外の応答と有限タップ長による実現誤差は、出力FIRの実特性で確認してください。

`ゲイン＋位相`はターゲット元のゲインと位相を使用します。`ゲインのみ`は入力ソースのゲインだけを使い、入力ソースの位相を補正目標へ含めません。

ターゲット編集で追加した位相フィルターは別の編集内容です。入力ソースをゲインのみにしても、明示的に追加した目標特性の位相編集を自動削除しません。

<a id="note-11"></a>
### 補足11：IIR係数とFIRの分離

手動 IIRと自動IIRは適用順を保持したバイクアッド chainとして出力します。出力帯域分割ページのIIRがある場合は、IIRイコライザーの後へ接続したCombined chainも確認できます。

IIR係数をFIRへ暗黙に畳み込まないため、後段DSP側でIIRとFIRの両方を設定してください。

<a id="note-12"></a>
### 補足12：自動ゲイン／自動位相 FIRの再現条件

自動ゲイン／自動位相はスピーカー、目標特性、区間、スムージング、mask、タップ数、solver条件、後処理条件から都度生成します。自動ゲインには共通入力整形のON/OFFと各設定も含まれます。確定済み係数列だけを編集状態の正本にはしません。

マルチウェイの割り当てでは再現可能なFIR 生成定義を渡し、マルチウェイが共通生成モジュールで再生成します。係数hashが一致しない場合は、その生成定義結果を採用しません。v4は元測定と整形設定を保存し、整形済み配列は保存しません。旧v1〜v3の生成定義は整形OFFの従来計算で再生成します。新生成定義を使用する場合はPhaseEQとマルチウェイの両方を更新してください。

<a id="note-13"></a>
### 補足13：書き出し後処理

単独書き出しでは、選択したDC Normalize、極性、コサインテーパー窓、自動ゲインを「現在の出力」へ反映します。設定は明示的に確認してください。

マルチウェイへの返却では、DC正規化・極性反転・コサインテーパー窓・FIR自動ゲインをPhaseEQ側で適用しません。変更先と処理範囲は「マルチウェイ連携中のFIR後処理」をご覧ください。

<a id="note-14"></a>
### 補足14：FIR、IIR、タップ数の基礎

基礎説明と選択基準は[設計パラメーターの決め方](#design-parameters)へ集約しています。

<a id="note-20"></a>
### 補足20：予測グラフの表示段階

予測グラフは現在ページに対応する処理段階を表示します。応答処理はスピーカー入力、目標特性は目標特性まで、FIRイコライザーは行選択に関係なくONの手動ゲイン・位相・自動ゲイン・自動位相をすべて表示します。IIRイコライザーの線名はスピーカー入力がIIR前、IIR Filterが全IIRの合成、IIR結果が入力へIIRを適用した結果です。IIRイコライザーの誤差は、IIR適用後の入力と目標特性の差です。書き出しのFIR誤差とは区別してください。

出力帯域分割ページは帯域分割後、書き出しは実際に出力する最終FIRを表示します。目標特性線は比較用であり、スピーカー／FIR応答へ表示上だけ乗算しません。

<a id="note-21"></a>
### 補足21：位相、群遅延、ウェーブレット

位相のセンタリングはスピーカー入力のインパルス応答基準を整えます。合成本体は有効なスピーカー、IIR、FIR、帯域分割、オールパス、極性、遅延を含むチャンネル応答を表示します。群遅延は位相の周波数変化から求めます。ただしPhaseEQの時間解析とマルチウェイ上段は別の応答生成経路を持つため、同じ線名だけで同じ解析条件と判断しないでください。

ゲインが小さい領域は位相マスクで除外できます。遮断帯域の大きな位相回転や群遅延突出は、十分な信号がなければ異常と判断しません。

ウェーブレットはIRを周波数帯と時間へ展開し、PeakとCentroidを表示します。PhaseEQは選択段階のGain/PhaseからIRを再構成し、合成は既存システム合成 IRを使います。PhaseEQの自動 alignがONの場合は目標特性への位置合わせも入るため、両画面が無条件に同じ時間基準とは限りません。差分はmapのdB差で、IR差分のウェーブレットではありません。Peakは帯域別のピーク時刻、Centroidはエネルギーの時間重心です。

マルチウェイ上段の「合成インパルス応答」（図内タイトルが「合成出力FIR」の版を含む）は、スピーカーやIIR等の有効条件を含む推定応答です。ダウンロードするFIR係数だけの波形ではありません。帯域分割・設計応答もStudioのウェイ応答であり、任意の追加Stageを含む合成最終結果とは区別してください。PhaseEQのIR/Stepは現在のFIRタップ長へ切り出した表示で、長い音響応答全体を表示するものではありません。

<a id="note-30"></a>
### 補足30：PhaseEQとマルチウェイの境界

PhaseEQは個別チャンネルのスピーカー処理、目標特性、IIR、FIR 生成定義を編集します。マルチウェイはチャンネル、ウェイ、グループ、帯域分割、ゲイン、極性、遅延、システム合成を管理します。

割り当て中の帯域分割条件はマルチウェイ側が正本です。PhaseEQは条件をプレビューし、個別チャンネルの編集結果を同じ割り当てへ返します。返却結果へ帯域分割を重ねず、マルチウェイが現在のマルチウェイ条件で最終チャンネルとシステム合成を再計算します。

割り当て ID、チャンネル、ウェイ、グループ、サンプルレート、FIR状態が往復先を識別します。別チャンネルの編集結果を流用する場合は、新しい割り当てとして明示的に割り当てます。

<a id="note-31"></a>
### 補足31：FIR ON／OFFとタップ数

FIR ONの初期タップ長は1023です。FIR クロスを使う帯域でタップ長0の場合は、実生成した分割FIR長×2＋1を補正用に仮割り当てします。

IIRだけの帯域または全帯域でタップ長0の場合はFIR OFFです。1 タップのUnity FIRを生成せず、FIR係数、生成定義、ファイル、report、タップ数を出力しません。

全帯域でもFIRを使用する場合があるため、FIR ON時はタップ長を明示設定できます。

<a id="note-32"></a>
### 補足32：モノラル／ステレオ／SUBの表示

モノラルはMainを表示します。ステレオはL、R、L+Rを表示し、SUB単独表示は行いません。

共通SUBはLとRの各システム合成へ一度ずつ含めます。L+Rは左右を加算した新しい応答ではなく、左右のウェイと左右別システム合成を同じグラフへ並べる表示です。

ウェーブレットはL／Rが各1 panel、L+Rが左右システム合成の2 panelです。片側チャンネルを合成対象外にしても、ステレオの表示区分は維持します。

<a id="note-33"></a>
### 補足33：全チャンネルの位相・時間整合

整合処理は押した時点のスピーカー、PhaseEQ、クロス、チャンネル設定から全有効物理チャンネルを解析します。ゲインは変更しません。

FIRとIIRの理論中心を揃え、IIRの理論調整後に全帯域間の遅延を補正します。ステレオは左右を同時解析し、共通SUBを共通基準として一度だけ扱います。

全チャンネルへ一つの因果化Offsetを適用した後、DSP追加遅延を最も近い1 sampleへ丸めます。再適用時は前回の自動遅延とオールパスを除去し、補正を累積しません。

相対遅延の解析範囲は±20 msです。推定値が範囲を超えた場合は±20 msへ丸めて適用せず、スピーカー入力または時間基準の確認を求めて全チャンネルの変更を中止します。

Unwrapped 位相のシステム合成は、各チャンネルと同じ実現応答を合成し、支配的チャンネルと同じ360度の表示枝へ揃えます。この表示調整は位相の傾き、群遅延、DSPへ適用する遅延を変更しません。

全帯域には境界がないため、位相・時間整合を表示・適用しません。全帯域+SUBはSUBと全帯域の1境界を解析します。

<a id="note-34"></a>
### 補足34：グループターゲットとチャンネル 目標特性

EQのフィルター一覧では「All ON」で全行を有効化、「All OFF」で全行を無効化、「All Clear」で全行を削除できます。対象は表示中の一覧だけです（ゲイン側の操作は位相側に影響しません）。All OFFは設定値を保持します。自動 EQの重複区間は同時に有効化できないため、All ONでは一覧の後の区間を優先し、OFFになった件数を表示します。受信目標特性の編集ロック中はこれらの操作も表示しません。

グループターゲットはマルチウェイで共通管理する表示基準です。合成のチャンネル応答、システム合成、FIR係数へ乗算しません。

マルチウェイの「目標特性プリセット」では、PhaseEQの「目標特性を選ぶ」に登録済みの標準目標特性／自分の目標特性だけを選択します。メイン画面に振幅・位相を表示し、PhaseEQ 割り当てへ同じ登録値を引き継ぎます。マルチウェイではファイル読み込み・目標特性編集・ゲイン調整・位相切替は行いません。

選択した目標特性はMain／ステレオごとに通常設定へ自動保存し、再読み込み後も復元します。一覧の並び順が変わってもIDで保持します。登録が削除された場合は別の目標特性へ自動変更せず、未登録の案内を表示します。

1. マルチウェイの「PhaseEQのTargetを開く」を押します。PhaseEQが開いていれば、既存画面へ目標特性メニューへの切り替えを要求します。**ブラウザーのタブは自動で前面に切り替わりません。ユーザー操作でPhaseEQのタブを選んでください。別ウィンドウで開いている場合は、そのウィンドウを選びます。** PhaseEQを表示したら目標特性メニューになっていることを確認します。接続チャンネルの編集内容はDraftへ退避し、単独編集で目標特性を管理します。PhaseEQが開いていない場合は、ボタンのリンクから画面を開きます。
2. チャンネル編集中から開いた場合は、元の登録済み目標特性を保存データから読み直します。チャンネル用の帯域分割は編集画面へ引き継ぎません。元のプリセットが見つからない場合は案内を表示してフラットで開くので、編集するプリセットを選び「コピーして編集」または「編集する」を押してください。PhaseEQの「登録・編集」の入力元欄でファイルを読み込み、「レベル・振幅」「位相」で編集し、下部の「新規登録」または「更新」を実行します。読み込み・編集だけではマルチウェイの選択肢には登録されません。
3. マルチウェイへ戻り「登録済みTargetを更新」を押し、登録した目標特性を選択します。更新した目標特性をPhaseEQで使う場合は全チャンネルへ再送信します。

「PhaseEQの受信待ち」と表示されている場合は、まずPhaseEQのタブ／ウィンドウを選び、数秒待ってください。バックグラウンドではブラウザーが更新を一時停止する場合があります。受信待ちの要求は時間切れで破棄しません。目標特性への切り替えを確認すると、マルチウェイに「切り替えました」と表示します。切り替わらない場合はPhaseEQのタブを再読み込みし、マルチウェイのボタンをもう一度押してからPhaseEQを表示してください。

受信チャンネルの目標特性は閲覧専用で、チャンネル編集中には操作できません。目標特性を登録・編集するときは「PhaseEQのTargetを開く」で単独編集へ切り替えます。チャンネルの編集内容はDraftへ退避します。単独編集で編集しただけではチャンネルへ反映されません。登録後、マルチウェイで選択して全チャンネルへ再送信してください。音響ターゲットONの境界は各ウェイで合成されます。

旧ファイルや未登録の編集結果は登録済みプリセットとして自動適用しません。旧データを使う場合はPhaseEQでプリセットへ登録してください。

#### 入力と目標特性のレベル合わせ

単独編集の「編集する > レベル・振幅」にあるTargetレベルの自動は、スピーカー測定の音圧が高く平坦な帯域へ目標特性を移動します。原則80 Hz以上の実測範囲を等間隔の対数周波数で評価し、上位音圧（98パーセンタイル）から3 dB以内・傾き3 dB/oct以内が1/3 oct以上続く区間を選びます。目標特性のデータ点が少なくても主帯域を評価し、補完帯域は除外します。

平坦な候補がなければ、音圧が高く相対レベルが安定した1/3〜1 octaveの実測帯域を自動選択します。原則80 Hz以上を対象にし、低域専用データはその実測範囲を使用します。上位音圧から6 dB以内・平均傾き6 dB/oct以内・相対レベルの中央80％の幅1.5 dB以内を条件とし、ノイズ部や急な減衰帯域は選びません。信頼できる帯域が全くなければ調整を停止します。手動シフトは自動調整後の微調整です。

測定データを適用したら、補正前に応答処理の「レベル合わせ」を確認してください。目標特性の位置を固定し、スピーカー入力の基準レベルを合わせます。元の測定データや再生音量は変更しません。

- 「目標特性に自動で合わせる」：スピーカー測定の高く平坦な帯域を先に選び、その帯域内の目標特性との差の中央値だけ入力を移動します。スピーカーは実測範囲の上位音圧（98パーセンタイル）から3 dB以内・傾き3 dB/oct以内で判定します。目標特性の上位レベルはこのスピーカー候補帯域内で評価し、そこから3 dB以内・傾き3 dB/oct以内が1/3 oct以上続く共通区間を使います。例えば目標特性の低域が持ち上がっていても、ツイーターの高音圧帯域に合わせられます。低いノイズ部や未測定の補完帯域は除外し、候補がない場合は手動指定を案内します。受信目標特性では従来の0 dB自動調整からこの方法へ切り替えます。明示した手動シフトは保持します。
- 調整量、基準帯域、調整後の中央値差を表示します。右側グラフで調整後のスピーカー入力と目標応答を比較できます。
- 平坦な帯域がない場合は「基準帯域」を「手動指定」にし、共通実測帯域から1/3 oct以上の範囲を指定してください。「自動調整後の微調整」で仕上げられます。
- 従来の「自動: 平坦部を0 dBへシフト」と「手動シフト」も選択できます。目標特性との差はグラフで確認してください。

<a id="note-35"></a>
### 補足35：DSP 書き出し v3

DSP 書き出し v3は出力先DSPとデバイスプロファイルを選び、チャンネルごとの互換性を検査してから生成します。miniDSP、CamillaDSP、SigmaStudio、Generic形式など、Adapterごとに出力内容が異なります。

遅延 [samples]はFIR由来のタップ遅延と追加遅延を合わせた実装値です。FIR OFF チャンネルにはFIRファイルとFIR タップ数を出力しませんが、IIRや遅延は独立して出力できます。

<a id="note-36"></a>
### 補足36：オールパス構造補償

オールパスはゲインをほぼ一定に保ったまま位相を回転させ、周波数ごとの群遅延を変えるIIRフィルターです。音量やクロスのゲイン形状を作るPEQ、ローパス、ハイパスとは役割が異なります。

マルチウェイでは、ある帯域だけが一方のIIRクロスを通り、別の帯域はそのクロスを通らない場合があります。`理論配置`は、通過していない側へ対応するオールパスを置いて構造上の位相回転差を先に補い、その後にチャンネル間の相対遅延を整えます。`使用不可`はオールパスを追加せず、遅延だけで調整可能な範囲を解析します。

適用後は解析結果のオールパス欄に加え、クロス付近の位相、群遅延、システム合成を確認します。実機が必要なバイクアッド数と係数形式を扱えない場合は「位相構造補償を自動適用」をOFFにして`使用不可`を選ぶか、DSP 書き出し v3の互換性警告に従って設計を見直します。

<a id="note-40"></a>
### 補足40：連続ESS測定のタイミング方式

`IRピーク・外部ESS`はESS相関でshotを見つけ、直接音peakを相対時間基準にします。タイミング markerがなくても使用できます。

`タイミングマーカー・外部ESS`はmarker付きESSで絶対タイミングを追跡します。markerを検証できないshotでもESS相関が有効なら、ゲインとpeak基準位相を保持できる場合があります。

`ツイーター基準・外部ESS`では、先に`基準ツイーター`として保存した測定を、後続の`測定対象スピーカー`で選びます。同じマイク位置、固定ツイーター、タイミング session、ルーティングを維持してください。PhaseEQは信頼条件を満たす基準測定だけを候補に表示し、サンプルレートが異なる場合はarrivalを時間換算します。

有効な基準候補が1件だけの場合、または前回のタイミング sessionと基準ツイーターチャンネルへ一致する候補が1件だけの場合は初回だけ自動選択します。候補が複数ある場合は誤選択を避けるため手動で選びます。レジュームした基準IDが現在のライブラリにない場合は、別の候補へ置換せず未選択に戻します。

ESS生成画面の`出力Routing補助`では、`マーカーL / ESS R`または`マーカーR / ESS L`を1回選ぶと、ESS出力、marker有効化、marker出力をまとめて設定できます。

基準測定が選択後に変更または無効化された場合、スピーカー応答はライブラリへ保存できますが、誤整合を避けるためツイーター基準タイミングは使用不可として保存します。マルチウェイは全チャンネルが同じ基準測定を共有する場合だけツイーター基準を一括適用し、一部チャンネルだけへ適用しません。

PhaseEQの位相のセンタリングまたは手動 offsetを変更した場合は、`マルチウェイへ送信`後にマルチウェイで`再計算`し、位相・時間整合を再適用してください。マルチウェイはPhaseEQで除去した追加中心量を相対時間情報から復元するため、ピークセンター変更だけで位相／群遅延表示全体が移動しません。復元する時間は解析用スピーカー stageだけに使い、DSP 遅延へ二重加算しません。

<a id="note-41"></a>
### 補足41：品質判定と標準

品質判定は厳格、標準、緩やかから選びます。Clip、最低S/N未満、欠損、非有限値、破綻したdeconvolutionはRejectし、正式結果へ含めません。

1shot以上で基本測定結果を作成できます。高精度判定はshot数、Coherence、Repeatability、残留centerなどを個別に確認します。

標準は採用shotから再計算した確定派生結果です。生データを上書きせず、Post denoiseも標準とは別結果として保持します。

<a id="note-42"></a>
### 補足42：測定データの一時保存と長期保存

測定中は一時sessionへJSON、NPZ、stereo WAVを保存します。入力切断や解析例外が起きても、確定済み測定データを可能な範囲で保持します。

統合未校正IR 1本・別校正原本・必要情報の保存確認とDB登録に成功した後、一時生データ・各回のIRを整理します。保存失敗時は一時データを保持します。新規パッケージには生データ・各回の波形を含めません。

<a id="note-50"></a>
### 補足50：設定改訂番号と互換性

settings.jsonには改訂番号があります。非対応の古い自動保存は現在状態へ適用せず、復元可能な隔離領域へ移します。

手動で選択した設定またはZIPが非対応の場合も、現在作業を変更せずエラーを表示します。新しいFormatを古いアプリへ無理に読み込まないでください。

<a id="note-51"></a>
### 補足51：スピーカー仕様のAI入力支援

AI入力支援は、メーカー資料などの貼り付けテキストをスピーカー仕様候補へ整理する補助機能です。使用時は、出典資料と再配布条件を確認してください。

保存前にメーカー、型番、単位、出典、数値範囲を確認してください。AIの出力を未確認のまま処理プロファイルや設計判断へ使用しないでください。

<a id="phaseeq-detail-target"></a>
### 目標特性の保存・管理の詳細

「登録・更新」欄の「編集中」が保存対象です。一覧で別の行を選ぶと、その目標特性を編集対象として読み込みます。「未保存編集の切替ロック」がONの場合は、未保存の変更を切り替え前に確認します。

| メニュー | 操作 |
|---|---|
| 登録・編集 | 一覧選択、入力元、ゲインEQ、位相EQ、レベル調整、登録・更新を1画面に表示 |
| 書き出し・読み戻し | 応答ファイル・設定JSONの出力、目標特性設定の復元 |
| 詳細管理 | 複製・削除・配布用管理、共通目標特性のリビジョン管理 |

一覧の上の「すべて／標準目標特性／ユーザー目標特性」で表示を切り替えられます。絞り込みで編集中の目標特性が非表示になっても、編集内容は保持します。

- **新規登録**：一覧を未選択にします。編集中なら「選択を解除して新規入力へ」を押します。ファイル入力 → ゲインEQ → 位相EQ → レベル調整を行い、下の「新規登録」で追加します。
- **既存の編集**：一覧の行を選ぶと、保存済みの元応答・ファイル名・EQ・レベルを読み込みます。ファイルの差し替えや調整後に、対象名を確認して「更新」を押します。元ファイルを再アップロードする必要はありません。
- **標準目標特性**：一覧選択で読み込めますが、上書きはできません。「コピーして新規登録」で編集内容を自分の目標特性に追加します。
- **元を残して登録**：自分の目標特性の編集中に「別の目標特性として新規登録」で追加します。

#### 名前と未保存の切替

新規作成の名前は入力ファイル名（拡張子を除く）やコピー元から仮入力します。同名が登録済みなら「(2)」「(3)」などを付けます。手入力した名前や既存目標特性の編集名はファイル読込で変更しません。

「保存済み」「未保存の変更あり」で状態を確認してください。名前・説明・分類も保存内容に含みます。保存時点へ戻すこともできます。未保存編集の切替ロックがONの場合は「保存して切替／変更を破棄して切替／キャンセル」を選択します。既定のOFFでは未保存の編集を破棄して選択先へ切り替えます。標準目標特性と新規目標特性では「保存して切替」は新規保存になります。

編集内容はグラフの更新対象になりますが、プリセットの登録内容を更新するには保存が必要です。旧「ターゲットを適用」は廃止し、グラフ更新と保存を分けています。自動表示更新をOFFにしている場合は右側の再計算でグラフを更新してください。

ファイル読み込み欄の「ターゲットファイルの位相を適用する」は、入力ファイルの位相だけを切り替えます。OFFでは入力位相を0°として扱い、位相EQで追加した位相調整は引き続き適用します。

ファイルの元応答、レベル設定、振幅・位相フィルター、LF/HF extensionを一緒に保存します。マルチウェイではこの登録済み目標特性を選びます。マルチウェイから受信したチャンネル 目標特性は閲覧専用で、編集する場合は単独編集へ切り替えて元の登録目標特性を開きます。

#### 詳細管理と保存対象

共通目標特性のリビジョン管理は通常プリセットとは別の追加機能です。「詳細管理」から開けますが、基本の編集・保存には不要です。

「登録・編集」と「詳細管理」は共通の一覧表と選択状態を使います。「種類」で標準目標特性とユーザー目標特性を区別でき、上の切り替えで絞り込めます。詳細管理で選択すると保存済み目標特性のグラフをプレビューします。詳細管理での選択だけでは編集中の目標特性、未保存の編集内容、保存先は変更しません。

「登録・編集」のグラフでは、`選択したTarget（登録済み）`（Selected Target）（紫の点線）が一覧で選択した登録済みTarget、`編集中のTarget（保存対象）`（Edited Target (saved response)）（青の実線）が編集中の保存対象です。`目標応答`（Target Response）は音響ターゲットに反映した帯域分割などを含む目標応答です。

Targetの登録・更新、個別ファイル書き出し、Working Session ZIP内のTarget応答ファイルには、音響ターゲットの追加成分を含めず、Target自体の編集結果を保存します。Working Sessionの設定には帯域分割などの設定も保持されます。

ユーザー目標特性は「登録・編集へ」、標準目標特性は「コピーして登録・編集へ」で編集画面へ移動します。複製・削除は選択した目標特性名の下に表示します。配布用設定と共通目標特性の旧リビジョン管理は折りたたんでいます。詳細管理には編集中目標特性の登録・更新欄を表示しません。

<a id="phaseeq-detail-input"></a>
### 目標特性の入力形式の詳細

1. `登録・編集`の入力元欄を使います。
2. FRD、TXT、CSV、REWターゲットカーブ、Dirac Live targetcurve、WAV（モノラルIR）、URLのいずれかを指定します。WAVは元のサンプルレートで振幅・位相に変換し、IRピークを時間原点として遅延を除きます。振幅のみを使う場合は`ゲインのみ`を選びます。保存する目標特性は変換後のカーブです。WAV由来の目標特性では低域の延長はOFF・操作不可です。高域の延長は選択でき、保存・読み戻しでも選択を保持します。OFFでは元WAVのナイキストより上をグラフに表示しません。ONでは端付近の傾きからGain・Phaseを推定して設計側のナイキストまで延長します。推定部分は元WAVの応答ではありません。
3. `ゲイン＋位相`または`ゲインのみ`を選びます。

`ゲインのみ`はターゲット元の位相を使用しません。目標特性編集で追加したゲイン／位相フィルターとは別の指定です。[補足10](#note-10)も参照してください。

スピーカー入力がなくても目標特性単独のFIRを作成できます。スピーカー入力との差分補正が必要な場合は、先に応答処理で測定を適用します。

<a id="phaseeq-detail-iir"></a>
### 手動IIRのフィルター系列と数値例

HP／LPのフィルター系列で`Variable-Q (2nd order)`を選ぶと、2次固定でQを調整できます。Q≒0.7071はバターワース相当です。Qを大きくするとFc付近が持ち上がるため、ヘッドルームを確認してください。

`Elliptic`は1〜8次、通過域リップル（`ripple_db`）、阻止域減衰（`stop_db`）を指定できます。いずれも正数で、`stop_db > ripple_db`が必要です。−120 dB幅の阻止域は120を入力します。Fcは通過域端（振幅が−ripple_db dBとなる周波数）であり、−3 dB点ではありません。

例：96 kHz、LP、Fc=1000 Hz、2次、リップル0.001 dB、阻止域減衰120 dB幅。現在のサンプルレートでデジタルIIRを生成します。96 kHzの上記例では20 kHzで約−24.45 dB、位相約−159.92°です。両方式とも目標特性 IIRで同じ係数計算を使用し、設定・プリセットに各値を保存します。

<a id="phaseeq-detail-auto-iir"></a>
### 自動IIR・入力整形の詳細条件

#### 自動IIRを生成する

自動 EQはターゲット追従式（自動PEQ）に統一しました。入力と目標特性を用意し、範囲・本数・ゲイン・Q・ヘッドルームを設定して実行します。

以前の方式で生成済みのIIRフィルターも、読み込み・編集・出力できます。旧方式の設定を読み込んだ後に再生成する場合はターゲット追従式を使います。生成済みフィルターがある場合は「自動IIRを削除」で自動生成分を削除してから実行してください。手動IIRは保持します。

「設定を初期値に戻す」は生成条件のみを戻します。生成済みフィルター、入力、目標特性、編集中チャンネルは変更せず、自動再生成もしません。

#### IIR 自動 EQ：ターゲット追従（自動PEQ）

##### 自動 EQ用の入力整形

入力整形はIIR 自動 EQとFIRイコライザーのゲイン画面から調整する共通設定です。すべてのFIR自動ゲイン（旧形式・複数範囲・音響ターゲット補正を含む）へ適用します。処理順はIIR適用後のスピーカー入力→入力整形→手動FIRイコライザー→各自動ゲインです。各フィルターの既存の平滑化・補正量制限・境界処理は維持します。自動位相・手動EQ・帯域分割本体・書き出し時の全体ゲイン正規化には適用しません。

計算用入力は破線で表示し、通常の補正後応答は元の入力と実フィルターで計算します。


「ターゲット追従式」の「自動 EQ用の入力整形」を開くと、深い谷を浅くした計算用データに対してEQを生成できます。元の測定データと目標特性は変更しません。谷を浅くした量が、そのまま出力EQへ加わることもありません。

- **深いディップを浅くして計算**：局所的で深い谷だけを対象にします。しきい値3 dB、圧縮比9:1、ソフトニー幅3 dBが初期値です。深い部分を強く圧縮し、谷の輪郭と滑らかなつながりを残します。周辺より12 dB低い谷は約4 dB（約1/3）、6 dBの谷は約3.3 dB、18 dBの谷は約4.7 dBが目安です。しきい値より深い部分だけを圧縮するため、一律の割合ではありません。目標特性との位置関係や平滑化でも結果は変わります。各項目の「？」に設定の目安を表示します。保存済みの値は保持し、新しい初期値は新規設定・設定リセット時に使用します。広い谷や片側に回復する部分がない自然な減衰は対象外です。
- **帯域別oct平滑化**：初期値は200 Hz以下が1/12 oct、200 Hz〜2 kHzが1/6 oct、2 kHz以上が1/3 oct。小さい幅ほど細かい凹凸を残します。帯域ごとの数値を0にすると、その帯域の平滑化を止めます。
- **両方OFF**：入力生成を通さず、従来のターゲット追従式で計算します。ON時も後段の探索・制限は同じで、渡す入力だけが変わります。同じ入力・目標特性・手動EQ・設定なら従来結果になります。
- **自動 EQ計算用入力**：実行後の有効な計算用入力を常に破線で追加表示します。表示ON/OFFの操作は不要です。通常の補正後グラフは、整形前の入力と実際のフィルターから求めるため、残った谷も表示されます。

新規設定・設定リセット・未設定項目は両機能ONです。保存済みの明示的なON/OFFは保持します。oct幅は「1/N oct」の分母Nを入力します（対象ディップ幅3、低域12、中域6、高域3が初期値）。各帯域の0は平滑化OFFです。保存形式は従来のoct幅のままで、既存値も同じ幅として復元します。IIRでは設定変更だけで生成済みEQは変わりません。生成済み自動IIRを削除して再実行してください。

FIR自動ゲインは次の応答再計算・書き出し時に設定を反映します。結果詳細では計算用の誤差と元入力の誤差を別々に確認できます。深い谷への追従を減らすため、元入力全体の誤差が従来方式より大きく残る場合があります。スピーカーの歪み低減は未確認です。使用時は、補正前後の実測特性と歪みを確認してください。

IIR 自動 EQはターゲット追従式を使用します。方式の選択操作は不要です。

1. スピーカー入力と目標特性を設定し、入力とターゲットのレベルを合わせます。このモードは自動的なレベル正規化を行いません。
2. 補正する周波数帯域、最大フィルター数を指定します。測定と目標特性に共通する有効データの範囲で補正します。
3. PEQごとのブースト上限（初期値6 dB）、カット上限（初期値12 dB）、最大Q（初期値5.0）と、合成IIRのヘッドルームを設定します。
4. IIR自動調整を実行で生成します。すでに自動IIRがある場合は、先に自動IIRを削除で自動生成分を削除します。手動IIRは保持します。
5. 補正前後の振幅誤差RMSとグラフを確認します。生成したPEQは通常のフィルター一覧で編集できます。

この方式は対数周波数上で振幅誤差を小さくする近似です。最大フィルター数に達する前でも、有効な改善がなければ終了します。局所的な谷もブースト上限内で補正候補にします。位相は最適化しませんが、IIRの位相変化は出力に含まれます。Qは一覧と同じ0.1刻みで確定し、確定後の誤差を表示します。

ブースト上限を0 dBにするとカットだけで補正します。合成ヘッドルームは手動IIRと自動IIRの合計で評価し、必要なら自動PEQのブーストを縮小します。手動IIRだけで上限を超える場合も手動値は変更しないため、結果の最大ゲインを確認してください。方式と条件は設定ファイルへ保存されます。

<a id="phaseeq-detail-taps"></a>
### 帯域分割FIRのタップ計算とマルチウェイとの対応

新規境界は、基準クロスから遮断周波数と自然タップ数を自動計算します。正の重ね合わせはHPを低く・LPを高くし、負の重ね合わせは逆に離します。Standalone PhaseEQのFIR LR2／LR4は、「音響ターゲットに反映」のON／OFFにかかわらずMultiwayと同じ自動算出器で自然タップ数を決定します。

Standalone PhaseEQの書き出しで指定するタップ数は、補正用FIRと帯域分割FIRを全長合成した後の**最終出力タップ設定**です。正数では、合成後のFIRが設定値より長い場合は中央クロップし、短い場合は実係数長を保持し、予測応答・個別書き出し・Working Session ZIPには同じ最終係数を使用します。設定値`0`はAdaptiveの指定ではありません。

音響ターゲットOFFのFIR LR2／LR4は、実生成した分割FIR長×2＋1を`auto_split`として使用します。この仮出力枠は、同じ境界条件で音響ターゲットONが使用する自然長×2＋1の`auto_target`と同じタップ数です。画面・保存の設定値0は維持します。複数境界がある場合は必要な最大枠を使用します。

自動割り当て元がない0ではFIRを生成しませんが、FIR ON/OFFの選択値は変更せず、チェックを保持したまま無効表示にします。最終出力タップ数は編集可能で、正数を適用するとFIR ON/OFFの操作と保存済み選択が再び有効になります。

#### タップ0の動作

最終出力タップ設定`0`、FIR ONのバンドパスは次のように動作します。

| HP側 | LP側 | 結果 |
|---|---|---|
| IIR／Through | IIR／Through | 自動枠がないため実効FIR OFF。ONの選択値は保持 |
| Kaiserまたは音響ターゲットOFFのFIR LR2／LR4 | IIR／Through | FIR ON（`auto_split`） |
| IIR／Through | Kaiserまたは音響ターゲットOFFのFIR LR2／LR4 | FIR ON（`auto_split`） |
| Kaiserまたは音響ターゲットOFFのFIR LR2／LR4 | 同左 | FIR ON（合成した分割FIRの`auto_split`） |
| 音響ターゲットONのFIR LR2／LR4を片側以上に使用 | 任意 | FIR ON（必要な最大`auto_target`。ターゲットOFF側のFIR分割も合成） |

したがって、HP／LPの両方がFIR LR2／LR4で「音響ターゲットに反映」がOFFの場合も、FIRは強制OFFされず`auto_split`で出力します。

#### Multiwayとの対応

StandaloneとMultiwayの主な対応は次のとおりです。

| 項目 | Standalone PhaseEQ | Multiway Studio |
|---|---|---|
| 音響ターゲットOFF | 分割FIRを単一出力へ直接合成 | 分割FIRを隣接Wayへ直接適用 |
| 音響ターゲットON | LR／NTM4境界を目標へ反映 | LR／NTM4境界を隣接Wayの目標へ反映 |
| タップ0 | 合成した分割FIRから`auto_split`、または`auto_target` | Wayごとに`auto_split`、または`auto_target` |
| 正数タップ | 単一出力の最終枠 | Wayごとの最終枠 |
| Adaptive | 単一出力を1回解析 | Wayごとに同じ処理を1回ずつ解析 |
| 最長タップ整列／Way間Delay | なし | あり |
| 設定変更の反映 | 選択直後の再描画で予測とFIR状態を更新 | 選択直後の再描画で各Wayを更新 |

Standard、Way、Compositeの最終FIRは共通処理を使用します。基本係数とEQを確定した後、自動クロップの範囲を計算し、窓ONでは長さの110%を奇数に切り上げ、元FIRの利用可能な実係数を左右対称に取得してからクロップ・テーパーを一度ずつ行います。中央有効領域の係数は保持します。

書き出しのタップ設定付近にある「周波数特性を確認して自動クロップ」は独立したON／OFFです。ONでは補正FIRと帯域分割FIRを全長合成した後、仮の出力枠を上限としてMultiway共通の高精度Adaptive FIR Croppingを1回だけ適用します。安全条件に合格する候補がなければ合成後の元FIRを維持します。設定値0は「0（自動割り当て）」と表示し、0 tapsのFIRとしては扱いません。

「現在の最終FIRタップ数」には、自動解決またはAdaptive判定後の実係数長と時間を表示します。サンプリング周波数は同じ書き出し欄で48 / 96 / 192 kHzから選択できます。Multiway Assignment接続中は継承値を表示し、変更できません。ファイル形式は従来どおりです。

旧設定は従来の音を保つため互換方式で読み込みます。`基準クロス方式へ切り替え`で明示移行できます。特に旧LR2目標FIRはスピーカーパッケージ管理 タップから自然タップ数へ変わるため、保存してから応答を比較してください。旧プリセットの`重なり幅 Hz`は旧設定の確認用表示です。新規・更新プリセットではHP/LP別の`Overlap [oct]`を使用します。

EQファイル合成は初期状態で閉じた折りたたみ欄にまとめています。FIR OFF中はアップロードとクリアを無効表示にし、登録済みファイルの読み込み・合成を行いません。登録内容は保持し、FIR ONに戻すと再利用できます。

<a id="phaseeq-detail-crop"></a>
### 自動クロップ・出力長・Delayの詳細

自動クロップONでも、Standaloneの手動出力FIRタップ数とマルチウェイの各帯域の手動タップ長は編集できます。Standaloneでは「適用」で設定を反映します。マルチウェイでは自動クロップON中の最終長は引き続きAdaptive判定で決まり、手動値は保持してOFF時に使用します。Assignment接続中のPhaseEQのタップ数と、DSP FIR出力OFF中のマルチウェイのタップ長は変更できません。

全境界がIIR／スルー、または全帯域で帯域分割FIRがない場合、自動クロップはOFF表示で選択できません。保存済みのON設定もOFFへ戻します。DSP FIR出力をONにすると各ウェイのタップ長を入力できます。FIR LR2／LR4などの帯域分割FIRに接続するウェイでは、0は分割FIRから必要長を自動計算する指定で、1以上は指定した長さです。IIRのみ・スルー・全帯域で0の場合はFIR OFFです。

一部でも帯域分割FIRがある場合は自動クロップを選択できます。

自動クロップのON／OFFにかかわらず、各ウェイのタップ長が0の場合、仮タップ長はそのウェイの実生成した帯域分割FIR長×2＋1です。例えば307 タップなら615 タップをPhaseEQ 割り当てへ渡します。補正を設計する長さに余裕を持たせます。自動クロップONでは手動タップ長を使用せず、帯域分割、PhaseEQ返却FIR、バッフル、追加EQ FIRを全長合成した最終FIRを1回だけ解析します。

係数の左右端から、最大値比−120 dBの減衰領域または安全なディップを探します。クロップ前の最終FIRとの差がGain 0.05 dB以下、Phase 0.5 deg以下、Complex 0.01以下、かつ削除Energy比1e-6以下の候補だけを採用します。適合する位置がない場合は条件を緩めず、元の全長FIRを維持します。

左右の削除数が異なる場合もゼロ埋めは行わず、クロップ開始位置をDSP追加Delayで補償します。コサインテーパー窓ONでは、Adaptiveの有効長を110%の奇数長へ拡張します。たとえば331 tapsなら365 tapsとし、元FIRの左右17 tapsずつを使用します。端の係数が不足する場合は左右で同数取得できる範囲に制限します。中央331 tapsには厳密に1.0を乗算します。

KaiserだけでなくFIR LR2／LR4も同じ処理です。最終係数を出力時にゼロ埋め・再テーパーしません。

自動クロップOFFでも同じ仮タップ長を使用します。1以上の明示指定は仮タップ長として維持します。IIRのみ・スルー・全帯域の0、およびFIR出力OFFはFIR OFFのままです。0という保存値は書き換えず、現在の帯域分割条件から毎回算出します。

「クロス近傍の変動量」の補正前後fcレベルは、FIR出力合わせ前の基準に統一します。補正後の各FIR有効帯域から実適用の共通ゲインを除いてから複素合成し、FIRなしの帯域には逆補正を適用しません。−0.3 dBは目標上限であり、一律0.3 dBを足す処理ではありません。手動Gain・極性・Delay・位相整合は評価に残し、実出力とグラフの絶対レベルは変更しません。

「3 FIR出力・タップ長」の各帯域入力欄の下に、現在の最終FIRタップ数を表示します。0の自動設定は維持し、最終出力の実タップ数を併記します。未計算・設定変更後は「再計算待ち」と再計算の操作案内、FIRなしはFIR OFFとして表示します。補正未返却だけでは計算・出力を保留せず、最終タップ数と補正の待機理由を別に表示します。復元した補正の返却待ち、設定不備、生成エラーでは、タップ数欄に理由と必要な操作を表示します。生成エラーは画面の詳細を確認し、原因を解消して再計算してください。

### Delayの内訳と積算

FIR使用時は、全出力のDSP追加Delayの最小値を0にします。たとえば積算値が12 ms・15 ms・20 msなら、DSP追加Delayは0 ms・3 ms・8 msです。差し引いた12 msは「共通基準差引」で確認できます。全チャンネルの相対時間とFIR係数は維持します。FIR自体の中心遅延は差し引きません。最小値が既に0の場合は減らず、残るDelay差が機器の上限を超える場合もあります。出力前に機種別の上限を確認してください。

「タップ長とディレイ目安」の先頭には、保存・出力と同じ最終FIRタップ数とDSP追加Delayを全チャンネル分表示します。DSPにはmsかsamplesのどちらか一方を入力します。この値はFIR起点補償・FIR理論差補償・測定補正・Way相対Delay・整合Delayの残り・共通オフセットの積算結果です。FIR使用時は、その最小値を全出力から差し引いた相対値を表示・保存・出力します。FIR自体が持つ遅延をさらに加算しないでください。

「Composite Engine · チャンネル／グループ結果」は測定ディレイがなくても表示します。再計算時に最終FIRの中心位置とクロップ補償から理論遅延差を求め、短い経路へDelayを追加します。FIR OFFの経路も同じ基準へ合わせます。グラフ、保存、DSP出力には同じ補償値を使用し、手動・整合Delayを一度ずつ反映します。対称なLinear FIRの中心遅延は原則として（タップ数−1）÷2 samplesで、実際のグラフには最終係数を使用します。補償値は「タップ数・Delayの明細」の「FIR理論差補償」で確認できます。

この補償はFIRの時間基準を揃えます。任意の補正FIRやIIRによる周波数ごとの群遅延差、スピーカーの到達差は最終特性や実測で確認してください。共通基準が揃った測定ディレイがある場合は、到達差も反映します。外部測定距離を選択した場合は、その基準を優先します。

各スピーカーの測定到達差が共通基準で揃っている場合は、最も遅い到達時間から各チャンネルの到達時間を引き、早い側へ測定補正を追加します。WayのDelay入力は相対的な追加補正です。自動整合Delayに含まれる測定補正は差し引き、同じ補正を重ねて加えません。積算結果に負の値がある場合は、全チャンネルへ共通オフセットを加えてDSPへ出力できる値にします。

確認手順は、①必要な測定を適用する、②各WayのDelayを設定する、③「再計算」を押す、④「タップ長とディレイ目安」で各Delayの内訳と積算結果を確認する、⑤FIRとDSP設定を保存する、です。「測定到達差」は補正前の相対値で、合計へ加える値は「測定補正」です。FIR自体の中心遅延は係数に含まれるため、DSP追加Delayへ重ねて入力しないでください。

旧設定の整合Delayに測定補正が含まれるか判別できない場合は、既存値を維持し、新しい測定補正を追加しません。画面に案内が出た場合は「位相・時間整合」を再適用し、再計算して内訳を確認してください。共通基準の測定が一時的に揃わない場合は、保存済みの測定補正を維持します。測定を更新した場合は、全チャンネルの測定基準を確認して再計算してください。

REWなどの入力に測定ディレイ情報がない場合は「時間基準：理論値」と表示します。入力の振幅・位相は維持し、測定していない到達差は追加しません。理論値で調整を進め、スピーカーの到達差は実測で確認してください。位相データがない入力の扱いは従来どおりです。

「タップ数・Delayの明細」を開くと、補正用割り当て、帯域分割FIR、分割＋追加EQの中間タップ数、コサインテーパー保護枠、最長タップ整列のON／OFF、整列前FIRタップ数、追加zero数、最終FIRタップ数、Delayの内訳を確認できます。追加zeroは行わず、保存された最長整列設定で最終係数をpaddingしません。表示用IRの長さはDSP入力には使いません。

最長タップ整列の保存設定にかかわらず、最終FIRの係数は維持し、時間差は追加Delayで補償します。小数サンプルを含む場合は、保存・出力欄の機種別互換性チェックも確認してください。

<a id="phaseeq-detail-lr4"></a>
### LR4 FIRの必要長と精度条件

分割方式の順序は、カイザー窓リニアフェーズFIR、LR2リニアフェーズFIR、LR4リニアフェーズFIR、LR2 IIR（Biquad）、LR4 IIR（Biquad 2段）、NTM4 IIR（Biquad 2段）、スルー（外部で帯域分割済み）です。

LR4 FIRはLP／HPの5 Hz〜ナイキスト周波数のうち、目標振幅−100 dB以上で誤差0.05 dB以内となるタップ長を割り当てます。目安は `x = 96Fc/Fs`、`K = max(1, 0.003079x³ − 0.023119x² + 0.198385x + 1)`、`N ≈ Fs/Fc × 9.3 × K` の奇数化です。

基準は96 kHz・20 Hz〜20 kHz・重ね合わせ0、余裕代5%の数値調査です。生成した応答を検証し、不足時には延長します。厳密な最小タップ数ではなく、EQ合成や手動クロップ後の精度を保証する値でもありません。LR2の評価下限は従来どおり−80 dB幅です。
