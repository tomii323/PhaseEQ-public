# PhaseEQ v1.20.33 更新案内

PhaseEQ v1.20.33では、15ページ版を正式な簡易操作マニュアルとして同梱し、詳細マニュアルと利用ガイドを現行の操作に合わせて更新しました。FIR Gain EQのシェルフ設定を復元する際の例外も修正しました。

## マニュアルの更新

- ダーク背景と配色を維持した[15ページ簡易操作マニュアル](manual/PhaseEQ_Multiway_QuickGuide_15p_Dark_JA.pdf)を同梱しました。PhaseEQの共通設定とマルチウェイの設定からダウンロードできます。
- 図の記号・矢印・手順番号・ページ参照を整理し、IIR EQ→FIR EQの操作順序を統一しました。音響ターゲットを使う場合のHP／LP準備と、自動補正前の周波数範囲の設定、手動調整も説明しています。
- 位相構造補償のON／OFFをGain・位相グラフで比較し、リバースヌルを確認する条件と表示専用の動作を整理しました。
- [画像付き詳細マニュアル](manual/PhaseEQ_v1.20.32_画像付き操作マニュアル_日本語.pdf)は92ページ版へ更新しました。表紙・ファイル名の対応版はv1.20.32を維持し、画面例には撮影版を明記しています。

## 修正内容

- FIR Gain EQにHigh Shelf／Low Shelfを含む設定の復元時に、編集一覧への反映が例外で止まる問題を修正しました。PEQ・シェルフ・チルト・HP／LPなどが混在する設定の復元と返却を確認しました。

## 検証範囲

マニュアルの全ページ描画、文字・グラフ・参照の点検、同梱PDFと配布リンクの検査、軽量品質チェックを実施しています。設定復元とマルチウェイ返却は隔離した実ブラウザーで確認しました。実機DSPへの取込と音響測定は含みません。

## 更新後の再起動

1. 両アプリの編集内容を保存します。
2. 起動に使った各ターミナルで`Ctrl+C`を押して終了します。ブラウザーのタブを閉じるだけではアプリは終了しません。
3. macOS／Linuxは`run_PhaseEQ_mac_linux.sh`、Windowsは`run_PhaseEQ_windows.bat`で起動します。
4. 表示版がv1.20.33になったことを確認します。

操作の詳細は[利用ガイド](user-guide.md)を参照してください。
